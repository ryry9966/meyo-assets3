最近 36kr 这类报道反复出现同一条故事线：十几个人、不融资或只融一小轮、ARR（年度经常性收入）做到几百万甚至上亿美元，而且是真盈利，不是靠融资输血撑出来的现金流。据公开报道，Midjourney 以 40 人左右的团队做到过数亿美元年营收；Anysphere（Cursor 背后团队）早期以极小规模跑出夸张的收入增速；Base44 八个人把产品做到被 Wix 以 8000 万美元收购。这些不是玄学样本，背后有一套可拆解的结构。这篇文章就把"迷你 AI 公司怎么真正赚钱"这件事拆开看：钱从哪来、账怎么算、坑在哪儿。

## 一、为什么“小团队 × 大模型”这门生意现在成立

三年前做 AI 创业只有两条路：自研模型（烧钱无底洞），或者承认自己只是"调 API 的"（心虚）。现在条件变了：

1. **模型变成了水电煤**。GPT、Claude、Gemini、DeepSeek、Qwen 这些 API 把"智能"变成按 token 计费的原料，创业门槛从"训练模型"降到了"组装产品"。
2. **人均产出被杠杆放大**。用 Cursor、Claude Code 这类 AI 编程工具，一个工程师能干过去小团队的活；云原生 + serverless 让运维几乎隐形。过去一款 SaaS 产品没有 20 人很难起步，现在 3 人就能交付。
3. **分发成本变低**。App Store、短视频、SEO、独立站，一条爆款视频带来的自然流量可能抵掉半年投放预算。

三条叠加，才出现"十个人干出过去五十个人的活"的现象。可以说是 indie hacker（独立开发者）运动的 AI 加强版。

## 二、钱从哪来：做“一个岗位的一件高频小事”

通用聊天助手是巨头的战场，迷你公司的活路在垂直缝隙里。一个朴素的筛选标准：**某个具体岗位每天要重复做的那件事**。

- 律所助理每天核对合同条款 → 合同审查工具
- 跨境卖家每天写多语言 listing → 电商文案工具
- 播客主理人每天剪音频、出字幕稿 → 音视频转写整理工具

判断一个场景值不值得做，看三个数：这个动作每天发生多少次、现在耗时多久、做错了代价多大。三个数都高，用户才愿意付月费；只占一个，大概率只能卖一次性买断，甚至根本没人付费。

## 三、生死线：把毛利算明白，再谈增长

AI 产品和传统 SaaS 最大的区别：**每多一个活跃用户，都跟着一笔真实的 token 账单**。毛利做不平，增长越快死得越快。

- 一条硬经验：API 成本占营收的比例要压到 20%~35% 以内，毛利才算健康。
- 核心手段是 **model routing**：简单任务（格式化、分类、短文本）走便宜的小模型甚至本地规则，复杂任务才升级旗舰模型；配合 prompt caching 和批量推理，单次成本能差一个数量级。
- 举个例子：月费 10 美元的用户，如果放任他天天用长上下文对话旗舰模型，成本可能直接倒挂；换成小模型 + 缓存，单用户月成本能压到 1~2 美元。
- 反面教材：免费额度不设上限 + 旗舰模型，等于欢迎羊毛党替你把账单刷成烟花。

## 四、护城河：不是模型，是数据飞轮和分发

"套壳"这个骂名没骂到点子上——所有应用本质上都建在底层能力之上。真问题是：**巨头下次更新 API 时，你会不会被顺手覆盖掉？** 能留下来的迷你公司，通常握着三样东西：

1. **私有场景数据**：用户在工作流里产生的修正、标注、偏好，回流后让产品越来越准，形成数据飞轮。
2. **工作流嵌入**：不是"再开一个网页去聊天"，而是嵌进用户已有的工具链（浏览器插件、IDE、ERP），拔出来的成本很高。
3. **分发位**：某个关键词的 SEO 排名、某个社群里的口碑——这些不是模型升级就能一键复制的资产。

## 五、团队与节奏：三个人干五个人的活，别干十个人的活

迷你公司不是"穷版大公司"，结构要刻意反常识：

- 最小配置：**一名全栈工程 + 一名设计（兼产品）+ 一名增长**；财务、客服交给 AI 和外包消化。
- 冷启动别急着自动化：先给 10 个种子用户手把手服务，把人肉流程跑通，再把环节逐个换成 AI。顺序反了，你自动化的是一个错误流程。
- 融资要克制：拿股权换来的钱，很容易花在"看起来像大公司"的姿势上，而不是验证生意本身。

迷你不是缺点的委婉说法，而是一种武器配置——钳子小，但夹得准。

## 写在最后：三条冷思考

1. **先定价，再做产品**。能收到钱是第一重验证；功能再炫、没人付费，那只是昂贵的爱好。
2. **盯住"每周活跃"，别盯注册数**。AI 新奇感带来的尝鲜用户天然流失，留存曲线出现拐点，才是产品成立的证据。
3. **别在巨头的 roadmap 上安家**。选场景前先自问：如果 OpenAI 下个版本内置了这功能，我还剩什么？答不上来，就换个地方挖。
