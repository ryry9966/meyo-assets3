最近 Anthropic 的一套融资路演材料被媒体翻了出来，其中一个说法直接炸了锅：Claude 把一段为 NVIDIA GPU 写的 CUDA kernel，移植成能在 Google TPU 上跑的 Triton kernel——据称 3 天完成、性能接近原生实现，而人类工程师做同样的活儿预估要数月。同期 Anthropic 宣布向 Google 承诺采购最高 100 万颗 TPU，金额数十亿美元级、配套超过 1GW 电力容量；NVIDIA 则很快公开回击，认为这类对比忽略了生态层面的差距。这件事的看点不是“谁秒杀谁”，而是 AI 芯片竞争的底层逻辑正在松动。拆开看，至少有三层值得说清。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-12/c2b5bb437867932c.png)

## CUDA 的护城河，护的从来不只是“一门语言”

- 2006 年 NVIDIA 推出 CUDA，把 GPU 从“图形协处理器”改造成通用并行计算平台。2012 年深度学习爆发后，CUDA 生态进入正循环，近 20 年积累下来的壁垒大致有三层：
  1. **工具链**：编译器、PTX 中间表示、profiling 与调试工具；硬件每换代一次（V100 → A100 → H100 → Blackwell），整套软件同步升级；
  2. **算子库**：cuBLAS、cuDNN、NCCL、TensorRT、CUTLASS——主流深度学习框架的底层几乎都在调用这些库；
  3. **人与经验**：文档、社区、教材，以及全球一大批会“榨干”GPU 性能的工程师。
- 换句话说，买卡只是第一层门票；真正锁住你的是“把利用率从 30% 调到 80%”的那套软件和 know-how。换硬件意味着把这套东西重做一遍，这才是迁移成本的核心。
- 举例：同一个 Transformer 训练任务，NVIDIA 旗舰卡的吞吐优势，相当一部分是软件栈调出来的，而非裸芯片差距。对硬件厂来说，最贵的从来不是流片，是没人愿意迁移。

## “3 天移植”到底发生了什么

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-12/598e0ccdb6185cda.png)

- 先补术语：kernel 是直接跑在 GPU/TPU 上的并行计算代码，比如矩阵乘法、attention 里的某个算子。大模型训练和推理，本质上就是海量 kernel 在排队执行。
- Triton 是 OpenAI 开源的类 Python kernel 语言，写法比 CUDA 简洁，能编译到 NVIDIA、AMD 等不同后端，经 PyTorch/XLA 生态也能落到 TPU 上。
- Claude 干的事可以概括成一条流水线：读懂 CUDA kernel 的算法意图 → 重写成 Triton 版本 → 在 TPU 上跑通 → 做数值校验和性能调优。据披露口径，移植版本与原生实现仍有性能差距但已可用——作为初版，这说明问题能解，不等于追平。
- 为什么 AI 在这件事上快？kernel 移植高度“模式化”：数学内核不变，变的是内存布局、并行调度和指令适配。这正是 LLM 的强项——大规模模式迁移，加上不知疲倦的“编译—报错—修改”循环。人类慢，慢在查文档和 debug 的物理时间；模型能把这循环压缩几个数量级。
- 但要看清 scope：被移植的是“一组 kernel”，不是“整个生态”。分布式训练框架、推理引擎、量化方案、驱动稳定性、集群运维——这些才是 CUDA 护城河的深水区，没有哪一个是 3 天能搬走的。

## 真正的变局：算力谈判桌上的筹码变了

- 头部实验室集体“去单点依赖”：Anthropic 同时使用 NVIDIA GPU、AWS Trainium 和 Google TPU；OpenAI 也在走 AMD 加自研路线。多供应商策略已成行业标配。
- CUDA 锁定的本质是迁移成本。如果 AI 能把移植成本从“人月”压到“人天”，云厂商和大模型公司在采购谈判桌上的议价权就完全不同了。路演材料本质上是在向投资人论证一句话：我们不会被任何单一供应商锁死。
- 软件抽象层这些年一直在变厚：Triton、torch.compile、MLIR、JAX/XLA。中间层越厚，硬件之间越可互换。历史上 AMD 的 ROCm、Intel 的 oneAPI 都凿过这堵墙；这次的变量在于——凿墙的工具第一次是 AI 本身，凿墙速度可能非线性增长。
- NVIDIA 的反驳同样站得住脚：生态不只是 kernel，还有新一代硬件的同步适配、千卡万卡集群的稳定性、端到端推理延迟。这些系统性能力短期无法复制。另一个背景事实值得记住：Anthropic 自己仍在大量采购 NVIDIA GPU——竞争与依赖同时存在，这才是现实。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-12/ea4019acf444c422.png)

1. **看路演数字，先问 scope**：移植了哪些 kernel、什么模型、什么精度与吞吐条件、和谁比、“3 天”里有多少人工辅助。融资材料是叙事，不是论文；趋势可以信，具体百分比建议打七折再看。
2. **护城河在换位置，不是消失**：壁垒正从“会写 CUDA kernel 很稀缺”转向“全栈系统优化 + 供应链 + 端到端工程”。未来几年，硬件之间的可迁移性会肉眼可见地变好，但把一万张卡跑稳这件事，依然很难。
3. **给工程师的建议**：与其焦虑被替代，不如把精力压在 profiling、并行计算原理、Triton/编译器这类抽象层上。AI 负责搬运代码，人负责定义问题、验证正确性、守住性能红线——这个分工已经在发生，早一步站上去，就少一步被动。
