36kr 近期一篇《平头哥分拆，难在阿里云》，把阿里体系里最特殊的一块资产推到了聚光灯下。集团改革走到深水区，多数业务的分拆本质是“股权+报表”的会计问题，唯独平头哥（阿里旗下芯片设计公司）动不了：它最大的客户是阿里云，最强的产品为阿里云定制，最核心的叙事也建立在阿里云的规模之上。云芯关系有点像龙虾肉和虾壳——长在一起是铠甲，硬掰开，两边都疼。这篇把“难”字拆到机制层面看：脐带粗在哪、解法有几种、旁观者能带走什么判断框架。

## 一、先盘家底：平头哥手里有什么牌

平头哥半导体 2018 年由中天微与达摩院自研芯片团队合并而来，名字取自“头铁”的蜜獾。这家公司也确实头铁，几条产品线各有分量：

- **玄铁系列 CPU IP**：基于 RISC-V 架构，从低功耗的 E902 到高性能的 C920 覆盖完整谱系，官方口径累计出货超 40 亿颗，是国内 RISC-V 生态事实上的“标准件供应商”；
- **倚天 710**：2021 年发布的 128 核 ARM 架构服务器 CPU，5nm 工艺，已在阿里云规模化商用，官方称性价比显著优于同规格 x86 实例；
- **含光 800**：2019 年发布的 AI 推理芯片，曾是峰值算力/功耗比的标杆之一；
- **无剑 SoC 平台**：把 CPU 核、接口和工具链打包输出，降低行业造芯片的门槛。

注意这个结构：它不是单一产品公司，而是“IP 授权 + 对外定制 + 自用整机芯片”三条线并行。其中最值钱、也最重的一条线（倚天这类自用整机芯片），恰恰是和阿里云长在一起的那条——这是分拆难的第一性原因。

## 二、“难在阿里云”：三层物理级纠缠

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-12/faa2c7fa0eea3096.png)

**1. 订单层：云是最大客户，也是最大保底。** 芯片公司估值的核心变量是订单可见性。平头哥倚天、含光这类重资产产品，需求基本来自阿里云内部（自用降本）。独立之后，云从“自己人”变成“客户之一”：采购要走比价、议价、看对外性价比，订单确定性直接打折。而先进制程不等人——业界估算 5nm 一次流片成本在数千万美元量级，3nm 逼近上亿美元，订单摇摆对芯片公司是致命的。

**2. 研发层：软硬协同本身就是产品。** 倚天 710 不是一颗“设计完拿去卖”的通用 CPU，而是围绕云的负载定制：虚拟化、存储 IO、scale-out 架构，与云的底层基础设施深度耦合；云的软件栈又反过来定义下一代芯片的微架构取舍。这是一个闭环反馈系统，拆开等于把回路剪断，两边同时变“聋”。

**3. 资本层：母体路径决定子体叙事。** 2023 年 3 月阿里启动"1+6+N"变革，平头哥被划入云智能集团；5 月阿里云宣布拟分拆上市；同年 11 月，集团财报明确不再推进云智能集团完全分拆，公开原因是芯片出口管制带来的不确定性。母体路径悬置，子体的估值锚、员工期权、融资窗口全部跟着悬置。反过来，云也不肯轻易放手：倚天 710 是云控制算力成本、对冲 x86 采购价格的核心筹码——放走平头哥，等于自拆护城河。

## 三、对照组：Google、Amazon、Microsoft 为什么都不拆芯片部门

云厂自研芯片是行业普遍操作，但没有一家做分拆：

- **Google TPU**：2016 年对外发布，迭代多代，支撑自家 AI 训练与推理，从未独立；
- **AWS Annapurna Labs**：2015 年收购后孵化出 Graviton、Trainium、Inferentia 系列，被视为 AWS 定价权的底层武器；
- **Microsoft Maia 100、Meta MTIA**：同样锁死在自家云与业务体系内。

逻辑很朴素：自研芯片的收益 = 降本 + 差异化 + 议价权，这些收益只有留在体系内才能兑现。一旦独立，就得和 Nvidia、AMD 正面拼市场，同时失去母体订单兜底，两头不沾。平头哥的特殊性在于多一张牌：玄铁 IP 对外授权，理论上可以走独立 IP 生意（对标 SiFive）。但 IP 授权是慢生意，现金流撑不起先进制程整机芯片的研发烧钱——这条腿也不够粗。

## 四、假如真要拆：三条路径与各自代价

1. **路径 A：不拆，云芯一体。** 倚天、含光并入云的成本模型，放弃独立估值，换取协同效率。代价是芯片团队的激励受限，期权绑定母体，外部人才吸引力下降。
2. **路径 B：彻底独立，引入外部战投。** 把 RISC-V IP 与边缘、IoT 定制芯片做成对外生意，客户从车厂、运营商、IoT 大厂里找。代价是失去云优先级，倚天这类基础设施芯片大概率留云，独立体规模缩水。
3. **路径 C：切一刀。** 基础设施芯片（服务器 CPU、AI 芯片）留云，IP 授权与边缘业务独立。代价是资产切分、专利归属、客户关系的谈判极其复杂，两边都要重新证明自己。

从行业规律推，现实最可能落在 A 与 C 之间——这也解释了为什么“分拆”传闻多次出现，落地却异常缓慢：不是决心问题，是解剖难度问题。

## 五、冷思考：三条可以带走的判断框架

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-12/1642bb936facf8ba.png)

1. **看芯片公司，先看订单可见性，再看团队光环。**“内部客户”既是护城河也是天花板。评估任何背靠大树的芯片公司，先问一句：离开母体后，订单从哪来？
2. **“云芯软一体”是降本刚需，不是面子工程。** 云厂自研芯片的渗透率（Graviton、TPU、倚天的部署占比）是判断云厂长期成本曲线的先行指标，值得长期盯。
3. **对工程师：软硬件协同是这轮周期最保值的能力。** RISC-V、编译器、系统调优、负载建模——芯片定义越来越由云侧软件反向驱动，纯硬件视角正在贬值，复合视角正在升值。

平头哥这桩悬案，本质是“组织要独立、物理要耦合”的拉锯战。芯片与云长在一起容易，分开很难——这大概是所有自研芯片的云巨头共同的宿命。分不分、何时分、怎么分，最后比的都不是口号，而是订单、流片成本和人才账本。
