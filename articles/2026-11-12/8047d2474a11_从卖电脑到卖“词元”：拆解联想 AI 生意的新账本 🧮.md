最近 36kr「最前线」报道，联想把“词元”当成一门正经生意来做：AI PC 里跑的个人智能体、企业侧的智能体平台，最终都要落到“按词元计费”这笔账上。词元（token）听起来像行话，其实是 AI 时代最重要的计量单位。一家卖了四十年电脑的公司，为什么突然关心起“词元”？这篇文章拆成三层：词元是什么、联想图什么、这门生意卡在哪。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-12/45de20ce61b0e190.png)

## 词元是什么：AI 时代的“度电”

- 大模型并不按“字”处理文本，而是先由分词器（tokenizer，主流方案是 BPE）把句子切成最小片段，这些片段就是词元。英文大约 0.75 个单词对应 1 个词元；中文在常见分词器下，1 个汉字约对应 1~1.8 个词元，各家实现略有差异。
- 行业通行的计价方式是“每百万词元多少钱”，输入通常比输出便宜。举例：让模型帮你写一份 3000 字的方案，输出本身要消耗几千词元，加上多轮对话的上下文，一次完整任务的总消耗轻松上万。
- 这套逻辑并不新鲜。早在 1961 年，约翰·麦卡锡就预言“计算会像水电一样按需计费”；后来云计算按小时卖虚拟机，SaaS 按席位收费，如今大模型按词元收费——计量单位一路演变，本质都是把“能力”切成可计量、可结算的小份。词元，就是智能时代的“度”。

## 联想的账本：硬件越来越薄，服务越来越厚

- PC 是典型的成熟市场：全球年出货量约 2.4~2.6 亿台，多年在低位徘徊。联想出货量常年全球第一，但公司整体净利率长期只有 2%~3%——一台几千元的 AI PC，落到账面上的利润可能只有百元级。
- AI PC 的硬件溢价有限。NPU 算力（主流门槛 40 TOPS 级）确实是新卖点，但厂商之间同质化得比模型迭代还快，用户很难为“能跑本地模型”长期多掏钱。
- 服务业务才是厚利润：按财报口径，联想的方案服务板块营收占一成多，经营利润率在 20% 上下，远高于设备业务。公司战略一直在向“设备+服务+订阅”迁移，词元是这条路上的自然延伸——硬件负责获客，服务负责赚钱。
- 最关键的是分发优势：数亿台存量设备和企业客户关系，是现成的“管道”。这和运营商靠装机量卖流量、云厂商靠存量客户卖 API，是同一个道理。

## 词元生意怎么转：端云混合的“分布式发电+售电”

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-12/8d133fac85e5b0a7.png)

联想技术路线的底座，是它自己反复强调的“混合式人工智能（Hybrid AI）”，词元生意就长在这套架构上：

1. **端侧发电**：AI PC 用 NPU 跑量化后的 7B~8B 级小模型，日常问答、文档摘要、本地知识库检索在本地产出词元，边际成本近乎为零，还能主打隐私卖点——数据不出设备。
2. **云侧并网**：长上下文推理、复杂规划、多智能体协作，调云端大模型 API 完成。
3. **联想站在中间做三件事**：提供智能体入口（AI PC 内置的个人超级智能体、企业侧的智能体平台）；做端云调度，决定一次请求走本地还是上云；做计费与分成——用户不感知背后是哪家模型，联想做聚合、批发与零售。
4. **数据飞轮**：设备端的使用数据反哺智能体优化，体验变好 → 使用变多 → 词元消耗上升 → 粘性上升。

一个直观类比：NPU 是屋顶光伏，云是电网，智能体是用电管家。联想想当的不只是“卖发电机的”，而是“售电公司+电表”——每一度智能，都过它的表。

## 最大的变量：词元本身在“通货紧缩”

这门生意最大的敌人不是对手，而是词元价格的下行曲线。

- **价格战已经打了两年多**：2024 年以来，国内主流大模型 API 经历多轮大幅降价，部分模型百万词元输入价格进入 1 元区间，降幅普遍达到一个数量级，海外趋势类似。背后是专用推理芯片、批处理、KV cache、量化与蒸馏，把单词元成本持续打下来——有研究机构测算，同等能力的推理成本大约以每年 10 倍的速度下降。
- **这意味着“倒卖词元”的毛利会被快速压缩**。如果只是把大模型 API 转手加价卖，护城河约等于零。
- **出路在智能体层**：用户真正愿意付费的是“结果”——自动对完的账、生成完的标书、排好的行程，而不是中间的词元。按任务/按结果计费（outcome-based pricing）比按 token 计费更抗通缩。这也是联想把“超级智能体”而不是“模型”放在故事中心的原因：词元是计量单位，智能体才是交付物。
- **其他不确定项**：个人用户的付费意愿仍待验证；端侧小模型能力有天花板，体验一旦不达预期，“本地优先”就退化成“云端依赖”；隐私卖点需要真实架构支撑，否则只是营销话术。

## 冷思考：给关注这门生意的人三条

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-12/a9bbac1c054ac766.png)

1. **盯住“单位智能成本”，别只听发布会。** 判断词元生意成立与否，核心变量是 cost per token 的下降速度与计费价差的赛跑。锚定结果计费、靠智能体工作流沉淀数据的模式更抗价格通缩；纯 API 转售模式最先出清。
2. **端云混合先算 TCO，再谈情怀。** 企业采购别被“本地更安全/更省钱”单边说服：拿真实工作负载测一轮词元消耗、响应质量与硬件折旧，再决定端云配比。本地不等于便宜，云端也不等于不安全。
3. **用“三件套”检验任何一家公司的 AI 转型**：分发入口（设备/用户规模）、推理成本控制（自建能力或议价能力）、可循环的计费闭环（用户持续付费）。三者齐备才叫商业模式，缺一件就还停在故事阶段。

词元生意，本质上是“把智能变成水电”这个六十年的老梦想在 AI 时代的重演——能否成真，看的不是概念多热，而是那块电表，转得是否足够稳定。
