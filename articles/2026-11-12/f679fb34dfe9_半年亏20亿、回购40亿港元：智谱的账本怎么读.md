最近一级市场被两个数字刷屏：智谱的上市申请材料显示，公司半年亏损约 20 亿元；与此同时，一份“最高 40 亿港元”的回购安排进入公众视野。很多人的第一反应是拧巴的——都亏成这样了，哪来的底气掏 40 亿回购？先把结论放在前面：这两个数字不但不矛盾，反而是同一份资本结构说明书的上下两页。把机制拆开，这就是一堂标准的“未盈利科技公司 IPO 公开课”。本文以公开披露口径为基准，把账本一页一页读给你看。

## 一、20 亿亏在哪：大模型公司的三座成本大山

智谱 2019 年从清华 KEG 实验室孵化而来，靠 GLM 系列基座模型和 ChatGLM 的开源路线站稳脚跟，海外以 Z.ai 品牌运营。这类“自己训基座模型”的公司，成本结构高度相似：

- **训练算力**：一次旗舰模型的预训练，算力开销动辄数亿元起步。Scaling Law 决定了能力每上一个台阶，投入大致要跟着翻倍，GPU 采购和租赁是最大的重资产项。
- **推理成本**：模型上线后，每一次 API 调用、每一轮对话都在实时烧卡。过去一年国内 API 价格战一轮接一轮，“每百万 token 又降价”的新闻背后，是毛利率被反复压缩。
- **人才密度**：顶尖算法工程师年薪普遍百万级，一支核心研发团队几十人，一年就是数亿量级的人力成本。

对照一下行业坐标：据公开报道，OpenAI 2024 年亏损约 50 亿美元，Anthropic 也长期处于深度投入期。放在“训基座模型”这个赛道里，半年 20 亿属于常规消耗，不是异常值。

还有一个容易踩坑的会计细节：港股招股书里常见“可转换可赎回优先股公允价值变动”科目——公司估值涨得越多，这一项计提的账面亏损反而越大。它不花一分钱现金，上市后优先股转为普通股，这笔亏损还会回冲。估值涨等于账面亏，这是会计准则式的黑色幽默。所以看亏损，先分清“现金亏损”和“会计亏损”。

## 二、40 亿回购是什么：不是豪气，是条款到期

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-12/21decfcb41067cb7.png)

把招股书当 API 文档读：先看报错（亏损），再看埋的钩子（条款），最后看依赖项（融资环境）。所谓“最高 40 亿港元回购”，大概率属于第二类——优先股赎回条款的披露，而不是公司主动买自家股票：

1. **条款从哪来**：私募融资轮次里，投资人拿的通常是优先股，附带赎回权（Redemption Right）——如果公司在约定期限内没有完成合格上市，投资人有权要求公司按“本金＋约定利息”（常见年化个位数）回购股份。
2. **为什么现在披露**：递交招股书时，这类或有义务必须摊在阳光下。“最高 40 亿”是把所有可能触发赎回的股份按上限口径加总，不是账上真要掏出的现金。
3. **IPO 的魔法**：只要上市成功，优先股通常自动转换为普通股，赎回权失效，40 亿的“义务”就地蒸发。回购条款本质是投资人的安全气囊，而上市是它的泄压阀。

所以这个数字读出来的信息不是“公司要还债 40 亿”，而是“历史投资人对退出路径的保底要求是 40 亿量级”。它反映的是过去几轮融资的定价与条款，而非未来现金流的黑洞。

## 三、为什么大模型公司集体巨亏：一道经济学题

把一家 LLM 公司想象成一边修路一边收费的路桥公司：修路（训练）是资本开支，先烧钱后成资产；收费（API、订阅）是经营现金流，但费率被竞争压着；路修得越宽（模型越强），维护费（推理与迭代）越高。当前全行业正卡在“路修宽了、费率没跟上”的阶段：

- **收入端**：国内以 To B 项目制为主，定制多、复用少、回款慢；To C 订阅与海外市场增长快，但基数还小。
- **成本端**：DeepSeek 等高效率开源模型崛起后，闭源 API 的定价天花板被进一步压低——效率红利大部分让渡给了用户，没有留在厂商的毛利率里。
- **节奏端**：基座模型一年一代，你不追下一代，上一代投入的护城河就开始漏水。

所以“亏损”本身不是新闻，**亏损收窄的斜率**与**收入增长的斜率**之间的剪刀差才是。

## 四、上市是解法吗：18C、弹药与时间窗口

- 港交所 18C 章（特专科技公司）就是为“未盈利但硬科技”的公司开的门，降低了对营收和盈利的门槛。
- 募资用途通常写得很朴素：训练下一代模型、扩充推理算力、补研发投入。对智谱而言，GLM 系列的迭代节奏就是生命线，弹药必须跟得上。
- 风险同样明确：港股对 AI 叙事的定价窗口不等人；身后有字节、阿里、DeepSeek 的贴身竞争；如果收入增速撑不起估值，二级市场会用脚投票。

一句话总结：上市不是终点，而是把“烧钱换能力”的私有循环，切换成“能力换公开融资”的公开循环。循环转不转得起来，取决于收入斜率能不能追上烧钱斜率。

## 五、冷思考：怎么看一家“亏损 AI 公司”

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-12/c786198cc3f4b15a.png)

给你三条可操作的检查项：

1. **先看毛利趋势，再看亏损绝对值**：亏损收窄＋毛利上翘，是商业模式跑通的信号；两条曲线反向走，才需要真正警惕。
2. **把 Runway 算清楚**：现金储备 ÷ 年化烧钱速率。账面弹药撑不过 18 个月的公司，融资节奏比技术路线更值得盯。
3. **分清“最高”“或然”“实际”三个口径**：回购、对赌类条款的上限数字，是法律意义上的最大值；标题喜欢用最大值，读者要用触发条件去折算。

亏损是燃料，条款是安全带，上市是换挡——三个仪表拼在一起，才是一辆车的完整车速表。看懂仪表盘，比争论“亏得多惨”或“回购多豪”有用得多。
