一天之内，美股市值缩水约 2.8 万亿美元；同一时间，硅谷头部风投的一份分析在中文科技圈刷屏：企业使用开源（开放权重）模型的支出，九成流向了中国团队训练的模型。两条消息叠在一起，很容易读出“变天”的味道。这篇文章不聊情绪，只拆三件事：市值蒸发的机制、那组“九成”数据的口径、以及开放权重生态重心迁移背后的工程与商业逻辑。拆完你大概就能分清：哪些是真信号，哪些是叙事浓度。

## 先泼冷水：“蒸发”的是预期，不是现金

- 市值怎么算：最后一笔成交价 × 总股本。它是边际定价——用当天换手的极小部分股份，给全部股份记账。
- 打个比方：一个小区 100 套房，昨晚只成交 1 套，价格比上周低 5%，中介马上说“小区资产缩水 5000 万”。没人搬走这笔钱，但所有挂牌价的锚都动了。
- 所以“一夜蒸发 2.8 万亿”的准确读法是：市场对“AI 算力与模型溢价”的预期，在单日内完成了一次剧烈重定价，而不是有等量资金流出。
- 但账面数字也不是无关痛痒：估值锚下移会传导到融资成本、期权激励和 CapEx 预算。预期会变成真约束，这是“蒸发”的第一层传导。

## 导火索：一次“智能单位成本”的暴跌事故

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-07/414577cc5857948c.png)

- 这个剧本年初就演过一次：DeepSeek-V3/R1 发布后，论文披露 V3 预训练约 278.8 万 H800 GPU 小时，按租金折算约 557 万美元。注意这是预训练算力成本，不含数据、研究和失败实验；但就算放大十倍，仍比同代闭源模型的训练预算低一个量级。
- 成本是怎么压下来的，四件事：
  1. MoE（Mixture of Experts）：总参数 671B，每个 token 只激活约 37B——在编 671 人，上班的只有 37 人；
  2. MLA（Multi-head Latent Attention）：把 KV cache 压到很小，长上下文推理的显存账单直接打骨折；
  3. FP8 混合精度、手写 PTX kernel、DualPipe 流水线：在受限的互联带宽上把通信和显存抠到极限；
  4. R1 用 GRPO 做强化学习练出推理能力，再蒸馏到 1.5B~70B 的小模型，消费级显卡也能跑。
- 价格信号：R1 API 上线时约 $0.55/百万 token（输入）、$2.19/百万 token（输出），约为同级闭源推理模型的零头。
- 资本市场的逻辑链很短：智能的单位成本暴跌 → 按旧成本曲线定价的算力需求与模型溢价需要重估 → 先卖为敬。年初英伟达单日蒸发约 5890 亿美元、创当时个股纪录，就是这条逻辑链的第一次显形。

## “九成流向中国”：先看数据，再看口径

- 这个说法有它的事实基础：
  1. Hugging Face 上，Qwen 系衍生模型数量已超 10 万，超过 Llama 系成为最大的模型家族；DeepSeek-R1 发布数月内，衍生与微调版本数以千计；
  2. 多份企业调研显示，选择开放权重路线的团队，底座高度集中在 DeepSeek 和 Qwen；
  3. 主流云厂商的开放模型托管目录里，这两家的位置也最靠前。
- 但引用“九成”之前，先问口径：
  1. 支出怎么统计？API 收入、自托管 GPU 折旧、云 marketplace 分账，三种口径几乎无法精确加总；
  2. 下载量 ≠ 使用量 ≠ 支出，衍生模型数量 ≠ 商业部署量；
  3. 开放权重模型被第三方推理云转售时，收入归属极难追溯；
  4. 严格说它们是 open weight 而非 open source：权重开放，训练数据与完整训练管线大多没有公开。
- 我的判断：方向上，“开放权重生态重心迁移”大概率成立；但“九成”是叙事浓度很高的单一口径，引用时建议自动打七折。对漂亮的整数保持本能警惕，是技术人的基本修养。

## 重心为什么会移动：四个工程与商业原因

1. 后发者的生态杠杆。闭源头部有先发优势和资本弹药，正面卷闭源不是理性选择；把权重放出去，先占住开发者心智和微调生态位——模型可以追赶，生态位要抢跑。
2. 算力约束倒逼效率创新。受限的互联带宽等于戴着镣铐跳舞，于是 MoE 通信、显存复用、低精度训练被抠出极限组合。工程上的朴素规律：约束才是最好的架构师。
3. License 商用友好。MIT、Apache 2.0 几乎零商用门槛；某些流行的开放权重协议则带月活上限、品牌署名等条款。企业合规部门天然更喜欢前者——少一条律师要读的条款，采购就多一分通过概率。
4. 定价即营销。低价 API 不只是补贴，而是把“智能价格锚”整体下压的武器：开发者的心理价位一旦锚定在低位，后来者很难再抬回去。

顺带说一句：开源不等于做慈善。开放权重公司的商业闭环是“权重获客、API 与企业服务变现”，开源是漏斗的上层，不是终点。

## Jevons 悖论：效率越高，算力可能越不够用

- 1865 年，经济学家 Jevons 发现：蒸汽机效率大涨后，英国煤耗不降反升——用煤越便宜，用煤的场景越多。
- 2025 年这一幕在算力上重演：DeepSeek 事件后，纳德拉公开引用这个悖论，随后几周算力龙头也逐步回补了大部分跌幅。
- 机制：推理成本每降一个量级，原本不划算的场景——实时语音、长上下文 Agent、视频理解——就进入可行域。带宽从 56K 到光纤，没有人因此少上网。
- 补一个边界条件：Jevons 悖论成立的前提是需求弹性够大。如果应用层消化不了便宜算力，剧本就切换成“供给过剩、价格战、资本开支反噬”——这正是空方真正担心的剧本。市场在两个剧本之间反复横跳，波动率就是这么来的。

## 三条冷思考，写给要做决策的人

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-07/9348fcfd1babd8bb.png)

1. 建立“口径敏感度”。看到“蒸发 X 万亿”“九成流向”，先问三件事：统计范围是什么、样本从哪来、时间窗多长。市值不等于现金，下载不等于收入。自己引用数据时，把口径写在数字旁边——那一行小字，是专业与外行的分界线。
2. 选型看 TCO，不看头条。开放权重 ≠ 免费：GPU、运维、版本升级、评测体系、安全护栏都是持续成本。更稳的做法是混合架构：敏感数据与高频调用走自托管，长尾与尖峰走 API，并用 OpenAI 兼容接口或 vLLM 这类抽象层把“换模型”的成本提前打下来。别让业务和某一家模型的人生绑定。
3. 把“成本通缩”写进产品假设。智能的单位成本大概率按年数倍下降，做五年财务模型时，别把今天的 API 价目表当常量。红利期的价格战里，比的不是谁跑得快，而是谁的架构留了余量、谁活得久。

一句话收尾：市值会蒸发，口径会打架，但“把智能做便宜”这条技术曲线不会回头。看懂曲线的人，不必每天盯热搜。
