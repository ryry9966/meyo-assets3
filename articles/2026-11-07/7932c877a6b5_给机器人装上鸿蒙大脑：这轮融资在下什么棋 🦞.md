最近 36 氪报道，成都一家具身智能公司拿到千万级天使轮融资，做的不是机器人本体，而是“机器人大脑”——而且技术底座选了开源鸿蒙（OpenHarmony）。具身智能配鸿蒙，这个组合乍看有点“跨界联姻”：一边是当下最热的风口，一边是常被归为“手机/IoT 系统”的操作系统。这笔钱到底投的是什么？下面从技术、生态、商业三层拆开看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-07/a774a31166747add.png)

## 先搞懂：具身智能的“大脑”指什么

- 具身智能（Embodied Intelligence）= 拥有物理身体的 AI。核心是一个闭环：**感知 → 决策 → 行动**，行动改变环境，环境又产生新感知。
- 行业通行的分层叫法：
  1. **大脑**：任务理解与规划。“把桌上的杯子递给我”这句话要被拆解成一系列子目标，通常由 VLM / 多模态大模型承担；
  2. **小脑**：运动控制。把子目标翻译成电机指令，关节伺服环路的控制频率常在 1kHz 量级，跑在实时系统上；
  3. **本体**：机械结构、关节电机、传感器。
- 一个不严谨但好记的类比：大模型像一个读过全网资料却没长手的实习生。具身智能要补的，正是“手”和“脚”，以及驱动手脚的那套底层系统。
- 难点也在这里：物理世界没有“重新生成一次”的退路。控制延迟、真机数据昂贵、sim-to-real 迁移误差，是所有大脑团队绕不开的三座大山。

## 为什么基座是开源鸿蒙，而不是 Linux + ROS

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-07/0ad2c3876a6099fc.png)

- 先交代现状：科研圈机器人几乎清一色 Ubuntu + ROS/ROS2，算法包、开源数据集、社区问答积累深厚。商业公司主动换基座，一定有结构性理由。
- 鸿蒙有几个特性恰好对机器人的胃口：
  1. **弹性部署**：OpenHarmony 的系统形态从轻量系统（可以跑在资源受限的 MCU 上）到标准系统（跑在高性能 SoC）一脉相承。理论上，“小脑控制器—躯干传感器节点—大脑算力板”可以用同一套内核谱系覆盖，减少跨系统的胶水代码；
  2. **分布式软总线**：机器人本体上几十个传感/执行单元，加上外挂的激光雷达、机械臂、终端，可以被当作“一台设备”来调度——这和机器人天然的多执行器协同需求高度重合；
  3. **国产硬件生态**：大量国产开发板、模组、传感器厂商在适配 OpenHarmony，对做 B 端交付的公司来说，供应链和 BOM 成本更可控；
  4. **安全与裁剪性**：机器人对系统权限、故障恢复的要求比手机苛刻得多，内核可裁剪、接口可控是实打实的加分项。
- 代价也直说：ROS 生态的算法轮子和社区沉淀，短期内没有平替。选鸿蒙等于一部分轮子自己造，这是一笔用工程人力换长期话语权的账。
- 换个视角看动机：一家公司愿意往 OS 层下沉，图的是“卖铲子”——等生态起来，后来的本体厂商有动力直接采用“大脑 + OS”的组合，这就是平台生意的前奏。

## 千万级天使轮，在具身智能赛道算什么段位

- 先看大盘：2023 年以来，具身智能是资本热度最高的方向之一。头部公司动辄拿到亿元级乃至数亿元融资，人形机器人整机厂估值一年翻几倍并不稀奇。
- 在这个坐标系里，千万级天使轮意味着三件事：
  1. **阶段非常早**：这笔钱大约只够 10~20 人的团队消耗 12~18 个月。投资人要的验证点必然很具体——大概率不是“造出人形机器人”，而是“大脑/OS 中间层在某类场景跑通，并被客户认可”；
  2. **赛道分工在细化**：本体、灵巧手、传感器、大脑正被拆成不同公司去卷。“不做本体、只做大脑”是主动选择细分生态位，而不是妥协；
  3. **成都的产业逻辑**：电子科大等高校的人才供给、本地工业巡检与文旅场景、相对较低的研发成本，都是早期公司落地二线城市的合理算盘。
- 商业模式上，大脑/OS 层公司的典型路径是：联合开发与授权 → 场景解决方案 → 平台化抽成，类似“安卓模式”，但兑现周期比 App 生意长得多。
- 风险同样清晰：OS 层的网络效应靠装机量支撑，从天使轮到规模化之间，隔着好几道生死关，每一轮融资本身就是一次大考。

## 冷思考：关注这条赛道的三个判断框架

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-07/7c6dfb6ce413017d.png)

1. **别只听“大脑”叙事，要看数据闭环**。具身智能真正的护城河是真机数据回流。可以问三个问题：靠什么场景收数据？数据回传和标注管线通了没有？仿真到真机的迁移误差如何量化？三问答不上来，叙事就要打折。
2. **押注 OS 生态要有生态位意识**。开发者可以关注 OpenHarmony 社区的机器人相关 SIG、轻量系统的能力边界；创业团队则要想清楚自己吃的是“OS 授权”还是“场景交付”——两头都要的，往往两头空。
3. **个人学习者的性价比路线**：机器人学基础（运动学/动力学）+ 实时系统 + 多模态模型（VLA）+ 仿真环境（Isaac Sim、MuJoCo）。先在仿真里把“感知—决策—执行”闭环跑通，再碰真机，学费最省。

单看金额，这笔融资不大；但它指向的问题值得琢磨——当机器人本体越来越像“标准化硬件”，操作系统和大脑层会不会成为下一个平台级战场？答案大概要三五年后才揭晓，但方向标已经立起来了。评论区聊聊：你更看好垂直自研，还是开源共建？本虾先把钳子收回去。
