过去十几年，双十一大屏上跳动的都是 GMV，大家抢的是购物车。而最近一年，阿里对外反复强调的高频词变成了 Token——大模型推理的计量单位，也是云厂商新的"营业额"。36kr 把这个转变概括为"不抢商品抢 Token"：一家电商公司，开始用每天烧掉多少 Token 来讲增长故事。以前抢购物车，现在抢上下文窗口。这个切换背后的逻辑是什么？Token 真能撑起一次翻盘吗？这篇文章把它拆开算一算。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-07/db4a9e8ace0f66ae.png)

## Token 是什么：AI 时代的"度电计量"

- **它是最小计费单位。** 大模型不直接读汉字和单词，而是先把文本切成 token（常见算法是 BPE 分词）。粗略换算：1 个 token 约等于 0.75 个英文单词，或 1~1.5 个汉字，不同词表差异不小。
- **它是推理时代的"电量"。** 训练拼的是算力采购，上线后拼的是推理：API 按输入/输出每千 token 计价，GPU 利用率、显存带宽、机房电力，最终全部摊到每个 token 上。管理层把 token 类比为 AI 时代的"电力"并不夸张——工业时代看发电量，电商时代看 GMV，AI 时代看 token 消耗量。
- **价格正在跳水。** 2024 年 5 月，阿里云把 Qwen-Long 的输入价格从 0.02 元/千 token 降到 0.0005 元，降幅约 97%；DeepSeek、字节随后把主流模型打到更低的价位。两年时间，头部模型推理价格下降了 1~2 个数量级，"每 token 成本"成了这个行业共同的摩尔定律。

## 阿里为什么"梭哈" Token：一套飞轮，不是一次降价

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-07/37a8b93a6d33fdcb.png)

- **主业需要新故事。** 国内电商大盘竞争白热化，GMV 增速叙事失效；云计算板块在经历阵痛后重回两位数增长，AI 相关产品收入连续多个季度保持三位数增长。估值锚自然从"商店"切到"电厂"。
- **第一环：开源导流。** Qwen（通义千问）系列坚定走开源路线，在 Hugging Face 上的衍生模型已超过 10 万个、下载量数亿次，成为全球规模最大的开源模型族群之一。开发者用得越深，迁走成本越高——开源模型本身没有护城河，开源攒下的生态才是。
- **第二环：降价扩量。** API 越便宜，应用和 Agent 越敢烧 token；调用量上涨摊薄推理成本，又反过来支撑下一轮降价。这就是工程师都熟悉的杰文斯悖论：蒸汽机效率每提高一次，煤反而烧得更多。
- **第三环：重注基建。** 2025 年 2 月，阿里宣布未来三年投入超过 3800 亿元建设云和 AI 算力，规模超过过去十年总和。这不是一次市场活动，而是一次资产负债表级别的下注。

## 翻盘之前，先过三道关

1. **成本关：折旧是刚性支出。** 3800 亿资本开支落地后，GPU 折旧会长期压制自由现金流；token 收入的复合增速必须跑赢折旧曲线，否则价格战就从"抢市场"变成"失血"。
2. **需求关：单轮问答有天花板。** 真正的增量在 Agent 和多模态——推理链越长、调用的工具越多，消耗越大，一次完整 Agent 任务的 token 消耗可能是普通问答的几倍到上百倍。应用形态决定 token 曲线的斜率。
3. **竞争与供给关。** DeepSeek 证明了"好模型可以不贵"，字节手握抖音的分发能力和火山引擎的低价策略，百度、腾讯在各自生态里闭环。同时，先进制程芯片和数据中心电力存在供给约束，大规模扩张要排队等货、等电，节奏不完全在自己手里。

## 别看新闻标题，看三个仪表盘

- **仪表盘一：云收入增速与 AI 收入占比。** 看连续 4~6 个季度的趋势，单季反弹不算数。
- **仪表盘二：token 调用量 × 单位推理成本。** "量涨价跌、收入还涨"才是健康的规模效应；只跌价不涨量，就是单纯让利。
- **仪表盘三：capex 与经营现金流的比值。** 投入要换回确定性收入，而不是纯信仰；这个比值若常年高位而收入跟不上，故事就讲不圆。

## 冷思考：给开发者、创业者和围观者

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-07/c970c20e445b3205.png)

- **给开发者：把模型价格曲线写进成本模型。** 用 context caching、批量推理、小模型蒸馏，把"最贵的模型"换成"够用的模型"，多数场景能省下大半成本。
- **给创业者：别把"接了个 API"当护城河。** 押注 token 弹性大的场景——长文档处理、Agent 工作流、视频生成。这类需求在单价下降时，用量涨得最凶。
- **给围观者：少用二值判断。** 对战略转型，别急着下"翻盘/完蛋"的结论，按季度盯上面三个仪表盘就够了。Token 和双十一订单确实都论"亿"计，区别是订单有峰值，token 的曲线目前还看不到拐头——这正是所有云厂商下重注的原因。
