过去二十年，互联网巨头打仗都有个核心 KPI：门户抢 PV，电商抢 GMV，短视频抢用户时长。到 2025 年，双 11 的硝烟淡了不少，数据中心里的战斗却在升温——千问 App 公测即登顶 App Store 免费榜，大模型按 token 计费的模式让「token 消耗量」成为新的增长叙事。36kr 把阿里的这轮动作概括成一句话：不抢商品抢 Token。这篇文章拆解三件事：Token 到底是什么、阿里为什么换赛道、以及翻盘的概率有多大。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-07/2438e2fcd4d549ee.png)

## 先搞懂：Token 为什么成了「硬通货」

- **它是什么**：Token 是大模型处理文本的最小单位。英文约 0.75 个单词对应一个 token，中文一个汉字通常是 1~2 个。你向模型提问，输入和输出全部按 token 计量计费——相当于 AI 世界的电表读数。
- **它怎么变成钱**：模型厂商的核心收入形态是 API 按 token 收费，或云上的 MaaS（Model as a Service）订阅。token 调用量曲线，基本就是收入管线的先行指标。
- **它为什么是时代指标**：每个技术周期，巨头都在追一个数字——PC 时代是 PV，移动时代是 DAU 与时长，AI 时代大概率是日均 token 消耗量。阿里云曾公开披露其百炼平台 token 调用量半年增长超百倍；吴泳铭也多次把 token 提到「AI 时代核心经济指标」的位置。
- 直观点说：训练大模型像建发电厂，推理消耗 token 像全社会用电。电厂值多少钱，最终看电表转多快。你的每句话都会被模型拆碎、称重、计费——比菜市场精确多了。

## 从货架到算力：阿里为什么换赛道

1. **电商进入存量时代。** 中国网购用户已超 9 亿、渗透率见顶，拼多多与抖音电商持续分食份额，双 11 的 GMV 大战边际收益递减。货架逻辑的天花板肉眼可见。
2. **云 + AI 是第二曲线。** 阿里云长期是中国市占率第一的云厂商，AI 相关产品收入连续多个季度三位数同比增长，是财报里少数还在高速增长的板块。
3. **组织与资本重新下注。** 吴泳铭兼任集团 CEO 与阿里云 CEO，战略收敛为「用户为先、AI 驱动」；2025 年 2 月宣布未来三年投入超 3800 亿元建设云和 AI 基础设施，规模超过过去十年总和。
4. **外部催化。** 据多家媒体报道，苹果选择阿里合作，为中国市场的 iPhone 提供端侧 AI 服务，资本市场开始重新给阿里的 AI 故事定价。

一句话总结：电商是现金流，AI 是期权——阿里把期权的杠杆调大了。

## 三张牌：开源、算力、生态

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-07/bb403ae011b4f6d4.png)

- **第一张牌：Qwen 开源。** 通义千问系列在 Hugging Face 上的衍生模型超过 10 万个，是全球最大的开源模型族群，累计下载量以亿计。开源不直接赚钱，但它是生态获客器：开发者用惯了 Qwen，微调和部署自然倾向跑在阿里云上——开源当广告，云当收银台。
- **第二张牌：全栈算力。** 从平头哥的 AI 芯片，到 IDC 与云平台，到 Qwen 模型，再到淘宝、高德、飞猪、钉钉、夸克的应用矩阵，阿里是国内少有的「芯片—云—模型—应用」四层俱全的公司。token 的生产、计费、消费可以在体内闭环。
- **第三张牌：C 端入口。** 千问 App 的差异点在生态整合：一句话让高德规划路线、飞猪订机票、淘宝比价下单。字节有抖音的流量池，DeepSeek 有低成本与口碑，阿里的筹码是「服务闭环」——AI 不只聊天，还能干活。

## 翻盘的四道坎

1. **量涨价跌。** 国内大模型 API 打了一年多价格战，百万 token 的输出价格从几十元跌到几元甚至几毛钱级。调用量百倍增长 ≠ 收入百倍增长，这是「带宽悖论」的重演：流量涨了，单位流量收入跌了。
2. **资本开支黑洞。** 3800 亿砸向 IDC 与 GPU，折旧直接压在利润表上；高端 GPU 供应受出口管制影响，国产替代的性能与节奏仍有不确定性。算力是重资产游戏，烧钱周期以年计。
3. **入口之争不看首发冲榜。** 免费榜第一只是起跑线：豆包背靠抖音日活，DeepSeek 有口碑护城河。千问 App 必须证明生态整合是刚需而非演示视频——回想一下，多少首日登顶的应用，三个月后查无此人。
4. **开源到收入的闭环漫长。** 客户完全可以下载 Qwen 权重、用自己的机器或别家云部署。建立心智容易，把心智转化为云收入，中间隔着迁移成本、销售网络和价格谈判。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-07/74e1ebe55d865f4f.png)

1. **Token 是过程指标，不是结果指标。** 看一家 AI 业务的健康度，顺序应当是：收入与毛利 > 付费客户留存 > token 调用量。只报调用量、不报收入的叙事，先打个问号。
2. **判断翻盘与否，盯三个信号。** AI 带动的云收入占比与增速；Qwen 开源用户的付费转化率；千问 App 三个月后的月活与留存，而非下载量。别用电商 GMV 思维看这场仗，token 时代的「GMV」要拆成量、价、留存三个因子分别看。
3. **对从业者的启示。** 模型层大概率走向「少数闭源巨头 + 开源公共品」双轨，单点卷模型的窗口在收窄；token 单价持续下降意味着应用层边际成本在降——在别人修好的路上跑运输（应用、Agent、垂直场景数据），比再修一条路划算。

双 11 二十年教会市场一件事：抢到货架不算赢，货架上的东西持续卖出去才算。Token 之战，大概率同理。
