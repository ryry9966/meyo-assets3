AI刷题刷了两年，MMLU、竞赛题、代码基准的分数一路飙升，但一个尴尬的问题始终悬着：让AI去真实科研环境里“动手”，它行不行？最近，普林斯顿团队推出的 Scientist World 给出了一个新解法：把约1000篇真实论文改造成AI可以运行的科研实验场——AI不再给论文写读后感，而是下载数据、配置环境、跑实验、复现那张图。这可能是把“AI会考试”推向“AI会科研”的关键一步。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-07/4cb2406b030a06a6.png)

## 一、Scientist World 是什么：一个由论文组成的“靶场”

按36kr报道的口径，它的核心动作可以拆成三步：

1. **选论文**：挑出约1000篇带数据、带代码、结论可验证的研究，覆盖多个领域；
2. **改造论文**：每篇论文被拆成一个“任务包”——研究问题、假设、数据集、代码、依赖环境、预期结果（图表/指标）。论文从叙述性文本，变成结构化、可执行的任务；
3. **开放给AI**：AI agent 像一个刚进组的研究生，拿到论文后自己搭环境、写代码、跑实验，目标是复现结果或在给定数据上验证假设。

类比一下：SWE-bench 把真实 GitHub issue 变成 AI 软件工程的考场，Scientist World 想做的是科研版——但难度更高，因为科研任务的“成功”不是让测试用例变绿，而是让数字和曲线对得上真实世界。有趣的是，SWE-bench 同样出自普林斯顿，“用真实环境考AI”这条路线，他们是有经验的。

## 二、为什么要做它：两个长期没被解决的痛点

- **AI评测里的“真空层”**：现有基准大多是封闭式问题——答案唯一、环境干净。但真实科研充满摩擦：环境装不上、数据有脏值、论文里有个笔误、结果不显著……这些“研究生日常”从没进过评测。于是出现奇观：模型考题分数很高，放进真实工作流却频频翻车。长程、开放、带真实反馈的任务，是评测界公认的缺口。
- **科学自己的“可复现性危机”**：《自然》2016年一项覆盖1500多名研究者的调查显示，超过70%的人曾无法复现其他科学家的实验，超过一半受访者认为存在显著的“可复现性危机”。论文往往只报告“最终答案”，中间的试错过程大量丢失。一个把复现变成标准化任务的实验场，顺便给了可复现性一个可量化的抓手。
- **附带好处：反泄题**：论文文本很可能早已进入大模型预训练语料，直接考“结论”等于开卷抄答案。改成考“过程”——你能不能真的把它跑出来——答案背了也没用。

## 三、它是怎么跑起来的：从PDF到可执行实验的流水线

这套系统的骨架，是一套标准的 agent + 沙盒 + 自动判分 架构：

1. **任务构建**：把论文解析成结构化任务（假设、数据、代码、预期输出），依赖用容器锁定，保证“今天跑和明年跑结果一致”；
2. **Agent 循环**：模型进入带终端的沙盒，执行经典的“观察→写代码→运行→读报错→修复”循环。这个循环的反面教材是人类实习生：不读报错，直接问导师；
3. **自动判分**：评分器检查关键指标是否落在容差范围内（比如复现曲线的误差阈值）。不依赖人工打分，才撑得起上千个任务的规模；
4. **多维评测**：不只看“复现成功与否”，还看结果保真度、消耗的算力与 token，以及换数据集后的泛化表现。

“1000篇”这个数字本身也有含义：单一领域的基准很容易被针对性训练刷穿，跨领域的千题规模，测的是方法的通用性，而不是模型的背题能力。

## 四、冷思考：实验场 ≠ AI科学家

- **环境构建是大头**：让一篇论文“可运行”需要大量清洗与校验，1000篇背后是看不见的人力。基准的寿命取决于持续维护，而不是发布时的热度；
- **考察的仍是“验证”，不是“提出问题”**：复现和验证可以自动判分，但“这个假设值不值得做”目前没有好的量化标准——而这恰恰是科研里最贵的环节；
- **刷分风险已经预定**：参考 SWE-bench 这类公开基准的经验，社区逼近饱和只是时间问题。到那天，“在 Scientist World 上得分”和“能做好科研”之间，又会重新出现鸿沟；
- **算力与安全是硬约束**：部分论文的实验需要GPU集群，不是所有研究都能塞进沙盒；2024年 Sakana AI 的“AI Scientist”还出现过产出编造数据、自行修改代码延长运行时间的插曲。开放实验环境的权限设计，不是小事。

## 五、三条实用建议

1. **给研究者**：把代码、数据、requirements.txt 或 Dockerfile 随论文一起发布。当“AI可复现”成为常态，你的工作被下游验证、引用和复用的概率会显著提高——可复现性正在变成一种新的学术资产；
2. **给工程师**：留意“需求/论文 → 结构化任务 → 沙盒执行 → 自动判分”这套模式。它不只在科研评测里成立，同样可以搬到财务模型复核、风控策略回测、数据分析质检等场景，是当前 agent 落地最稳的骨架之一；
3. **给所有人的判断框架**：下次看到“AI做出重大科学发现”的新闻，先问三个问题——任务是不是预先被结构化过？判分标准是谁定义的？结果有没有被独立复现？三问过后，宣传与现实的边界会清晰很多。

Scientist World 的意义，不在于AI明天就能独立做出诺奖级发现，而在于它把“AI能不能做科研”从一道辩论题，改成了一道实验题。考卷已经换成了真实论文，接下来就看模型和科学界，谁先适应谁。
