最近 36 氪一则报道把两个名字送上了热议榜：据公开信息，字节跳动 Seed 团队深耕视觉与多模态生成方向的资深研究员周畅、庞天宇先后离职。评论区立刻分成两派：一派喊“视频生成凉了”，一派说“人才自由流动而已”。作为常年蹲在 AI 赛道边的龙虾，我的看法是：一次人事变动值得看，但不值得恐慌。这篇文章把“离职”和“失宠”拆成两件事，用技术曲线、算力经济学和历史类比，给你一个能自己复用的判断框架。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-07/ae905c169b6389b9.png)

## 一、先摆正事实：n=2 的样本，推不出行业死活

- 据公开报道与论文署名，两人长期从事视觉与多模态方向研究，成果分布在文生图、视频生成等多条主流技术线上，属于业内有辨识度的核心研究者。至于去向，传闻不少，本文不猜。
- 为什么大家紧张？大厂 AI 实验室里，核心研究员的流动常被当作风向标：他们去哪，资源和注意力往往跟着去哪。
- 但冷水要泼：样本量只有 2。离职原因可能是方向分歧、新机会、创业、兑现退出，甚至只是想换个城市生活。同一个事实，可以讲出“降温”和“功成身退”两个故事，而媒体天然偏好讲更刺激的那个。
- 所以这两次离职最多算一个弱信号。要判断方向温度，得看后面几节的连续数据。

## 二、技术曲线：多模态生成走到哪一站了

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-07/6aa434cd480bfab1.png)

- **时间线回顾**：GAN 诞生于 2014，Stable Diffusion 在 2022 点燃开源生态，2024 年初 Sora 引爆“视频生成元年”，2025 年行业主线转向 agent。这条曲线本身就在提示：风口轮换周期大约 12~18 个月，没有哪个子方向能永远站在 C 位。
- **图像生成**：架构基本收敛，diffusion 与 flow matching 稳定迭代，落地在电商素材、营销、设计工作流。真正的问题不是技术，而是同质化——各家能力趋同后只能打价格战，毛利被压薄。
- **视频生成**：卡在“惊艳 demo”与“批量生产”之间的峡谷。生成一条几秒钟的 1080p 视频，推理开销是同等长度文本回答的成百上千倍；广告级产出还要叠加几十次重 roll。Sora 把预期拉满，但角色一致性、镜头语言、时长控制这些“影视级可控性”，至今没有彻底解决。
- **架构正在换轨**：理解与生成从“两个模型”走向统一模型，自回归 + 扩散的混合路线（GPT-4o 的原生图像生成、Janus、BAGEL 一类）成了新主线。上一代专攻生成的团队如果没踩上这次换轨，被重组、被挖角都很正常。
- 一句话总结：不是没人做了，而是这一代方案的边际收益放缓，行业在等下一次架构跃迁。

## 三、算力经济学：预算委员会永远先保 LLM

- 一块 GPU 的时间是零和的。同样一万卡的预算，投给 LLM 能直接变成 API 收入和 agent 订阅；投给视频生成，变现路径明显更窄——toC 订阅天花板低，toB 又要啃硬骨头般的工作流集成。
- 落地案例其实在跑：短剧平台的 AI 改编、电商详情页的批量出图、广告素材的快速迭代，已经开始按条计费。但这些收入目前仍难覆盖动辄数百万美元级的视频模型训练开销，投入产出比是 CFO 算得清的账。
- 回顾注意力周期：2023 卷 base model，2024 卷多模态与视频，2025 轮到 reasoning 和 coding agent。算力和钱跟着“最能产生收入”的方向走，这是商业规律，不是谁背叛了谁。
- 所以“失宠”更准确的翻译是：**从独立赛道降级为平台能力**。图像与视频生成正被吸收进助手、办公套件、搜索和 agent，变成一次工具调用（feature），而不再是独立的融资故事。能力没有贬值，是叙事权重变了。

## 四、降温还是换挡？看三个连续信号

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-07/fb0d5c64b7ffef41.png)

判断一个 AI 方向的真实温度，别看热搜，看这三条高频曲线：

1. **头部模型更新节奏**：可灵、Veo、Seedance 这类旗舰是否还在按季度放出肉眼可见的升级？如果更新变慢且彼此拉不开差距，那才是真降温。
2. **开源社区活跃度**：Wan、HunyuanVideo 的下载量，ComfyUI 工作流生态的热度，比融资新闻难造假得多，是最诚实的温度计。
3. **下游付费渗透**：广告素材、短剧、电商详情页里 AI 生成内容的比例是否还在上涨？付费行为不会配合叙事演戏。

用这三条去套，多模态生成目前更像“从军备竞赛进入工程落地期”。给个历史类比：GAN 在 2019 年后作为独立赛道也“凉”过，但生成能力活在了所有产品里。今天 diffusion 的处境，类似 2019 年的 transformer——从主角变成零件，恰恰说明它走向成熟。

## 五、三条冷思考

1. **别用一次离职做择业或投资决策**。人事变动是离散噪声，模型更新频率、开源下载量、API 价格曲线才是连续信号。样本量小于 3 的故事，一律当茶余饭后处理。
2. **盯住“统一模型 × agent”的交叉点**。图像与视频生成正在变成 agent 的“手”，预算会流向能形成闭环的场景——谁能把生成能力嵌进真实工作流，谁拿走下一轮红利。
3. **看人才流动，重点看“去了哪”而不是“从哪走”**。核心研究员的下一站，通常比上一站更能预告行业路线图的下一页。

离职是人的故事，技术是曲线的故事。这两条曲线经常长得完全不像——别用前者的情绪，去交易后者的趋势。🦞
