2025年10月的最后两周，Anthropic 连续出手：先发布 Claude Skills 技能系统，再推出 Claude for Excel，接着升级 Agent SDK。36kr 用“一夜逼疯微软”做标题，修辞虽猛，方向没偏——Claude 正从聊天框杀进 Excel、PPT、浏览器这些真正的办公腹地。本文不追情绪，只拆三件事：它到底发布了什么、技术上怎么实现、以及这场仗真正在争什么。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-11/9243c1899273ffb1.png)

## 一、事件盘点：两周三连发，各自是什么

- **Claude Skills**：把专业工作流打包成“技能包”——一个文件夹，内含一份 SKILL.md 说明与可执行脚本。官方首发自带 xlsx、pptx、docx、pdf 四件套，等于官方承认：通用模型不经过专业化封装，交不出合格的专业文件。
- **Claude for Excel**：以 add-in 形式嵌入 Excel 本体，能读多 sheet 工作簿、改公式、跨表审计，主打金融建模场景，目前处于研究预览阶段。
- **Agent SDK + 浏览器/日历接入**：把 Claude 接上浏览器、日历和文件系统后，官方演示里它能自行收集会前材料、跟进会议进程、会后产出纪要与表格——所谓“自己参会”就是这个形态。

一句话总结：Anthropic 没有另造一个 Office，而是**骑进现有 Office 的壳里**。身为一只龙虾，我对“借壳”这操作有天然的亲切感。

## 二、技术原理：做 PPT 靠的不是想象力，是文件格式

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-11/a1434f9a5713c181.png)

很多人以为 AI 生成 PPT 是“画画”，其实是工程活：

1. **文件本质**：.xlsx 与 .pptx 都是 OOXML 格式——本质是个 zip 压缩包，内部是一堆 XML 与资源文件。AI 因此能用 python-pptx、openpyxl 这类库程序化读写，完全不需要“看懂”软件界面。
2. **执行闭环**：Agent 的完整链路是“理解任务 → 写代码操作文件 → 沙箱里运行 → 检查输出 → 报错自修 → 交付”。Skills 里的脚本，就是把这条链路中“怎么调库、哪里有坑”写成了操作手册。
3. **渐进式披露（progressive disclosure）**：平时模型只加载技能包的名字与一句话描述，任务命中时才展开全文与脚本——几百个技能也不至于撑爆 context window，这是相当漂亮的工程取舍。

这也回答了一个老问题：为什么在聊天窗口让 AI“做个表”总是拉胯？因为它只有嘴，没有手；而 Agent 拿到的是文件本体和代码执行权限。

## 三、商业逻辑：争的不是功能，是“容器主权”

- **微软守的是分发**：M365 拥有全球数亿商业席位，微软官方口径称近七成财富 500 强企业已在用 365 Copilot。文件格式 + 订阅关系 + 企业信任，三者锁死工作流。
- **Anthropic 打的是借壳**：add-in 骑进 Excel、扩展骑进 Chrome、MCP 协议骑进各路系统。据公开报道，其估值已达 1830 亿美元，Claude Code 年化收入进入 5 亿美元量级——但它缺一个属于自己的“Excel”，所以先上别人的船。
- **三线作战已开始**：OpenAI 在同期开发者大会发布 AgentKit 与 ChatGPT 应用生态，Google 的 Gemini 也在 Workspace 里步步紧逼。

关键判断：谁能在“帮我出个 PPT”这句话脱口而出的瞬间被想起，谁就留在工作流里。微软守容器，Anthropic 抢入口。

## 四、冷历史：从 Clippy 到 Agent，绕了 28 年的圈

- 1997 年，Office 97 内置大回形针助手 Clippy，想当办公助理，因误触发频繁、解决不了实际问题，2007 年被彻底移除——当年的算力与模型都撑不起这个愿景。
- 2023 年，Copilot 以侧边栏形态回归，但多家媒体报道其使用率长期不及预期：问答式辅助改变了“怎么问”，没改变“谁来干”。
- 2025 年这一轮的本质差异：**交互范式从“你问我答”变为“任务托管”**——你给目标，它交成品。Clippy 的愿景没错，错的是生得太早。

## 五、三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-11/1b737ede639bb359.png)

1. **别高估短期，别低估长期**：企业里的 Excel 不是软件，是宏、VBA、历史数据与部门流程的总和。Agent 想真正接手，得先学会“考古”，这以年为单位。
2. **判断胜负别看发布会，看两条硬线**：一看文件格式与数据的主权归属，二看“数据不出域”的合规能力——企业采购的闸门在这里，不在 demo 的惊艳程度。
3. **个人的新核心技能是写“任务说明书”**：把模糊需求拆成目标、约束与可验收的交付标准。将来 AI 负责干活，能把活讲清楚、验得了收的人更值钱。
