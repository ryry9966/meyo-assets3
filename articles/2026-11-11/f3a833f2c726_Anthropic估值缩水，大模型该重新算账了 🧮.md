36kr 报道把一个信号顶上热搜：Anthropic——被视作"OpenAI 之外第二极"的大模型公司，估值出现缩水迹象。表面看是一家公司的融资新闻，实际上它牵动的是全球大模型资产的"定价锚"。锚一动，水下的船都跟着晃，国内同行首当其冲。这篇就把四件事拆开讲清楚：估值怎么缩的、为什么缩、压力怎么传导到国内、以及国内公司手里还有哪些牌。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-11/b93bdddfe1cadf99.png)

## 一、先看事实：缩的是"倍数"，不是收入

时间线（据公开报道）：

- 2021 年成立，创始团队出自 OpenAI，主打"安全对齐"技术路线
- 2023–2024 年：亚马逊累计投入约 80 亿美元，谷歌深度绑定，估值从 40 亿美元量级一路抬升
- 2025 年 3 月：融资 35 亿美元，投后估值 615 亿美元
- 2025 年 9 月：融资 130 亿美元，投后估值 1830 亿美元
- 之后：老股转让的二级市场价格较官方估值出现折价，新一轮融资谈判里投资人明显更挑剔

关键在于：Anthropic 的基本面并没有崩。Claude 的收入仍在高速增长，年化收入据公开报道已达数十亿美元量级。缩水缩的不是收入，而是"每一美元收入值多少钱"——也就是估值倍数。一级市场估值是谈出来的，二级市场老股价格是真金白银撮合出来的；两者出现裂口，通常意味着市场正在重新定价。

## 二、为什么缩：三重挤压

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-11/e15fdc96b9accc9e.png)

1. **收入倍数回归**。以 1830 亿美元估值、年化收入约 50 亿美元粗算，PS 倍数仍在 30 倍以上；而成熟 SaaS 公司通常只有 5–15 倍。利率环境和"AI 溢价"退潮，倍数自然向现实回归。
2. **算力吞金**。模型层有个结构性问题：算力从云厂商租和买，训练一次 frontier 级模型的成本逐代指数上升，推理成本又随用户量线性膨胀。收入越多，算力账单越大，毛利率被上游抽走一大块。
3. **竞争与开源**。OpenAI 的先发生态在前，开源模型（Llama、DeepSeek 等）把 API 价格持续往下压，"我更强所以我更贵"的能力溢价越来越难维持。

一句话总结：市场没有否定"AI 有用"，只是在算术层面追问——这门生意的单位经济模型到底成不成立。

## 三、压力如何传导到国内大模型公司

传导路径大致有四条：

1. **估值锚下移**。国内头部创业公司（智谱、月之暗面、MiniMax 等）过去的融资叙事大多是"对标 OpenAI/Anthropic 的折价版"，估值普遍停在几十亿美元量级。美国锚一动，对标故事就得重写，再融资时的谈判空间被直接压缩。
2. **价格战压低收入端**。2024 年 5 月，DeepSeek-V2 把百万 tokens 输入价格打到 1 元级，引发全行业 API 降价潮。海外 Claude API 的单价和国内不在一个数量级，国内公司单位收入的天花板天然更低。
3. **变现结构差异**。美国市场有 ChatGPT Plus 这类月费 20 美元的 C 端订阅基本盘；国内 C 端付费率低，ToB 以定制项目为主，毛利薄、回款慢。收入质量本就有差距，倍数再一压缩，两头受挤。
4. **算力成本**。高端芯片采购受限、国产算力适配需要额外工程投入，训练 frontier 级模型的门槛客观上更高。这部分约束短期改不了，只能靠效率消化。

## 四、回调不是出清：被倒逼出来的三条活路

估值回调同时也是一次压力测试，逼着公司换活法：

- **卷效率替代卷算力**。DeepSeek-V3 论文披露，正式训练的 GPU 租金约 558 万美元（不含全部研发与实验开销），证明算法与工程效率可以部分对冲算力堆叠。国内团队在效率路线上有真实积累。
- **开源换生态**。open weights 换开发者心智与影响力，再通过企业版、托管服务变现，这条路径已经被验证过。
- **价值向应用层迁移**。模型层毛利变薄，价值就往下游走：编程助手、Agent、垂直行业私有化部署。模型降价对应用层反而是红利——token 便宜了，过去跑不起的 Agent 场景才跑得起来。

## 五、三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-11/067da6aea43efb83.png)

1. **看估值先看单位经济模型**。毛利率、单 token 推理成本、用户留存，比参数规模和榜单排名诚实得多——榜单像单元测试，跑通了不代表产品能活。
2. **区分"倍数压缩"和"需求证伪"**。目前是前者：全球 token 消耗量还在指数级增长，需求没有消失，变的是市场愿意为同样收入支付的倍数。
3. **估值寒冬往往是应用层的春天**。模型能力外溢、价格下行，绑定真实场景、现金流健康的应用公司，反而是这一轮最容易活下来的物种。

大模型的下半场，比的不再是"谁的估值高"，而是"谁的账算得过来"。
