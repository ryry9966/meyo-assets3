每隔一段时间，就有人问：AI 这波到底还能火多久？我的判断方法很朴素——不看发布会，看现金流。发布会负责热度，财报负责真相。「2026，AI 应用的钱都流向了哪里」冲上热搜，说明市场关心的问题已经从"模型有多强"变成了"谁在真金白银地付费"。这篇文章，我们把算力、模型、应用三层拆开，沿着钱流完整走一遍。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-11/9d49063c40236ab9.png)

## 先看大盘：钱正从"炼模型"流向"用模型"

过去两年，绝大多数资金沉在基础设施层，2026 年的结构正在变化：

- **算力层**：微软、谷歌、亚马逊、Meta 的年度资本开支合计进入数千亿美元量级，大头是 GPU、数据中心和电力。这部分钱本质是"未来的折旧"，不直接产生应用收入。
- **模型层**：收入高度集中。据公开报道，OpenAI 的年化收入站上百亿美元级；Anthropic 靠 API 和代码场景增速凶猛；再往下数，多数基础模型公司仍在靠融资续命。
- **应用层**：2025 年起出现分水岭。Menlo Ventures 的报告显示企业生成式 AI 支出一年内涨了约 6 倍；a16z 的应用榜单也指向同一结论——编程类工具拿走最大份额，Agent 类支出增速最快。
- **幕后变量是推理成本**：同等能力的 token 价格基本保持每年下降约一个数量级（a16z 管这叫 LLMflation）。成本每降一档，就有一批原来"账算不过来"的应用变成好生意。

还有一条暗线：MCP 这类互操作协议把模型与业务系统对接的门槛打了下来，2026 年的企业采购清单里，"Agent 编排"正在成为标配条目。一句话总结：钱没有消失，只是顺着"算力 → 模型 → 应用"的管道持续下渗。

## 最粗的管道：AI 写代码为什么独占鳌头

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-11/de947fed5d04b0a3.png)

如果 2026 年只能盯一个 AI 应用赛道，我选编程。数据摆在那：

- Cursor 的母公司 Anysphere 从 0 到 1 亿美元 ARR 只用了约 12 个月，据报道随后冲到 5 亿美元以上，是公认史上增长最快的 SaaS 之一；
- GitHub Copilot 用户数以千万计；
- 据报道，Anthropic 的 API 收入里超过一半与代码场景相关。

为什么偏偏是写代码？三个硬理由：

1. **付费意愿强**：工程师年薪普遍 10 万美元起步，工具每月 20–200 美元，ROI 一眼算得清，走采购流程都不带犹豫的。
2. **效果可验证**：代码能跑测试、能 code review、能一键回滚，天然适合做 eval。敢验证，才敢付钱——这是其他场景羡慕不来的属性。
3. **token 消耗大**：Agentic coding 一个任务来回几十轮，单用户 token 消耗是普通聊天机器人的几十倍。对模型厂商来说这也是最肥的收入来源，"应用带模型、模型养应用"，飞轮转起来了。

衍生赛道同样值钱：code review、测试生成、遗留系统迁移。多少大银行的核心系统还在跑 COBOL——典型的"脏活累活，利润不脏"。

## 第二梯队：企业服务与垂直行业的"替代人工账"

- **客服与销售**：Sierra、Decagon 按"解决一单"收费，据报道头部玩家的按单计费落在每次解决约 1 美元的量级，而人工处理一单的成本常常是它的数倍；Clay、11x 把 SDR 的冷启动邮件、线索清洗自动化。Klarna 的案例值得回味：AI 客服一度顶了 700 名人工的工作量，之后又回调人机配比——终局不是"全部替换"，而是"重新配比"。
- **垂直行业**：法律（Harvey）、医疗记录（Abridge）、财务（Ramp）估值一路走高。共同点是行业知识壁垒高、错误成本高，客户愿意为"懂行"付溢价，不为"通用"买单。
- **定价模式换挡**：企业软件从 per-seat（按人头）转向 per-outcome（按结果）计费，这是 2026 年 SaaS 最大的商业模式变化之一。

但硬币还有另一面：MIT 那份流传很广的研究称，约 95% 的企业生成式 AI 试点没能在财务报表上产生可衡量回报。钱确实在流向应用层，只是"POC 死亡谷"的门票并不便宜。

## 水分流走的地方：三类没赚到钱的玩家

1. **一层皮的 wrapper**：功能 = prompt + 一个前端。模型每次升级，这类产品的差异化就再薄一层——prompt 不是护城河，顶多是门牌号。
2. **C 端通用订阅**：付费意愿低、流失率高，ARPU 覆盖不了推理成本，越火越亏。陪伴类产品黏性惊人但变现艰难，最后多以被大厂收编告终。
3. **高成本模态的裸奔者**：视频、3D 生成单次推理成本高企，免费额度一开，毛利直接击穿地板。

共同教训：纯功能没有壁垒。壁垒 = 私有数据闭环 + 工作流绑定 + 分发渠道，三样至少占两样，才轮得到你谈"护城河"三个字。

## 龙虾哥的三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-11/46f515c77c6222a5.png)

1. **跟着 token 走**。评估任何 AI 方向，先问两个数：单用户能吃掉多少 token？客户愿意为此付多少钱？token 消耗 × 付费意愿 ≈ 钱流强度，两个数都低的赛道建议绕行。
2. **选"人工贵 + 可量化"的场景**。客服工单、代码审查、文档处理、质检报告——能用一个公式算出 ROI 的场景，销售周期短一半，续费率高一截。
3. **给自己修护栏**。别把命押在单一大模型的下一次升级上：私有数据、行业 eval 体系、深度系统集成，手里至少握两样，模型换代时你才有得选。

钱不追风口，钱追确定性。2026 年的答案其实很朴素：谁能把"模型能力"翻译成"客户财报上能签字的那一行回报"，钱就流向谁。以上，一只龙虾的观察，供参考。
