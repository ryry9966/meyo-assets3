最近一条 36kr 的报道在圈子里刷了屏：Anthropic 估值缩水，压力传导到国内大模型公司。表面看，这只是一次海外 AI 头部公司的估值波动；实际上它更像一根插在整个赛道里的温度计——量的是大模型行业的整体水位，而水位下降，会顺着融资链条一路传到国内每一家大模型公司门口。这篇文章拆三件事：估值是怎么缩的、压力是怎么传导的、国内公司现在应该盯什么。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-11/b006666cbf545116.png)

## 一、先搞清楚：估值缩水缩的到底是什么

很多人看到“估值缩水”第一反应是“股价跌了”，这是个误解。Anthropic 这类公司并未上市，它的估值来自最近一轮一级市场融资；所谓缩水，通常体现在二级市场（secondary 老股转让）出现折价、新投资人不愿按上一轮价格接盘。机制拆开看有三层：

1. **收入倍数回归**。AI 公司过去拿到的估值普遍是 30–50 倍 ARR（年度经常性收入），而传统 SaaS 公司一般是 5–15 倍。倍数高低反映的是市场对未来增速的信心，信心一旦松动，倍数先掉。
2. **成本结构刚性**。前沿模型一次训练成本在亿美元量级，推理成本随用户量线性增长，但 API 定价却因竞争持续下探，毛利长期承压。
3. **现金流依赖**。头部模型公司普遍大幅亏损，靠云厂商的战略投资维持算力开支。这种“投资换算力、算力换收入、收入撑估值”的循环，任何一个环节降温，整体估值都会被重新定价。

一句话总结：缩的不是账面数字，是市场对“收入增长能不能追上成本增长”的信心。

## 二、传导链路：三层管道，一层比一层实

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-11/4cccf464c5e33600.png)

硅谷的估值波动，为什么会传到国内？传导链路大致三层：

1. **估值锚定效应**。投资机构给国内大模型公司报价时，普遍拿海外头部公司的最新估值做 benchmark。锚往下移，所有参照它的报价跟着下移——这是传导最快的一层。
2. **资金供给收缩**。过去两年投 AI 的一级市场资金里，美元基金占相当比例。海外 AI 资产估值下修，LP 对 AI 板块的回报预期下调，新基金募资变慢，能流向国内早期项目的钱随之变少。
3. **退出预期重估**。一级市场赚的是轮次差价，最终退出靠 IPO 或并购。如果对标公司的公开市场估值中枢下移，后轮投资人会担心“进得贵、出得贱”，决策周期明显拉长。

打个比方：上游把阀门关小，下游水压下降有先后，但一定会到。国内公司的体感通常滞后一到三个季度。

## 三、压力落到头上：国内公司的烧钱曲线还没走完

传导过来之后，具体压在哪几个位置？

- **收入侧**：国内 API 价格战打了两年多，主流模型的 token 单价降了一个数量级，收入靠“量”补“价”；ToC 订阅付费率仍然偏低；ToB 私有化部署的毛利又被定制化交付的人力吃掉一块。
- **成本侧**：高端算力采购受限，国产芯片需要额外的适配工程，训练成本折算下来并不占优，推理侧同样受影响。
- **竞争侧**：DeepSeek、Qwen 等开源模型持续逼近闭源效果，直接压低了闭源 API 的定价上限——开源越强，闭源越难靠“模型领先”收溢价。
- **融资侧**：新一轮融资节奏放缓后，公司只有两条路：要么接受大厂投资、深度绑定生态，要么尽快把经营性毛利做正。

也不必全盘悲观，国内有三个差异点：

1. 应用层和场景生态丰富，模型能力“最后一公里”的变现路径更多；
2. 制造、零售、金融等行业的数据沉淀和付费意愿正在起来；
3. 工程侧的成本优化——蒸馏、量化、KV Cache 优化——属于全球第一梯队。这点像龙虾：壳不必最华丽，肉得扎实。

## 四、历史参照：挤泡沫挤掉什么、留下什么

2000 年互联网泡沫是最常用的参照系：

- **死掉的**：靠概念融资、没有真实收入的公司；
- **活下来的**：现金流模型健康、需求真实的公司。Amazon 当年市值跌掉九成后慢慢爬回来，Google 在泡沫退去后靠搜索广告确立商业模式；
- **外溢资产**：泡沫期铺设的光纤主干网，后来以极低价格支撑了整个 Web 2.0 时代。

映射到今天：GPU 集群和数据中心就是这一轮的“光纤”。即使部分模型公司被出清，算力基础设施和真实的企业需求大概率会留下来。所以判断的关键从来不是“泡沫破没破”，而是“谁的成本曲线能被真实收入追上”。

## 五、三条冷思考：退潮期的作业怎么交

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-11/bfe56f625621df53.png)

1. **用新倍数重做财务模型**。别拿 30–50 倍 ARR 的旧假设做预算，按 10–15 倍甚至更保守的倍数倒推融资额，把现金跑道（runway）从 12 个月拉到 24 个月以上。融资窗口关闭之前，不会有人提前通知你。
2. **收入质量优先于收入规模**。盯三个指标：毛利率、净收入留存（NRR）、大客户集中度。一笔靠补贴和人情换来的大单，在下一轮尽调里反而可能扣分。
3. **层级错位竞争**。基础模型层的战争由巨头和极少数玩家打，应用层和垂直行业仍有大量空位。护城河不是“我的模型更强”，而是“我有场景数据闭环 + 行业 know-how + 交付能力”。

估值缩水不是行业判决书，而是一份提前送达的压力测试报告：它告诉所有人，下一阶段的考题从“讲故事”换成了“算得过来账”。按新考纲提前复习的公司，往往在退潮时反而捡到更多滩涂。
