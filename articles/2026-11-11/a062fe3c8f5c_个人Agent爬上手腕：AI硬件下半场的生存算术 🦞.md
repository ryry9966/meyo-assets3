最近一条科技新闻，信号意义大于新闻本身：据36氪报道，定位「个人Agent」的应用 Muse 登陆 Apple Watch。注意这个动作的形状，没有发布会，没有新手环，一款 AI 助手直接寄宿进一块已经戴在几百万人手腕上的设备。过去两年，AI 硬件创业公司排队造「下一代iPhone」，Humane、Rabbit 起了个大早赶了个晚集；如今风向调头，Agent 们开始往成熟硬件里钻。手腕凭什么值钱？AI 硬件还剩几条路能活？老规矩，先剥壳再吃肉。

## 先剥壳：个人Agent到底是什么

聊天机器人是「你问它答」，Agent 的核心是「感知—规划—行动」的闭环。拆开看是三层能力：

1. **记忆层**：把你的日程、偏好、习惯存成可检索的上下文。主流做法是 RAG——个人数据切块、向量化入库，用时检索拼进提示词。
2. **执行层**：通过 API / App Intents 调用日历、消息、地图等服务，替你「动手」而不只是「动嘴」。
3. **感知层**：心率、位置、睡眠、运动等传感器信号，让助手知道你现在在哪、状态如何。

举个例子：你抬腕说「我快迟到了」，Agent 读完日历、路况和你的步速，直接改签到、给对方发条消息、把会议顺延十五分钟。注意，是替你做完，不是给你一份建议清单。主动性，正是它区别于上一代语音助手（听懂但只回话）的分水岭。

## 为什么是手腕：被低估的「传感器 + 微交互」入口

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-11/db6cd79504b7d63d.png)

- **贴身程度**：手机在兜里，手表在脉搏上。心率、血氧、睡眠、定位全天候在线，这是 Agent 做个性化推断最便宜的信号源。
- **微交互经济学**：手机交互以分钟计，手表以秒计，抬腕三秒说一句话、震动一下回一条，打断成本低。Agent 的高频轻量服务天然适配这个形态。
- **约束也在同一块表上**：Apple Watch 电池只有 300mAh 量级，屏幕一英寸多，本地算力有限。所以这类产品几乎是同一套架构：手表负责唤醒、收音、显示和传感器采集，重计算交给云端大模型，中间靠手机转发。延迟、耗电、弱网，每一样都是工程硬骨头。
- **平台宿命**：苹果用 App Intents、Siri 权限、健康数据授权把守大门。第三方 Agent 能碰到什么数据、能替用户执行到哪一步，全看平台脸色。

## 上一波为什么摔了：Humane 和 Rabbit 交过的学费

- **Humane AI Pin**：699 美元外加月订阅，无屏幕、靠激光投影交互，实测又烫又难用；2025 年初以约 1.16 亿美元把资产卖给 HP，而它此前融资超过 2 亿美元，教科书级的价值毁灭。
- **Rabbit R1**：199 美元卖出了十万台量级，但主打的大动作模型 LAM 被实测打回原形，体验远不及发布会视频。
- **共同死因不是「AI 不行」，而是产品逻辑错了**：让用户花几百美元，买一台只能完成手机两成功能的设备。这笔「新形态税」，没人愿意交。
- **反例同样醒目**：Meta 与雷朋合作的智能眼镜借用成熟太阳镜形态，加上摄像头和音频，累计卖出数百万副；Apple Watch 本身就是「成熟形态 + 差异化传感器」的赢法。结论很朴素：硬件要成立，形态得先独立解决一个任务（遮阳、看时间、听歌），AI 是加分项，不是购买理由。

## 各寻出路：AI硬件的四种活法

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-11/5ca73c728b4d35b5.png)

1. **寄生路线**（Muse 这类）：不做硬件，直接上架应用商店，分发成本趋近于零。但命脉握在平台手里——抽成、权限，以及随时可能被官方功能收编的风险，业内戏称被「Sherlocked」。
2. **依附成熟形态**：往眼镜、耳机、手表这些已验证品类里塞 AI。风险最低，但拼的是供应链和品牌，创业公司很难挤上牌桌。
3. **垂直专用件**：挑手机做不好的窄场景，会议录音吊坠（Limitless）、AI 陪伴挂件（Friend，99 美元）、儿童 AI 玩具。逻辑是场景够专，才值得用户多带一件东西。
4. **平台级豪赌**：试图定义下一代入口，即 Humane 和 Rabbit 当年的野心。赌赢定义十年，赌输烧光融资，四种活法里方差最大。

无论走哪条路，商业账本都绕不开三笔：硬件 BOM 成本、获客成本、订阅留存。纯硬件毛利薄，所以大家最终都在赌订阅——Agent 的价值要靠长期服务兑现，这恰好是软件的节奏。

## 冷思考：手腕上的 Agent 要过三关

- **隐私关**：位置 + 健康 + 对话记录三者叠加，画像精度远超手机。数据放端侧还是云端、能否一键导出，直接决定用户信任。苹果 Private Cloud Compute 和端侧小模型（约 30 亿参数量级）代表的「数据不出端」思路，会变成行业标配压力。
- **平台关**：苹果自己在推进 Apple Intelligence 和 Siri 改造，官方能力每前进一步，第三方 Agent 的空间就被压缩一格。寄生者要么做平台做不了的跨服务编排，要么等着被收编。
- **体验关**：主动性是双刃剑。聊天答错一句无伤大雅，Agent 替你订错一张机票就是事故。哪些动作可以直接做、哪些必须先过目，这些交互细节比模型参数更决定留存。

最后三条带走的干货：

1. **评测 Agent 看任务闭环，不看参数**：它能否从头到尾替你完成一件具体的事（改签、订位、总结一场会），完成率多少，比「接了哪个大模型」重要得多。
2. **盯紧个人数据的所有权**：你的记忆和上下文存在谁的服务器上、能否导出迁移。换产品搬不走记忆，等于被锁死，这层数据才是 Agent 时代的真护城河。
3. **给 AI 硬件公司做体检，先量「形态税」**：它是「成熟形态 + 一个差异化传感器」，还是「为了 AI 重新发明一台设备」？后者请默认它还要先烧三年钱。
