2025 年以来 AI 圈最耐人寻味的一幕：一家从没办过融资发布会、官网朴素到极点的公司，估值传闻一路被抬到 1500 亿元量级，头部机构排队想把钱送进去。36kr 的报道《1500 亿，机构抢着给 DeepSeek 送钱》说的就是这件事。创业公司的常见剧本是“拿不到钱”，DeepSeek 的剧本却是“钱拿不过来”，大概是最幸福的烦恼之一。这篇拆三个问题：机构在抢什么？它为什么此刻要钱？1500 亿到底贵不贵？

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-04/8e6196fe0532e0ad.png)

## 01 事件线：一家“从不缺钱”的公司开了门

- **2023 年 7 月**，量化巨头幻方量化内部孵化出深度求索（DeepSeek），创始人梁文锋。幻方此前自建“萤火二号”超算集群，公开报道称囤了约一万张 A100，在国内大模型创业潮里属于少有的“先有卡、后有公司”的选手。
- **2024 年 5 月**，V2 发布，API 定价打到同行的几十分之一，第一次让全行业讨论“价格战”；12 月底，V3 发布，论文披露全部训练约 278.8 万 H800 GPU 小时、折算成本约 557 万美元，只有同期海外头部模型的零头。
- **2025 年 1 月**，R1 发布，用强化学习把推理能力做到对标 o1，App 冲上多国下载榜第一；随后英伟达单日市值蒸发近 6000 亿美元、跌幅约 17%，成为 AI 商业史上的标志性事件。
- **2025 年年中起**，多家媒体报道公司首次考虑接受外部融资，估值传闻从百亿美元级一路抬升，阿里巴巴、国家级基金等名字出现在意向名单中。截至目前公司未官宣，具体条款以官方披露为准。
- 关键在于性质变了：过去是幻方“全资输血 + 不着急赚钱”，现在第一次向外部资本开放股权。这不只是一次融资事件，更像一个信号，前沿模型竞赛进入了“资本开支决定上限”的阶段。

## 02 机构抢的是什么：三层稀缺性

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-04/2d0a95624df571b0.png)

贵的不该是流量，而是稀缺性。拆开看有三层：

1. **工程效率的稀缺。** V3/R1 背后是一整套省钱组合拳：MoE（混合专家）架构让每个 token 只激活约 1/18 的参数；MLA 把 KV Cache 压缩了一个数量级，推理显存大幅下降；再叠加 FP8 混合精度与底层算子优化。同样的能力，用别人几分之一的算力烧出来，这套方法论本身就是资产。
2. **能力路径的稀缺。** R1 证明了推理能力可以主要靠强化学习（GRPO 算法 + 规则化奖励）自主涌现，不依赖海量人工标注的思维链数据。全球多个团队在开源社区复现了这条路线，它已成为开源推理模型的事实参照系。
3. **生态位置的稀缺。** 权重以 MIT 协议开放，允许商用与蒸馏。云厂商部署、端侧本地化、开发者微调，全链条都在用。某种意义上，它成了全球开源 AI 的“默认底座”之一。

一句话总结：机构买的不是当下的收入报表，而是“低成本逼近前沿”的方法论 + 已经铺开的生态位，两者叠加成一种稀缺资产。

## 03 为什么此刻要钱：推理时代的算力账单

- **训练贵，推理更贵。** R1 这类推理模型会先输出生成长长的思维链再给答案，单次请求动辄数千上万 token，成本是普通对话模型的几倍到几十倍。调用量一涨，GPU 就是吞金兽。幻方的量化主业能输血，但量级撑不起全球规模的推理集群。
- **看同行就知道水位。** OpenAI、xAI、Anthropic 在 2025 年都以数百亿美元级的融资或算力承诺扩军。前沿模型的牌桌，入场费已是十亿美元起步，且越往后越贵。
- **钱的去向可以推测。** 据公开报道，融资讨论与下一代模型训练、国产算力适配基本同步。合理推测：钱进来，大部分最终会变成卡和电，而不是办公楼和营销预算。
- 换句话说，这不是“缺钱花”，而是“要打下一仗”。推理需求指数级增长时，谁先囤够算力，谁的服务稳定性和迭代速度就有底气。

## 04 1500 亿贵不贵：三个估值锚

- **锚一：比价。** OpenAI 估值传闻在 3000 亿美元级，Anthropic 已到千亿美元级，国内同行普遍在数十亿美元档。若按约 200 亿美元（1500 亿元）理解，DeepSeek 在国际第一梯队里不算突兀，在国内则是断层领先。
- **锚二：稀缺性溢价。** 全行业找不出第二家同时具备：前沿能力、全面开源、极致成本、无外部资本依赖。稀缺资产在一级市场天然有溢价，这直接解释了机构“排队送钱”的场面。
- **锚三：风险折价。** 开源削弱了卖 API 的定价权，能力护城河要靠持续迭代来维持；商业化动作克制，收入体量尚未成为故事主线；芯片供给与供应链存在外部不确定性。理性的报价必须给这些因素打折。
- 结论：1500 亿不是“它值多少”的标准答案，而是多方博弈后“能成交”的价格。对机构而言，错过头部筹码的成本，往往比买贵一点的成本更高，这是一级市场真实的博弈结构。

## 05 三条冷思考：热闹之外看什么

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-04/6809786c6439eb23.png)

1. **融资 ≠ 赚钱。** 估值反映的是稀缺性预期，不是利润。判断任何一家 AI 公司，优先看 API 调用量、企业客户续约率这类硬指标，而不是新闻里的金额数字。
2. **开源红利先落袋。** 对开发者和中小企业，开源权重 + 低价 API 是实打实的成本红利。与其追热点概念，不如先把自家业务的 AI 成本降下来、把场景跑通，这才是这类新闻里普通人能直接兑换的部分。
3. **警惕“送钱”叙事外溢。** 一级市场资金向少数头部集中是常态，不代表行业普遍繁荣。二级市场上遇到各类“DeepSeek 概念”时，多问一层：这家公司有没有真实订单、真实技术关联，还是仅仅贴了个标签？

热闹留给机构，确定性留给看懂机制的人。
