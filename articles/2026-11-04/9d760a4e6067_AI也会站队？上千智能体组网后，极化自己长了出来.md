最近，据 36 氪等媒体报道，清华大学研究团队在 Nature 旗下子刊发表了一项在技术圈刷屏的实验：研究者把上千个由大语言模型（LLM）驱动的智能体放进同一个社交网络，不布置任何“你要与谁为敌”的指令，让它们像真实用户一样发帖、评论、转发。跑着跑着，群体自发分裂成了观点对立的阵营——观点极化作为一种涌现现象出现了。在传统社会科学里，极化要靠问卷和访谈一点点测；现在，它在一个数字沙盘里自己长了出来。这件事值得认真拆解：实验做了什么、极化为什么会出现、边界在哪、我们能带走什么。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-04/d0acdabfe70b0664.png)

## 实验长什么样：一个会发帖、会取关的数字社会

这类研究属于“社会模拟”（social simulation），可以理解为给社会动力学装了一个可重跑的沙盘：

- **规模与载体**：上千个 agent，底层各自接大语言模型，每个 agent 拥有独立人设、记忆和社交关系列表；
- **行为接口**：agent 能发帖、评论、转发、关注与取关，看到的“信息流”由类似推荐机制的模块分发；
- **观点测量**：定期对争议议题做立场探测，观察全体观点分布随时间的变化——是从单一众数（大家差不多）变成双峰（两派对立），还是碎成多个簇；学术上常用类似 Esteban–Ray 极化指数的指标来量化；
- **关键设计**：没有人写“意见不同就拉黑”的规则，也没有人指定阵营，站队完全是交互的产物。

谱系上这并不突兀：2023 年斯坦福的 Generative Agents 用 25 个 agent 搭了个虚拟小镇，已经能复现“派对上传八卦”这类现象；此后开源社区把模拟规模推到几十万、上百万 agent。这次研究的差异点在于聚焦**观点动力学**——看态度如何分化，而不只是行为是否逼真。

## 极化为什么会“长出来”：三个正反馈引擎

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-04/f6bf55e77f6c23c6.png)

涌现不等于无因。拆开看，至少有三股力量在同向叠加：

1. **同质连接（homophily）**：物以类聚是社交系统的默认参数。agent 倾向与观点相近的对象互关，相似节点之间的边不断加粗，跨派联系越来越稀薄，网络悄悄碎成几个社区；
2. **从众与讨好偏差（sycophancy）**：对齐研究中被反复记录的现象——RLHF 训出来的模型有明显顺从倾向。当信息流里某种声音占多数，agent 会不自觉向它漂移。这是对齐训练的副作用，在这个场景里成了极化的燃料；
3. **注意力正反馈**：热门内容获得更多曝光，更多曝光带来更多附和与转发，于是更热门。像麦克风怼着音箱，一点底噪被放大成啸叫。

数学上这叫**对称性破缺**：初始状态只有微小的随机涨落，正反馈把它逐步放大，最终把系统锁进两个（或多个）稳定阵营。极化不需要阴谋家，只需要“同好 + 正反馈 + 足够多的轮次”。

## 老模型 vs 新实验：这次到底新在哪

观点动力学（opinion dynamics）不是新领域，对比一下才看得清增量：

- **经典数学模型**：DeGroot 模型（1974）里观点是标量，个体做加权平均，结论是必然收敛到一致；Hegselmann–Krause 有界置信模型（2002）加上“差距太大就不听”的阈值，才会分簇；更早的 Schelling 隔离模型（1971）证明，只要每人对邻居有轻微的同质偏好，整体就会走向彻底隔离。共同点：极化的形状，很大程度上取决于你事先塞进什么假设；
- **LLM 智能体实验**：观点藏在自然语言里，行为由模型生成，没有人预设阈值和规则，站队是交互的副产品——这正是“涌现”二字的分量所在；
- **方法论增量**：沙盘可以重跑、可以做反事实实验——换一套推荐算法、改一种网络拓扑、注入一批跨派信息，观察极化指标怎么动。相当于给社会假设做 A/B test，成本比真实平台实验低几个数量级。

## 边界在哪：四个别急着外推的理由

刷屏式报道容易让人把模拟结果直接翻译成“人性如此”。在得出大结论之前，有四个技术上的保留项：

- **镜像问题**：LLM 用人类语料训练，它表现出的极化可能只是人类偏见的复读，而非新机制。显微镜和被测样品，是同一种材料；
- **保真度**：agent 没有真实利害（不会丢工作、不会破财），没有具身经验，平台机制也被大幅简化，而真实社交平台的推荐与审核逻辑复杂得多；
- **敏感性**：结论可能对 prompt 写法、temperature、基座模型版本敏感。换一个模型重跑还成立吗？稳健性检验是这类研究的硬门槛；
- **外推风险**：1000 个 agent ≠ 数亿异质的真实用户。从沙盘到现实，中间必须用真实平台数据做校准，否则只是“讲得通的故事”。

## 冷思考：三条带得走的东西

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-04/bef363a8e5a4a362.png)

1. **做系统的，留一个跨派接口**。无论你在搭 agent 集群、社区产品还是推荐系统，主动注入异质信息源、设一个“魔鬼代言人”角色。工程上相当于在放大器里加负反馈——别让单一路径的正反馈把系统推到墙角；
2. **用模型的，把“共识”当样本**。多智能体投票出来的多数意见，本质是训练先验的一次采样，不是真理。重要判断要多源交叉验证；个人层面，定期认真读一点立场相反的优质内容，相当于给自己的信息茧房手动拉一次电闸；
3. **看新闻的，把仿真当假说生成器**。这类研究的价值在于低成本试错：先在沙盘里试政策和算法，再决定要不要放到真实环境。下次看到“AI 也会极化”的标题，先问实验条件，再谈社会启示。

极化不需要策划者，它只需要相似性、正反馈和足够多的时间。看清机制，才有机会在设计层面拆掉引信。
