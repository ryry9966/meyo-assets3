前几天 36kr 的热搜很有意思：GPT-6 Astra 给 Qwen 做了一次“脑科手术”，只动 0.016% 的参数，数学成绩就明显上涨。直觉上这很反常——一台机器有几十亿个零件，你只换了万分之一点六，凭什么单科暴涨？这篇文章把数字掰开、原理讲透、手段列全，最后说说这件事对普通开发者意味着什么。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-04/8003529a680d3ac6.png)

## 先把 0.016% 掰开：这其实是一个"2MB 补丁"

- 以 7B 模型为例，0.016% ≈ 112 万个参数。FP16 精度下，全量权重约 14GB，而 112 万参数只占 2.2MB——相当于给一个 14GB 的游戏打了个 2MB 的补丁。改的不是游戏本体，是某个局部模块的运行逻辑。
- 还有个巧合：7B 级模型（hidden size 4096、32 层）在所有注意力层的 Q/K/V/O 上挂一个 rank=1 的 LoRA，可训练参数约为 32×4×2×4096 ≈ 105 万，恰好落在 0.015% 附近。量级严丝合缝，基本可以推断这类实验走的是参数高效微调（PEFT）路线。
- 换句话说，报道里所谓“爆改大脑”，实际操作更接近“贴片式改装”：主体权重全部冻结，只训练一小块外挂。

## 为什么动一点点就够：数学能力是“解锁”出来的

- 预训练阶段，模型早就读过海量教材、题解、竞赛论坛和带数学注释的代码。数学知识基本在库里，缺的是被稳定调用的“姿势”。
- 推理掉分通常掉在三个环节：解题格式（CoT 分步是否规范）、自我校验（会不会回头检查）、搜索深度（敢不敢多试几条路径）。这些更像习惯而非知识，而改习惯的成本远低于灌知识的成本。
- 类比一个工程师：他不是缺语法知识，缺的是 code review 的肌肉记忆。让高手带着 review 几十次 PR，风格就立起来了——不需要回炉重读四年本科。
- 学术侧早有伏笔：LIMA（2023）证明 1000 条精选数据就能完成行为对齐；ROME/MEMIT 用单层低秩更新就能改写模型记住的事实；机制可解释性研究也发现不少技能对应着高度稀疏的“回路”。小改动撬动大变化，不是玄学，是结构使然。

## 拆解三板斧：蒸馏数据、低秩适配、稀疏更新

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-04/af12ec6e2dd472ed.png)

按报道口径反推，这种“教师改学生”的组合拳通常是三件事叠加：

1. **教师蒸馏 + 拒绝采样**。强模型对同一道题生成多条解题链，只保留最终答案正确的，再把高质量过程喂给学生。数学是蒸馏的理想科目：答案可验证，数据能自动量产、自动质检，不依赖人工标注。
2. **LoRA 低秩适配**。冻结原权重，只训练一对低秩矩阵 ΔW=BA。参数量和显存开销骤降，7B 模型一张消费级显卡就能跑，训练完只需保存几十 MB 的适配器文件。
3. **稀疏更新 / 参数掩码**。先按梯度显著性给参数做“体检”，挑出极小一批关键权重只更新它们，其余原封不动。天然抗遗忘，还能把“数学补丁”单独保存、随时热插拔。

三件事拼起来就是：教师出题、判卷、讲解；学生戴着低秩眼镜学姿势，大脑本体一克都不动。

## 冷水时间：单科涨分 ≠ 全科变强

- **Goodhart 定律警告**：一旦某个指标成为目标，它就不再是好指标。GSM8K、MATH 这类公开集流传多年，刷分与数据污染的风险真实存在。真正该看的是 held-out 新题、换题型、跨难度的表现。
- **灾难性遗忘**：只喂数学数据，模型很可能“涨一分数学、跌三分作文”。工程上的常规解法是混入通用数据，或对原模型输出加 KL 约束，把补丁焊牢在原有能力之上。
- **能力边界要认清**：低秩/稀疏改动矫正的是 method，不是 memory。它能教会模型更规范的解题姿势，不能凭空注入预训练里没见过的定理和技巧。指望 0.016% 的补丁补上知识面，是想多了。
- **补一句商业事实**：用前沿模型的输出训练竞品模型，在多数 API 服务条款里历来是限制条款，商用之前法务这一关绕不过去。

## 三条冷思考：给真想动手的人

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-04/610a5369c42ac358.png)

1. **先 PEFT，后全参**。7B 级别的任务型微调，LoRA 永远是第一选择：成本、显存、迭代速度全面占优。只有确认瓶颈不在“姿势”而确实在“知识”时，再考虑继续预训练或全参微调。
2. **数据质量压倒数据数量**。优先挑“答案可验证”的任务做蒸馏和拒绝采样；一千条经过质检的高分解题链，效果通常好过十万条裸爬数据。教师模型的价值不在名气大，在会挑题、会讲题。
3. **给每次微调配一张体检表**。除目标 benchmark 外，固定复测代码生成、写作、指令遵循、多语言这几项的回归分数。补丁式微调最大的工程风险从来不是“没涨”，而是“别处悄悄塌了”。

大模型的能力扩散，正在从“整包换代”走向“补丁迭代”：上一个版本负责生产知识，下一个版本负责把姿势调对。这对开源生态是实实在在的利好——前提永远是：把 benchmark 的涨幅当路标，别把它当终点。补丁哲学，永不过时。
