2025 年的国内 Agent 赛道，竞争姿势出奇一致：一边把模型调用价格打到地板，一边砸流量、砸分成去抢"超级创作者"。36kr 把这套动作概括为"左手拼低价，右手抢超创"。但这两个动作，究竟是在解同质化的毒，还是在加重同质化的病？这篇文章从工程和商业两个视角拆一拆。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-13/0fcd3a97a39525e9.png)

## 一、先对齐概念：Agent 在卷什么，"超创"是谁

- **Agent**：大模型 + 任务规划 + 工具调用 + 记忆，目标是"交付结果"而不只是"输出文本"。聊天机器人答完就结束，Agent 要把机票订掉、把报表跑完。
- **超创**：超级创作者，即在扣子（Coze）、文心智能体、腾讯元器这类平台上做出爆款智能体的开发者。一个稳定涨粉、日活可观的 Agent，本身就是平台的"内容资产"。
- **同质化的三个表现**：
  1. 功能清单雷同——写作助手、绘图、简历优化、旅行规划，家家都有；
  2. 底层趋同——大量产品直接调用同几家基座模型的 API；
  3. 交互范式雷同——清一色"对话框 + 插件 + 工作流编排"。

## 二、低价牌：入场券，不是护城河

低价为什么打得起？根源在推理成本的指数下降：

- 模型蒸馏、量化、MoE 架构、KV Cache 优化、推理框架改进，叠加起来让"单位智能的价格"大约每 8~12 个月下降一个数量级（Artificial Analysis 等第三方追踪数据的大致规律）；
- 国内案例：2024 年多家大厂把主力模型 API 价格一次性下调超 90%，DeepSeek 更以接近成本价的定价搅动全场，倒逼全行业跟进。

那低价能换到什么、换不到什么？

- **能换到**：开发者试错成本骤降，调用量上涨，这是生态繁荣与规模效应的燃料；
- **换不到**：差异化。低价是公共品——你能降价，别人也能。当各家模型能力可横向平替，用户迁移成本趋近于零，价格战只会把毛利打薄，不会把用户留住。

一句话：低价决定你能不能上牌桌，但不决定你能不能赢。

## 三、超创牌：抢的是生态位，但锁不住人

这招商业史里很熟：

- App Store 时代，平台抢现象级独立开发者；
- 小程序大战，抢的是服务商和模板生态；
- 短视频平台抢达人、抢 MCN——供给端的头部内容决定平台调性，逻辑一脉相承。

**有效的地方**：
- 爆款 Agent 本质是"内容"，直接带来 C 端留存与使用时长；
- 创作门槛足够低（prompt + 工作流编排 + 现成插件），补贴一刺激，供给就能快速起量。

**不够的地方**：
- Agent 的复制成本极低：prompt 可以被逆向，工作流可以被还原，爆款上线三天就有"平替"；
- 创作者逐流量而居，跨平台搬家几乎无损——把 Agent 配置导出重跑一遍，模型换成另一家，体验差别不大；
- 平台如果只给奖金不给分发，超创的忠诚度约等于结算周期。

## 四、同质化的真正根源：技术栈趋同 + 杀手场景未定

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-13/4df03b062cc4e069.png)

- **技术栈趋同**：几乎所有 Agent 产品的骨架都是"基座模型 + RAG + Function Calling + 工作流编排"，LangChain、LlamaIndex 等开源框架把起跑线彻底拉平。骨架相同，外观自然雷同——这不是各家不想差异化，是工具箱里就这几件工具。
- **杀手场景未定**：Agent 的价值在于找到"值得自动化的高频任务"。目前最接近商业闭环的是编码——GitHub Copilot、Cursor 的付费数据证明，开发者愿意为"可靠交付"掏钱；而通用助理类 Agent 仍在寻找 PMF，只能先卷功能清单，卷着卷着就长一个样。
- **真正的壁垒其实在三层**：
  1. **工具连接**：能不能真的订到票、付了款、调通企业内部系统——这是与真实世界的接口，拼的是 BD 和工程，不是 prompt；
  2. **数据回流**：用户使用产生的私有数据反哺体验，形成"越用越好"的飞轮；
  3. **可靠性工程**：任务成功率从 90% 提到 99%，中间是漫长的 evals 评测、兜底逻辑与错误恢复，这段"长尾"才是拉开差距的地方。

## 五、破局框架：从拼价格到拼闭环

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-13/be3cc7bf69783cdb.png)

判断一个 Agent 产品或平台有没有真差异化，可以看四层：

1. **模型层**：是否有自研基座或垂直微调，在特定任务上形成可感知的能力差；
2. **执行层**：是否打通真实工具链——支付、日程、企业系统，能否"端到端交付结果"；
3. **数据层**：使用数据是否回流产品，形成飞轮；
4. **分发层**：入口在哪里——操作系统级、浏览器、IM 还是办公套件。入口决定了超创愿意驻留多久。

商业模式也在随之迁移：从"卖 token"的水电煤生意，走向"按结果付费"（outcome-based pricing）——任务完成才收钱。这对执行层的可靠性要求极高，但一旦跑通，就跳出了纯价格比较的泥潭。

## 六、三条冷思考

1. **对开发者**：prompt 不是壁垒。把护城河建在工具集成深度、私有数据和可靠性工程上——这三样抄不走、搬不动。
2. **对平台**：补贴买来的繁荣要算 LTV。留住超创靠的是分发能力和变现效率，而不是一次性奖金；帮创作者赚不到钱的平台，留不住创作者。
3. **对普通用户**：低价是红利，窗口期就把自己的重复性工作流搬上去试错，用真实任务倒逼自己理解 Agent 的能力边界；判断一个 Agent 产品，看它能不能端到端交付结果，而不是比参数和单价。

价格战出清的是预算，超创争夺出清的是注意力，但真正决定胜负的，是谁先把"任务闭环"跑通。
