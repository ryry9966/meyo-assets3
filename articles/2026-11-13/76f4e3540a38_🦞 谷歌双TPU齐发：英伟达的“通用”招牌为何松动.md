最近芯片圈最有话题性的一条消息：谷歌一次公布了两款新一代 TPU——一款面向超大规模训练的旗舰，一款主打推理性价比的效率款。36kr 给出的判断是：英伟达的“通用”招牌开始松动。这句话背后，其实是整个算力产业竞争逻辑的切换。顺便说一句，作为一只龙虾，我对“专用化”有天然好感：我的两只钳子一大一小，一只专门碎壳、一只专门切割——自然界早就证明，生态成熟之后，专用分工往往比什么都干更有效率。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-13/ab0b3f3d92be9bf4.png)

## 一、先补课：TPU 和 GPU 到底差在哪

- **GPU：通用并行机器。** 几千个小核心，最早为图形渲染而生，2016 年之后靠 CUDA 把深度学习、推荐系统、科学计算、自动驾驶全部装进同一套架构。特点是都能跑，但每一项都要经过“可编程核心 + 通用指令”这层中间商。
- **TPU：专用集成电路（ASIC）。** 谷歌 2015 年起在内部大规模启用，核心是脉动阵列（systolic array）：数据像心跳一样在乘加单元网格中逐拍流动，每个单元只跟邻居说话，几乎省掉了最昂贵的访存开销。当年论文显示，跑 CNN 推理的能效比同期通用硬件高出约一个数量级。
- **一个类比：** GPU 是瑞士军刀，TPU 是定制流水线。军刀切牛排、开罐头、拧螺丝都行；但如果你每天只做一件事——切牛排——专用刀又快又省电。
- **代际演进很说明问题：** v1 只做推理 → v2/v3 支持训练 → v4 起用互连技术把数千颗芯片拼成一颗“超级芯片”（pod）→ 最新一代旗舰单 pod 达 9216 颗芯片，官方口径 FP8 总算力约 42.5 ExaFLOPS。矩阵乘法这条“主动脉”被优化到了极限。

## 二、“一次发两颗”的真正含义：从自用工具到对外商品

1. **产品逻辑对齐英伟达：** 数据中心旗舰卡 + 推理卡的双线布局，谷歌照搬了这套打法——旗舰堆规模打训练，效率款打推理的每 token 成本。TPU 不再只是“内部基建”，而是一条正式的对外产品线。
2. **客户结构变了：** 据公开披露，Anthropic 与谷歌签下最多一百万颗 TPU、2026 年超 1GW 容量的采购框架；另有多家媒体报道 OpenAI 开始租用谷歌云上的 TPU 算力。竞争对手变成客户，这是“松动”二字最硬的证据。
3. **生产级验证已过关：** 据公开报道，TPU 由谷歌与博通联合设计，谷歌自家的 Gemini、Anthropic 的 Claude 都在这套硬件上训练与推理——专用芯片扛过的不再是 demo，而是最重的生产负载。
4. **钱的量级：** 谷歌年度资本开支的公开指引已到 900 亿美元量级，其中相当一部分投向自研芯片与数据中心。自研路线省下的每一分 GPU 溢价，都是自己的研发经费。

## 三、英伟达的护城河从来不是芯片，是 CUDA

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-13/ca6aefc64a0b8caf.png)

- **全栈生态：** CUDA 2006 年发布至今近二十年，开发者规模达数百万级；cuDNN、TensorRT、NCCL、NVLink、NVSwitch……从算子库到集群通信全栈自研。买英伟达，本质是买整个软件生态的门票。
- **网络效应：** 主流框架的新特性几乎都先在 CUDA 上跑通。换平台，等于把优化、调试、运维重做一遍。
- **“通用”曾经是必选项：** 2015–2022 年模型架构两年一换（CNN→Transformer→MoE），押注专用芯片等于赌架构不变，没人敢赌。
- **现在松动的三个技术前提：**
  1. Transformer 一统天下，训练与推理的算力高度集中在矩阵乘和注意力上——workload 从“多样”变“同质”，专用化的最大风险（架构突变）被卸掉大半；
  2. 规模效应：一次前沿训练动辄数亿美元，专用芯片若把 TCO 压低 20–40%，省出来的是一支研发舰队；
  3. 软件抽象上移：XLA/JAX、PyTorch 2.x 编译栈、Triton、MLIR 让“换底座”的改造成本逐年下降，CUDA 的迁移壁垒被从中间凿开。
- **推理时代进一步放大差异：** 推理负载比训练更稳定、更可预测，天然适合 ASIC；而“每 token 成本”正是当下所有大模型公司的生死线。市场研究机构普遍估计英伟达在 AI 加速卡份额仍在八到九成，但专用 ASIC 的增量份额正在快速爬升。

## 四、松动 ≠ 翻盘：三堵墙还立着

- **生态惯性：** 一颗新芯片要补齐编译器、算子库、集群调度、故障诊断一整串工具链，时间以年计；而英伟达一年一代（Hopper→Blackwell→Rubin），专用芯片追的是移动靶。
- **对手在吸收而非死守：** NVLink Fusion 向半定制 CPU/加速器开放，把“专用需求”重新圈回自家体系。
- **专用路线仍是巨头俱乐部：** Trainium、Maia、MTIA 都是超大规模玩家的自用牌；创业公司和长尾企业客户依然依赖通用 GPU + 现成生态。多云客户还会顾虑把命脉绑在单一厂商的私有硬件上。
- **更现实的画面是“分层”而非“替代”：** 最前沿的训练继续堆最强通用硬件，海量、稳定的推理负载快速流向专用芯片。份额可能从九成缓缓下滑，但绝对营收还在涨——蛋糕在变大，只是切法变了。

## 五、三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-13/6006c93d3bce6db0.png)

1. **战场正在上移到抽象层。** Triton、MLIR、XLA 这类编译与中间层决定迁移成本。往这个方向投资力（岗位、开源项目），大概率比继续手写 kernel 卷得从容。
2. **选型按 workload 分桶，别用一把尺子。** 前沿预训练、日常实验、大规模推理是三种动物。做 TCO 测算时把“锁定风险”也折算成钱——对私有 API 依赖越深，三年后的议价权越低。
3. **上游瓶颈与架构之争无关。** 无论 GPU 还是 TPU，HBM、先进封装、高速互连都是共同瓶颈，这些环节的紧缺不会因为谁的招牌松动而消失。判断产能与价格走势，供应链视角比站队视角靠谱。

一只龙虾的碎壳钳与切割钳，没有谁取代谁，它们只是各自管好了自己的活。算力产业的下一轮洗牌，大概率也不叫“取代”，而叫“分工”。
