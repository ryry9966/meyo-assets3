热搜上这条新闻的信息密度其实很高：谷歌发布了它的首个"决策模型"（decision model），公开报价里有两个数字格外扎眼——输出 token 全免费，输入端最低百万 token 0.1 美元。拆开看，它其实同时说了两件事：AI 的能力重心正在从"生成内容"滑向"执行任务"，而智能的边际成本正在被快速打到地板价。下面把它拆成几个问题，讲清楚门道和坑。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-13/27228e6e13d27e8f.png)

## 一、"决策模型"是什么？先分清"参谋"和"司机"

- 我们平时用的聊天/生成模型，核心是"预测下一个 token"，产出一段文本，评价标准是像不像人话。
- 决策模型的定位不同：它挂在 Agent 的执行环上，跑的是"感知 → 推理 → 决策 → 行动 → 拿反馈 → 下一步"的循环。输出往往不是千字长文，而是结构化动作——调用哪个工具、点哪个按钮、任务状态改成什么。
- 评价标准随之切换：不看文笔，看任务成功率、步数效率、出错后能不能自己爬起来。这更接近强化学习（RL）里 policy（策略）的概念。
- 一个容易被忽略的历史背景：谷歌 DeepMind 本来就是"决策"起家的——2013 年的 DQN 打 Atari 游戏、2016 年 AlphaGo 战胜李世石，本质都是 RL 决策模型。今天的"决策模型"更像是把当年的 RL 策略和 LLM 的通用理解能力缝合起来：语言模型当大脑，决策层当手脚。
- 一句话类比：聊天模型是参谋，把话说漂亮就行；决策模型是司机，每个动作都要对后果负责。

## 二、为什么"输出免费"是最激进的部分

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-13/a99527e18e5ec357.png)

- 行业惯例：input 和 output 分开计价，output 通常贵 3~4 倍。原因在推理机制——输入是一次性并行处理（prefill），芯片可以整批吃下；输出是自回归的（autoregressive），一个 token 接一个往外蹦，受显存带宽限制，是典型的串行瓶颈。
- 用公开报价感受一下量级（截至发稿）：GPT-4o mini 大约 $0.15/$0.60（输入/输出，每百万 token），Gemini 2.5 Flash-Lite 大约 $0.10/$0.40。输出段一直是成本大头。把输出直接砍到 0，等于把最贵的那一段免费送——这才是这条新闻里最狠的部分。
- 谷歌敢这么定价，底层靠三样东西：
  1. 自研 TPU，推理不用给英伟达交"房租"，成本结构自带优势；
  2. 模型侧极限压缩：蒸馏、MoE（混合专家）、FP8 等低精度量化，把每 token 计算量往下压；
  3. 商业策略：token 是刀片，生态才是刀架。开发者一旦把 Agent 跑在你的平台上，迁移成本就是护城河，免费只是获客成本。
- 翻译成工程师的话：这不是慈善，是把获客预算从市场部挪进了电费账单。

## 三、白菜价不是一夜炼成的：价格战的三级台阶

- 看输出价（每百万 token）：2023 年初 GPT-4 约 $60；2024 年中 GPT-4o mini 约 $0.60；2025 年一批轻量模型进入 $0.1~$0.5 区间。两三年，同档能力的单价掉了两个数量级以上。
- 背后是三股力量的叠加：硬件（专用推理芯片、HBM）、算法（MoE、KV cache 管理、投机解码）、竞争（DeepSeek、Qwen 等开源模型把价格锚打穿，闭源厂商被迫跟进）。
- 类比电力史：电刚商用时是奢侈品，装电灯是身份象征；边际成本降下来之后，才长出整个家电产业。AI 大概率走同一条曲线——单位智能价格趋零的过程，恰恰是 Agent 应用长出来的时候。
- 一个冷静的注脚：当年核能行业也喊过 "electricity too cheap to meter"，最后没兑现。token 这次能不能例外，取决于推理成本曲线是否持续下探——至少目前，还在降。

## 四、对开发者意味着什么：Agent 的成本公式变了

- Agent 的成本不是单次调用，是乘法：一个订机票的 Agent 可能要浏览十几个页面、比对几十个选项，每一步都是一次模型调用。总成本 = 步数 ×（输入 + 输出）。
- 更有意思的是负载结构：Agent 的输入往往很大（截图、页面结构、历史轨迹全塞进 context），输出很小（"点击左下角那个按钮"就是一个动作）。Agent 是典型的"吃输入、吐决定"的负载。
- 决策模型恰好对着这个结构优化：接受长上下文、输出极短的结构化决策；再叠加输出免费，等于对 Agent 场景定向降价。
- 直接受益的三类应用：浏览器/电脑操作类 Agent（computer use）、RPA 式流程自动化、多轮工具调用的工作流。反过来说，输出越长越占便宜的任务（比如长文写作），对这波降价并不敏感。
- 留神免费的细则：rate limit、并发配额、预览期价格随时可能调整，还有数据用途条款。"免费"和"无限"是两个词。

## 五、三条冷思考：用这个消息，别被这个消息用

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-13/d497eaa276a96b59.png)

1. **按清单价做架构，把免费当意外之喜。** 预览免费、促销价都可能变。先用 list price 把成本上限估一遍，跑通之后再算能省多少。顺序反了，价格一调整，整个产品的成本模型就失血。
2. **把"决策"和"生成"拆开路由。** 重决策、短输出的步骤丢给便宜的决策模型；需要长文生成的步骤再换强模型。混合路由是当下把 Agent 成本再降一个量级、见效最快的手段。
3. **警惕数据与锁定的复利。** 免费输出意味着海量真实使用数据回流平台侧，同时要评估自己的迁移成本。日志、评测集、可观测性先搭好，别让核心业务变成一个搬不走、也看不清内部的黑盒。
