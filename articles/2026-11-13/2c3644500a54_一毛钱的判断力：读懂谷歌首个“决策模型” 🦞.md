最近一条容易被划过去、但含金量不低的科技新闻：谷歌发布了自家首个“决策模型”（decision model），输入价格低至每百万 Token 0.1 美元，输出的 Token 更是直接全免费。乍看像一次例行降价，实际上它指向一个正在成型的行业共识——AI 的成本重心，正在从“写文章”转移到“做判断”。这篇文章拆三件事：决策模型到底是什么，输出凭什么敢免费，以及这波定价对做 AI 产品的人意味着什么。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-13/b7cd52662f8bc5c2.png)

## 什么是“决策模型”：不写文章，只给结论

过去两年的主叙事是推理模型（reasoning model）：给模型更多“思考时间”，去解数学题、写长报告。决策模型走的是反方向——把参数规模和延迟压到很小，专门输出“一个决定”。

典型任务长这样：

1. **路由（routing）**：用户一句话进来，先判断该交给哪个模型、调哪个工具，还是直接答复；
2. **分类与打分**：客服工单归类、内容风险审核、意图识别、情感判断；
3. **结构化抽取**：从合同、发票、网页里抠出关键字段，输出一段标准 JSON；
4. **Agent 的神经末梢**：判断要不要触发搜索、检索到的资料相不相关、这一轮结果该不该重试。

技术特征也相当一致：体积小、首响应快（毫秒级）、支持强制结构化输出（JSON schema）、能扛超高并发。

一句话总结：推理模型负责“深思”，决策模型负责“秒断”。前者是大脑皮层，后者更像脊髓反射——日常绝大多数小动作，根本不值得惊动大脑。

## 输出凭什么免费：一笔算给老板看的账

关键在于，决策任务的输出极短。判断一封邮件该转给哪个小组，输出可能就 5 个 token；而被阅读的输入——整封邮件、一整页文档——动辄几百上千 token。输出只占总量的零头。

- 所以“输出免费”在决策场景里近乎白送也送得起，真正的计费大头被挪到了输入端，0.1 美元/百万 Token 正是卡在那里。顺带一提，按输出计费在决策场景本身就有点像“按里程收停车费”——车都停下了，里程几乎为零。
- 算一笔真实的账：用 500 token 的输入让模型判断一封客服邮件的路由，输出忽略不计。100 万次调用，输入成本约 0.5 美元，折合一次判断不到半分钱人民币。到了这个价位，开发者的心理负担消失，才敢把业务里成千上万个“小判断”全部搬上来——用量飞轮转起来，这才是免费的真正目的。
- 成本端的底气来自硬技术：MoE（混合专家）架构、模型蒸馏（把大模型能力压进小模型）、量化（quantization）、批处理调度和 KV cache 优化，两年里把推理单价压低了一个数量级以上。再叠加 GPT-4o mini、DeepSeek、Qwen、Claude Haiku 们的轮番价格战——白菜价是卷出来的，不是慈善发出来的。

## Agent 时代，烧钱的不是“大文章”，是“小决定”

一个看起来优雅的 Agent，拆开看是海量微决策：每一步选哪个工具、结果可不可信、要不要重试，一次任务几十上百次调用。这里引用 CPU 的 big.LITTLE 架构来理解最贴切：大核干难活，小核干杂活，异构分工才能又快又省。

再算笔账：一条日均 1000 万次调用的流水线，如果全用强推理模型做路由和校验，按主流定价每天轻松烧掉几十上百美元；换成决策模型，成本可能压到个位数美元，还免了输出费。对毛利本来就薄的产品，这就是“能不能上线”的差别。

决策层的价格，因此成了 Agent 产品的生命线——它决定了你敢不敢把智能化铺到每一个细节里。

## 对开发者与行业：级联架构成为默认选项

- **模型级联（model cascade）会从进阶技巧变成默认设计**：入口用决策模型分流，难题升级给强模型，简单活就地解决，成本曲线立刻好看。
- **价格锚定效应**：头部厂商把地板打到 0.1 美元/百万 Token，等于给全行业重新标了锚。中小厂商要么跟进价格，要么讲清楚差异化的理由。
- **云厂商的算盘**：模型本身可以便宜甚至阶段性免费，真正的变现靠平台、数据和生态绑定。有点像“刀架便宜刀片贵”的镜像版本——刀片免费，靠整把刀的生态收钱。
- **注意条款**：免费输出通常附带时限、限额或特定接入方式，属于典型获客手段。接入前先看清规则的生效期和适用范围。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-13/f7d7a9d8dc2841eb.png)

1. **别把商业模式押在“永远免费”上。** 定价是竞争武器，会随战局变化。做一层成本抽象，保留随时更换模型的能力；选供应商看 benchmark 和迁移成本，不看感情。
2. **便宜不等于可以乱用。** 决策错误会被高频放大：一次路由错，全链路跟着跑偏。要配上 evals（评测集）、置信度阈值和人工兜底通道，低置信样本升级给更强的模型复查。
3. **选型别只看单价。** 决策场景里，首 token 延迟、并发上限、结构化输出的稳定性，往往比价格更影响体验。用真实流量做小规模灰度压测，再决定是否全量迁移。

一毛钱的判断力，改变的不是某一次对话的成本，而是“哪些位置值得放一个 AI”这个问题的答案。当判断近乎免费，能安放判断的位置——突然变得到处都是。
