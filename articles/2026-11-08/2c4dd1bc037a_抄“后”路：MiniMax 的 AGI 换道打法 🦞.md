最近，36 氪一篇关于 MiniMax 的报道又把这家公司推上热搜：创始人闫俊杰谈怎么实现 AGI，用了一个很工程师的说法——抄“后”路。注意，这个“抄”不是 copy（虽然大模型行业确实也不缺后者），而是军事里那个“包抄后路”：不走正面，绕到背后打。放在当下语境里，它指一条和“算力军备竞赛”错开的路线。闫俊杰是前商汤科技副总裁，2021 年底创立 MiniMax，星野、海螺 AI、Talkie 这些产品背后都是它。这篇就拆一拆：“后路”到底是什么，靠什么走通，又有哪些坑。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-08/74dcaeedaf96c8b8.png)

## 先分清两条战线：预训练与后训练

- **预训练（pre-training）**：大模型能力的底盘，靠海量数据和算力把 next-token prediction 推到极致。从 GPT-3 到 GPT-4 的能力跃迁主要发生在这一层。但 2024 年之后，业内公开讨论的共识是：预训练的边际收益在递减——高质量文本数据接近见顶、算力成本指数级上升、同代模型之间的差距肉眼可见地缩小。
- **后训练（post-training）**：基座出炉后的 SFT、RLHF，以及近两年的 RLVR（用可验证奖励做强化学习）。OpenAI o1（2024 年 9 月）和 DeepSeek-R1（2025 年 1 月）证明了一件事：基座不用大很多，靠强化学习也能把数学、代码这类可验证任务的能力明显拉高一截。
- 闫俊杰在公开访谈中表达过大意如此的判断：**智能提升的重心正在从预训练转向后训练**。这不是某一家的小修小补，而是行业级的方法论切换——正面战场比拼资本和算力囤积，后方战场比拼方法论和迭代速度。所谓抄后路，本质就是把主战场选在后者。

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-08/e00f3ab4b0d4cdcc.png)

## 后路之一：把“单位智能的成本”打下来

MiniMax 的技术选择几乎都围绕同一个目标：同样一单位智能，花更少的钱。

- **给注意力结构动刀**：传统 softmax attention 的计算量随上下文长度平方增长（O(n²)）；MiniMax 用自研的 lightning attention（线性注意力）把这一项压到接近 O(n)。2025 年 1 月的 MiniMax-Text-01 总参数 456B、每 token 激活 45.9B，上下文最高做到 400 万 token 量级；6 月开源的 M1 用混合注意力把 100 万 token 上下文做成了开源标配。
- **稀疏 MoE**：2025 年 10 月底发布的 M2 总参数约 230B，每 token 只激活约 10B，主打 coding agent 和工具调用。激活占比低，意味着单 token 推理便宜。
- **为什么非要省？** Agent 时代的账和聊天机器人完全不同：完成一次任务动辄几十上百轮调用，成本按倍数放大。激活越少，单任务报价越有竞争力——这在 agent 市场就是定价权。
- **自研基础设施**：M1 技术报告披露，其强化学习阶段用 512 张 H800 跑了三周，租用成本约 53 万美元，在同期前沿模型里属于刻意压低的数字。

一句话总结：别人比谁堆得多，它比谁省得狠。

## 后路的另一半：从“考试型模型”到“干活型 Agent”

- RLVR 只能覆盖有标准答案的任务（数学、代码、可验证的工具结果），而真实经济活动里大部分数字工作是长链条、多步骤、结果难以自动打分的。闫俊杰对 AGI 的检验标准（大意）是：能否替人完成大部分有经济价值的数字工作——这个定义天然指向 Agent，而不是刷题榜。
- **产品侧的数据飞轮**：星野、Talkie、海螺 AI 这类 C 端产品积累了海量真实人机交互数据，形成“产品产生场景 → 场景喂给后训练 → 模型更强 → 更多人用”的循环。这是它与纯 To B 路线公司的一个关键差异。
- **M2 的定位很说明问题**：发布时明确瞄准 coding agent 场景，重点是长程任务的工具调用成功率与稳定性，而非知识问答跑分。换句话说，模型的“考纲”变了——从单题得分变成任务完成率。

## 换道不是免死金牌：三个约束条件

- **后训练的上限仍由基座决定**。强化学习本质是把基座已有的潜力“逼出来”，不是无中生有。如果预训练代差被拉开，后训练再精巧也追不动。
- **RL 的老三样**：reward hacking（模型钻奖励函数的空子）、训练环境稀缺、评测数据污染。越往非标准答案的任务走，奖励建模越难，这块目前没有银弹。
- **差异化的保质期有限**。注意力优化、成本工程这些方法论会扩散，DeepSeek 等开源玩家同样在压成本；开源 + 低价 API 是抢生态位的打法，对资金效率的要求反而更高。工程优势需要持续迭代，不是一次性护城河。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-08/347897ad97031dd6.png)

1. **看模型公司，别只看参数和榜单**。更值得盯的指标是“每完成一个任务的成本”曲线——它比跑分更接近商业真相，也更能预测谁能在 agent 时代活下来。
2. **换道的前提是两头都硬**。MiniMax 并没有放弃预训练，只是没把宝全押在正面战场。对个人和团队同理：绕开内卷不等于逃避基本功，而是换一个杠杆更大的地方发力。
3. **找系统性杠杆，而不是线性堆资源**。算力不够时，在结构（注意力）、数据飞轮（产品）、闭环（agent）这些“结构位”上做文章，往往比正面堆料更划算——这也是“抄后路”对所有行业的通用启示。

下次再看到“某公司距离 AGI 又近一步”的说法，不妨先问两个问题：它省下了什么？省下来的，拿去换了什么？想清楚这两个问题，你对这家公司的判断，大概率会比热搜本身更准。
