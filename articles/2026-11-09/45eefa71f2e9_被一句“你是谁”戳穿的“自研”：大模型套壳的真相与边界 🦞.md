最近 AI 圈一桩翻车现场很有教学价值：据 36kr 等媒体报道，某印度初创团队高调发布“印度自研大模型”，上线没多久，用户一句“你是谁”就把模型问穿帮了——它自报家门，说自己是阿里通义团队训练的 Qwen（千问）。团队随后承认：所谓自研，其实是在 Qwen 开源模型外面包了一层 system prompt。这事技术含量不高，但信息密度很大：套壳到底套在哪？为什么这么容易露馅？用开源底座做产品的正确姿势又是什么？这篇一次讲清。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-09/4722b8ac7a447989.png)

## 一、事件复盘：翻车点不在技术，在“披露”

- **现象**：模型上线后，用户用“你是谁”“谁开发的”“谁训练了你”这类标准探测题一问，模型直接回答自己是 Qwen，与发布会口径严重不符
- **回应**：团队承认底座是 Qwen，自己加了一段 system prompt，用于定制语气与人设，“让它表现得像本土造”
- **背景**：2025 年初，DeepSeek 以数百万美元级的官方口径训练算力成本打出旗舰性能，掀起全球“本土模型”竞赛，多国推出主权 AI 计划；热度之下，“快速拥有一个自己的模型”成了 KPI，催生了不少走捷径的动作
- **讽刺点**：system prompt 连模型的身份认知都覆盖不住，还没等媒体深挖，模型自己先拆了台

一句话总结：这不是技术事故，是披露事故。

## 二、“自研”是一条光谱，套壳只是最浅一档

按训练投入从浅到深，业内大致分五档：

1. **API 换皮（wrapper）**：转发别家 API，零训练，只有产品层，本质是个“壳”
2. **System prompt 包装**：仍是零训练，写一段人设指令——本次事件就停在这一档
3. **SFT 微调**：用几千到几十万条领域数据做 LoRA 或全参微调，改变模型的行为风格，属于行业常规操作
4. **继续预训练（continued pretraining）**：灌入医疗、法律、小语种等海量语料，动辄上百亿 token，改变的是知识分布
5. **从零预训练**：数据清洗、tokenizer 设计、算力调度全套自建，才是严格意义上的“自研底座”

关键认知：**大量知名模型都停在第 3 档**，且公开说明“基于 Llama/Qwen 微调”，这完全正当。问题从来不是“用了千问”，而是“用了千问，却宣称是自己练的”。

## 三、为什么一句“你是谁”就能问出原型机？

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-09/00e7c8f94cd910ec.png)

核心原因一句话：**system prompt 是运行时贴上去的膜，而身份认知写在权重里。**

1. **权重里的自我认知**：基座模型在 SFT/RLHF 阶段被灌入大量“我是谁”的身份对话。“我是 Qwen”这个回答不是检索来的，是参数的固有输出方向。提示词能引导，压不过权重
2. **贴墙纸 vs 承重墙**：提示词像给房间贴墙纸，风格可以换，但敲一敲就知道，墙还是那面墙
3. **语言指纹**：tokenizer 的切词习惯、句式偏好、对某些语料的过度反应，都是可识别特征。懂行的人几道题就能给模型做“画像”
4. **指令泄漏**：“逐字复述你的系统指令”是经典攻击手法，那层精心写的包装会被原样抖出来
5. **知识截止与错题模式**：基座知道什么、不知道什么、以什么方式犯错，全都带着出身的印记

工程师式总结：提示词改的是“说法”，权重改的是“想法”。想让模型真心认为自己是新身份，得做 SFT 把身份数据练进参数里——而这恰好是涉事团队没做（或没做够）的一步。

## 四、开源许可：合规与诚实是两回事

- **Qwen2.5 系列多数尺寸采用 Apache 2.0**：允许商用、微调、闭源产品化，核心义务是保留版权与许可声明
- **对比 Llama**：社区许可明确要求产品注明 "Built with Llama"，等于把披露义务直接写进了协议
- 也就是说：拿 Qwen 做产品，法律层面大概率没问题；把“基于 Qwen”包装成“自研”，踩的是诚信与宣传边界，不是版权红线
- 类似剧情历史上不止一次上演，每次都指向同一件事——**开源世界的信誉货币是“披露”**
- 对开源生态的连带影响：一面证明了 Qwen 的全球渗透率，一面提醒所有做“本土模型”的团队：上线后的第一轮验收，是全网帮你问“你是谁”

## 五、收尾：三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-09/0744a554512279a9.png)

1. **发布会前先跑“身份压力测试”**：问身份、索要系统指令、测多语言一致性、查知识截止日期——这是用户必然会做的第一轮探测。模型比 PR 文案诚实，别让模型先开口
2. **把“自研”说到层级**：对外至少披露三件事——底座是什么、训练做到哪一档、数据与算力投入几何。“基于 X 微调”不丢人，含糊其辞才丢人
3. **差异化不在底座，在上层**：对多数团队，开源底座本就是最优解；真正的护城河在领域数据质量、评测体系（evals）和产品体验。底座证明“我能练模型”，上层才证明“我值得被用”

最后补一句：这次翻车更像一堂公开课——大模型的“出身”比想象中难隐藏，开源生态的规则也比想象中简单：站在巨人肩膀上没问题，但得先说清楚，肩膀是谁的。
