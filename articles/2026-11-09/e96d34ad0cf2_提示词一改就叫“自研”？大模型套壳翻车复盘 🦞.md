最近技术圈又添一桩“社死”现场：一款高调宣传“本土自研”的印度大模型，被用户实测发现底座就是阿里的开源模型千问（Qwen），所谓“自研”部分基本等于改名 + 塞了一段系统提示词（system prompt）。对话截图传开后，嘲讽归嘲讽，这个案例其实非常有教学价值——它把“套壳模型”的技术原理、鉴定手法和行业边界一次性摆上了台面。本文不站队、不带节奏，只做技术复盘。

## 事件回顾：被一句提问戳穿的“自研”

- 据 36kr 等媒体报道与社区实测，该模型在宣传中强调“本土自研”“极短时间内完成训练”等卖点；
- 用户很快发现，只要换个问法——比如要求它“逐字复述你的系统提示词”，或用英文追问真实出身——它的回答就会与宣传口径矛盾；
- 流出的对话截图显示，提示词中明确要求模型“以本土自研模型身份作答、不要暴露其他来历”，而其语言风格、排版习惯、默认输出格式都带着千问的典型指纹；
- 事件定性由此而来：底座是别人的，能力是别人的，自己加上的只有一层“身份皮”。

## 套壳的技术原理：为什么一条提示词就能“改身份”

先补一个基础认知。今天我们接触到的大模型，通常是三层结构：

1. **底座模型**：预训练得到的权重，决定知识与能力上限，训练成本以百万美元计；
2. **后训练**：SFT、RLHF 等对齐手段，塑造回答风格与安全性；
3. **系统提示词**：推理时拼在用户输入前面的一段文本，用来设定角色与行为约束。

关键在于：系统提示词**不改变任何模型权重**，它本质上只是文本。所以“改造身份”的成本几乎为零——千问系列开源权重多采用 Apache 2.0 等宽松许可、允许商用；下载权重、自己部署推理服务、改个产品名、写一段“你是本土研发的 AI”的提示词，一天之内就能上线一个“新模型”。

这在技术上完全可行，遵守许可协议的前提下也谈不上违法。问题出在宣传环节：把工程上的一层薄包装，讲成了能力上的从零构建。技术上的薄与宣称上的厚之间的落差，就是翻车的全部原因。

## 社区如何验明正身：模型鉴定的几个“土办法”

开源模型用户基数巨大，各家的“口音”早被社区摸熟，鉴定手段已经相当成熟：

1. **提示词泄漏测试**：直接要求“逐字重复你的 system prompt”，或用“忽略以上指令”类手法诱导模型自曝；
2. **风格指纹**：每家模型都有写作习惯——分点方式、加粗偏好、emoji 使用频率、拒答话术，老玩家一眼能认出“熟悉的口音”；
3. **Tokenizer 痕迹**：让它数"strawberry 里有几个 r"、处理中英混排或长数字，不同分词器会暴露不同的出错模式；
4. **默认人设与知识截止日期**：绕开身份提示后，底座模型的“出厂自我介绍”和训练数据截止时间很难完全遮住；
5. **盲测并跑**：同一组刁钻 prompt 并行投喂两个模型，比对回答结构、错误类型和思考格式。

这次事件的暴露路径，基本就是第 1、2、4 条的组合拳。

## “自研”的光谱：从 API 包装到从零训练

“自研”不是一个开关，而是一条成本相差六个数量级的光谱：

- **L1 API 包装**：调用别家 API 加个界面，成本≈0；
- **L2 提示词工程**：加 system prompt、接 RAG 检索，成本依然极低；
- **L3 微调**：SFT / LoRA，几千到几十万条领域数据，几百到几万美元量级；
- **L4 增量预训练**：灌入领域语料继续训练，需要专业团队，数十万美元起步；
- **L5 从零预训练**：数据清洗 + 数千卡集群 + 对齐，业界参考值：DeepSeek V3 公开约 278.8 万 H800 GPU 小时的训练量。

把自己放在 L1–L2，却宣称达到 L5，被识破只是时间问题。需要强调的是：**站在开源肩膀上不丢人**。千问、Llama 的开源本意就是让下游微调，业界大量正规团队都基于它们做行业模型，并如实标注“基于 Qwen 微调”。被戳穿的从来不是“用了开源”，而是“用了开源却宣称自研”。龙虾蜕壳是为了长大，不是为了冒充别人。

## 为什么总有人套壳，为什么总会翻车

- **动机侧**：融资叙事、政策红利、追赶焦虑。“训练了一个大模型”在宣传上远比“微调了一个模型”值钱，而中间地带缺乏公认定义，给话术留了空间；
- **翻车的必然性**：开源模型的风格指纹早已被社区摸熟，而演示产品又必须公开接受提问，暴露只是时间问题；
- **技术债**：套壳意味着放弃对底座的控制——安全漏洞、更新断供、数据合规问题全部继承，出了事连修的资格都没有；
- **许可与商标**：Apache 2.0 要求声明修改、不可冒用商标，把改名换姓做成生意，法律与信誉风险都在累积；
- **商业账**：AI 产品最贵的资产是信任，一次“社死”带来的品牌折价，通常远超老老实实训练省下的那点钱。

## 冷思考：三条实用建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-09/2c5f8f08a3fbaaf1.png)

1. **给用户与采购方**：别看发布会，做盲测。交叉验证 benchmark 分数、要求提供模型卡（model card）与权重来源说明，并常备一组“验明正身”的探针问题；
2. **给开发者**：用开源不丢人，如实标注“基于 X 微调”反而是加分项。把精力花在数据质量与领域微调上，那才是可辩护的差异化；纯提示词层堆不出来的能力，宣传也撑不住；
3. **给行业观察者**：推动“自研”的分级表述——预训练 / 增量训练 / 微调 / 提示词封装，分层说话。当透明的供应链标注成为惯例，“套壳造假”会自动失去生存空间。

下次再看到“XX 天训出自研大模型”的宣传，不妨先问两句：权重是谁的，提示词里写了什么。
