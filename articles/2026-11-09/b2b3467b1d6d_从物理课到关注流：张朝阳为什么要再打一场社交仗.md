最近 36 氪的一篇报道把搜狐重新拉回大众视野：60 出头的张朝阳不打算躺平，正带着搜狐视频的"关注流"再打一场社交仗——自己当一号用户，发视频、逐条回评论、每周雷打不动直播讲物理和英语。一家在社交赛道上屡战屡败的老牌公司，为什么偏要挑这条公认最难的赛道再战一次？这篇文章拆一下它的历史包袱、真实打法和理性预期，最后给出几条冷思考。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-09/208a89263308cb43.png)

## 一、社交心结从哪来：搜狐错过的三张船票

- **门户时代的江湖地位**：1998 年搜狐正式亮相，与新浪、网易并称三大门户，2000 年登陆纳斯达克，第一代中国人"上网看新闻"的编辑推荐流，很大程度是它定义的。
- 但过去二十多年，它接连错过三次浪潮：
  1. **搜索**：手里握着搜狗输入法这个国民级入口，搜索主业却始终打不过百度，2021 年搜狗整体并入腾讯，就此画上句号；
  2. **社交**：2010 年上线搜狐微博，面对新浪"名人战略 + 媒体化运营"的强攻，资源和决心都不在一个量级，两年后逐渐偃旗息鼓；熟人 IM 更是完全没插上手；2019 年又推出围绕搜狐新闻评论区的狐友，声量有限；
  3. **算法分发**：新闻客户端一度做到头部，却被今日头条的推荐算法降维打击，信息流心智拱手让人。
- 剩下的家底：畅游的游戏现金流持续输血，视频业务收缩版权采购、转向自制和直播，公司整体降本增效。搜狐像一台老服务器——从不宕机，但也很少有人关心它还在跑什么业务。
- 所以社交对今天的搜狐不是生死问题，更像一个放了二十年的心结，外加一张廉价的实验门票。

## 二、社交为什么最难：关系链是互联网最深的护城河

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-09/1236cb42f959cdf6.png)

- 原理层面：网络效应近似 Metcalfe 定律——网络价值与节点数的平方成正比。关系链一旦沉淀，迁移成本极高。换一部手机，把聊天记录迁移过去要折腾半小时，但没人会因此弃用微信，因为社交关系不在手机里，在网络上。
- 于是形成经典死锁（deadlock）：没有关系链 → 用户没有打开的动力 → 没有内容消费 → 吸不来新用户。画成架构图，就是两个互相等待资源的进程。
- 战绩佐证：2019 年初多闪、聊天宝、马桶MT 同日发布，号称"三英战微信"，无一幸存；字节坐拥顶级流量池，在即时通讯上照样反复碰壁，最后是靠抖音"内容 + 轻社交"绕开熟人链，才建起自己的关系网。
- 被验证过的路径其实只有两条：
  1. **熟人链路径**：从通讯录和 IM 长出来，代表是微信；
  2. **内容社区路径**：先做内容供给，再沉淀兴趣型弱关系，代表是微博、B 站、小红书。
- 搜狐这次的赌注显然押在第二条路上，而且是更窄的版本：知识内容社区。窄，未必是坏事。

## 三、这次的打法：把创始人当成最大的 KOL

- 2021 年底，张朝阳开播《张朝阳的物理课》，直播推导薛定谔方程、讲黑体辐射和广义相对论，切片进入短视频池，后来出书成系列；加上更早的英语课，他大概是目前唯一把"讲物理"当获客手段的 CEO。
- 把这套组合拳拆成机制看：
  1. **创始人 IP = 近乎零成本的冷启动流量**，不买量、不投流，边际成本极低；
  2. **直播 + 切片 = 持续的内容供给**，解决社区早期"没东西看"的死锁；
  3. **关注流 = 把观众关系沉淀成关注关系**。技术上它是时间线分发、克制纯算法推荐，核心卖点是"创作者的确定性"：我关注的人发了内容，粉丝一定看得到；
  4. **生态目标**：吸引知识型创作者跟随入驻，形成"物理课 → 科学知识社区 → 泛兴趣社区"的漏斗。
- 关于分发路线，有个工程师式的比喻：推荐流把曝光交给模型，创作者的流量是抽奖；关注流把曝光部分还给创作者，流量是储蓄。前者天花板高，后者激励稳。搜狐选的是后者。
- 参照系：罗永浩之于交个朋友、董宇辉之于东方甄选，超头 IP 都是点火器。但 IP 是双刃剑——流量认人不认平台，主播退场往往伴随数据大幅回落。张朝阳自己上阵的独特优势在于：他不会退场，也不存在天价分成谈判。

## 四、怎么给这场仗记分：别用 DAU，用细分生态

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-09/336601fbd791c8c5.png)

- **基本面先看清**：近年依靠游戏业务的现金流和整体降本增效，搜狐恢复了季度盈利，现金储备充裕，没有生存压力。这意味着社交是一张"便宜期权"——成了翻身，不成不伤筋动骨。这与 2011 年前后豪赌微博、卷入视频版权大战时的资源结构完全不同，试错成本被压到了历史最低。
- **时间维度**：张朝阳反复讲"人生是长跑"，从早年带队登山到如今固定早起、每周直播、长期记录课件，个人作息与公司节奏深度绑定。一个 60 多岁、没有任期焦虑、不被外部 KPI 胁迫的创始人，是极少数能承受"十年不温不火"的操盘者——耐心本身就是稀缺资源。
- **风险变量是 AI**：泛知识需求正在被 AI 问答分流，"查资料学物理"未必再需要社区；但直播里的陪伴感、即兴互动和"人味"，短期内难以被模型替代。若能把物理课 IP 延伸成 AI 学习工具，故事还能多长一层。
- **记分方式**：用社交平台的标准（DAU、关系链密度）去打分，这场仗大概率不及格；换成细分社区的标准——创作者留存、人均互动、垂类心智——它有机会做成一门"小而稳"的生意。目标函数不是取代谁，而是在一个足够窄的生态里做到不可替代。

## 五、三条冷思考

1. **创始人 IP 是点火器，不是护城河。** 它能解决冷启动，解决不了关系链沉淀。判断这类项目，别看首月声量，看第六个月的创作者留存率。
2. **先赢下一条窄赛道，再谈网络。** "知识/科学内容社区"比"再做一个微博"胜率高得多：竞争密度低、优质供给稀缺、用户目的明确。大众社交赛道是坟场，细分社区是温室。
3. **耐心资本不一定在机构手里。** 这场仗最大的筹码不是钱，而是"可以输很久"的股权结构与创始人状态。对普通人和小团队同理：选战场之前，先冷静估算自己能承受多久不赢。
