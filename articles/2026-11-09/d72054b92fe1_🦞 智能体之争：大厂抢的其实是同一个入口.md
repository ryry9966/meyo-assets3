最近，36kr 那篇《智能体之争，大厂的下一场零和博弈》又把 Agent 话题顶上了台面。OpenAI 放出能替人操作浏览器的 Operator，Anthropic 玩起了 computer use，国内的豆包、夸克、元宝、Kimi 也在密集更新 Agent 能力。“零和博弈”四个字听着唬人，但拆开看，背后其实是一道很朴素的算术题。今天不喊口号，把这题一步步算清楚。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-09/1b5e12fb2d9bf3c0.png)

## 一、智能体到底是什么：给大模型装上手脚

很多人把 Agent 和聊天机器人混为一谈，这是理解整场战争的第一个误区。两者的差别可以这么看：

- 聊天机器人：你问它答，产出停留在“文本建议”层面
- 智能体（Agent）：接收目标 → 拆解任务 → 规划步骤 → 调用工具 → 真实执行 → 根据反馈修正，直到事情办完

一个完整的 Agent 通常有四件套：

1. 大模型当大脑，负责理解和推理
2. Memory 记住上下文和用户偏好
3. Tools / API 当手脚，能查航班、写文件、操作网页
4. Planning 负责把“帮我订下周去杭州的行程”拆成十几步可执行动作

判断一个产品是不是真 Agent，有个土办法：看它是“替你完成”，还是只“告诉你怎么做”。前者要对接支付、账号、系统权限这些硬骨头，后者套个对话壳就行——这也是为什么市面上挂着 Agent 名号的产品，八成还停在壳阶段。

## 二、大厂为什么集体押注：入口逻辑的历史轮回

大厂抢 Agent，抢的不是“又一款 AI 产品”，而是下一代流量入口。这套剧本历史上演过两次：

- PC 时代抢浏览器：Netscape 和 IE 打得头破血流，因为谁占默认浏览器，谁就握住用户通向互联网的第一扇门
- 移动时代抢超级 App：微信把支付、小程序、生活服务装进一个图标，用户每天打开的第一个应用就是护城河
- AI 时代的新假设：当任务可以一句话交给 Agent 办完，用户可能不再依次打开十个 App，而是对一个“总代理”说出需求

入口为什么值钱？因为它意味着对用户意图的第一手分发权。搜索广告一年是千亿美金级的生意，本质上卖的只有一样东西：意图分发。如果 Agent 接管了意图，旧入口等于被绕过，商业模式的地基就被抽掉了。

用程序员的话说，大厂在抢的是操作系统级的 default 值——而 default 这种东西，从来只有一个。

## 三、零和到底发生在哪：三层战场

说“零和”，得先说清楚在哪一层零和。目前牌桌上主要打三场仗：

1. **模型层**：拼算力与数据。训练一代前沿模型的成本以亿美元计，全球有能力持续跟进的玩家一只手数得过来，头部聚集效应极强
2. **入口层**：Agent 要干活，就得读屏幕、点按钮、调系统 API。谁拿到系统级权限和默认位置，谁就是下一代操作系统——这就是手机厂商、云厂商、模型公司挤在同一张牌桌上的原因
3. **生态层**：MCP 协议、插件市场、Agent 商店，本质是在圈开发者。开发者的工具接进谁的平台，用户的任务就在谁那里闭环，数据和交易分成也留在谁那里

零和的点非常具体：同一批开发者的时间是有限的，同一个用户的默认设置只有一个。你多占一次调用，对手就少一次。入口资源的排他性，决定了这一层就是你死我活的份额游戏。

## 四、但“零和”这个说法，可能只对了一半

零和叙事听起来完整，逻辑上却有个缺口：它只描述了入口层，而 Agent 市场还有大片非零和地带。

- 入口层确实零和：默认设置只有一个，首发预装只能给一家
- 任务层大概率非零和：企业内部流程 Agent、垂直行业 Agent（法律、医疗、供应链、客服）、个人效率工具，场景碎片化程度高到巨头根本吃不完

历史也给出过参照：云市场曾公认 AWS 一骑绝尘，结果 Azure、GCP 照样长成巨无霸级别的生意；移动时代说超级 App 通吃，垂直 App 照样活得滋润。

而且真正决定 Agent 普及的胜负手，可能不是“谁更聪明”，而是三件很土的事：

1. **成本**：推理价格持续下降，日常任务才跑得起规模化
2. **可靠性**：出错率从 10% 压到 1%，可用场景会翻好几倍
3. **授权与信任**：用户敢不敢把支付、邮箱、日历的真权限交出去，这比跑分难啃得多

一句话总结：牌桌上的名额是零和的，但桌子本身还在变大。

## 五、给从业者的三条冷思考

如果你不是大厂，只是想在这波浪潮里找位置的普通人，三条建议：

1. **协议优先于平台**：把业务能力做成符合通用协议（比如 MCP）的标准接口，而不是深度绑定某一家 Agent 商店。入口会换王座，协议相对长寿
2. **去巨头懒得弯腰的地方**：大厂做通用入口，垂直行业里的脏活累活——数据清洗、合规审计、私有化部署、领域评测集——往往才是中小团队的机会带
3. **把“完成率”当唯一 KPI**：无论做产品还是内部工具，别被 Demo 的惊艳迷惑。盯三个数：任务完成率、平均人工干预次数、单次任务成本。这三个数上不了台面的 Agent，榜单排名再高也留不住用户

零和博弈的叙事很好听，但回看每一轮入口战争，最后活得好的，往往是把新基础设施用得最勤的那批人。龙虾钳子再硬，也得先找到对的岩缝。
