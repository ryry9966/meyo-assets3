"token"这个词，几年前还只活在 NLP 论文和 tokenizer 源码里，如今已经是财报电话会上的高频词。据 36kr 等媒体报道，百度把它进一步推上了台面——提出“词元所”，希望让 token 成为 AI 时代的通用计量与结算单位，类比电力时代的“千瓦时”、金融时代的证券交易所。这乍听像概念包装，拆开看其实是一笔很朴素的账：任何产业要规模化交易，第一步都是统一度量衡。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-14/dae9b52b25a58b88.png)

## 词元：大模型世界的“原子”

大模型并不直接认识文字，它认识的是 token。tokenizer（分词器）把文本切成最小可计算的片段：英文常按子词拆分（BPE 算法），一个长单词可能被切成好几块；中文的切分效率各家差异很大——有的模型 1 个汉字约 0.6 个 token，有的要 1~2 个 token。

对使用者来说，token 同时是三样东西：

- **计数单位**：模型输入输出的基本颗粒度，上下文窗口大小（128K、1M）都按 token 计。
- **结算单位**：主流模型 API 几乎都按“每百万 token 单价”收费，输入、输出分别计价。
- **成本单位**：一次“帮我总结这份 20 页 PDF”的调用，输入可能吃掉 2 万 token、输出 2 千 token，账单就是这两笔之和。

为什么按 token 计费而不按次？因为推理成本与 token 规模强相关——长序列下 attention 计算量甚至呈平方级增长，GPU 显存和吞吐也都以 token 为基本盘。按 token 线性计费，简单透明，方便对账。

## 为什么需要尺子：AI 经济缺一套度量衡

历史上每一代产业，都有一把标志性尺子：

1. **电力时代**：千瓦时统一了电能计量，才有了电网定价、跨区域买卖，电才真正成为商品。
2. **石油时代**：桶（barrel）加上 WTI、布伦特基准价，原油才变成可全球结算的标准品。
3. **互联网时代**：DAU、MAU、PV，是流量估值和广告定价的底层坐标。

AI 时代的问题在于：尺子太多且互相不对齐。各家模型 tokenizer 不同，“1 个 token”物理上并不等价；计费口径五花八门，有的按 token、有的按次、有的按订阅；缓存命中与否、上下文利用率高低，能让实际成本差出数倍。没有统一定价基准，就没有透明交易；没有透明交易，应用层的经济模型就算不清账。这是“词元所”想解决的核心矛盾。

## “词元所”想做什么：给 token 建一个交易所

按目前的公开表述，词元所的逻辑接近证券交易所，只是标的从股票换成了 token：

- **挂牌与报价**：模型厂商把能力和 token 单价公开挂出，类似上市公司的信息披露。
- **撮合与结算**：应用开发者按 token 调用、按 token 结算，平台统一清算，省去逐家签约、逐家对账。
- **价值度量**：尺子不只量价格，也尝试量“一个 token 值多少钱”——输出质量、时延、稳定性都可折算进单位 token 的有效价值。
- **生态闭环**：文心系列模型、千帆平台、百度智能云构成完整供给侧，据公开披露其日均 token 处理量已达十万亿量级——结算量越大，制定规则的筹码越重。

这里来一点工程师式幽默：上一代平台经济抽佣靠“数用户”，这一代可能靠“数词元”。

## 这把尺子量得出什么，量不出什么

**量得出的：**

- **真实用量**：token 消耗是目前唯一能跨应用、跨模型横向对比的活跃度指标，比“下载量”“注册数”诚实得多。
- **可预算的成本**：单价 × token 数 ≈ 账单。prompt 压缩、缓存命中、批处理折扣，都能直接折算成钱，成本优化有抓手。

**量不出的：**

- **质量不等价**：A 模型 1 个 token ≠ B 模型 1 个 token。同一个问题，A 用 500 token 答完，B 要 800 token，单价低不等于总成本低。
- **价值不等价**：一个 token 可能是“的”，也可能是推理链上的关键一步。Agent 时代单次任务动辄消耗百万 token，其中多少是“有效词元”，尺子本身量不出来。
- **激励风险**：如果唯 token 论，可能激励模型“多说、说长”，这是典型的古德哈特定律（Goodhart's Law）陷阱——指标一旦成为目标，就不再是好指标。

## 开发者的三个实操动作

1. **建立 token 账本**：把每次 LLM 调用的输入/输出 token 数、缓存命中率、单价记录下来，一周就能画出自己业务的成本曲线。
2. **比价看“每任务成本”，不看“每 token 单价”**：用同一组测试任务跑多个模型，算完成任务的平均总成本，再叠加质量评分，这才是真实性价比。
3. **盯住结算基础设施的进展**：如果 token 定价真的标准化，模型切换和混合调度（router）的迁移成本会大幅下降，议价时手里也多一张牌。

## 冷思考：尺子即权力

度量衡从来不只是技术问题，更是生态位之争。最后留三条判断框架：

1. **谁定义“官方汇率”，谁拿清算权**：token 标准化背后是规则制定权的竞争，历史上每一代计量标准背后都有巨头的影子，token 大概率不例外——关注标准是否中立、开放、可审计。
2. **尺子量的是用量，不是价值**：签约、选型前，先用自己的真实业务数据校准，别直接采信任何平台的公开基准。
3. **值得盯的信号**：token 报价是否变得公开可查、跨厂商结算是否真正跑通。跑通了，AI 应用的经济模型才算真正“通电”；跑不通，词元所就只是又一个品牌叙事。
