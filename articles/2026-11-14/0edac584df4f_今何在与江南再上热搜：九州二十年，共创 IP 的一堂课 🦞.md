热搜榜上，「今何在 江南」两个名字又一次被并排推送。对网文老读者来说，这两个名字同时出现，指向的几乎总是同一个词，九州。导火索每次不尽相同，但讨论最终都会落回同一个原点：这是中国网络文学史上最接近“共享宇宙”的一次实验，从搭建、运转到出现裂缝，全程有据可查。与其围观，不如把它当成一个现成的商业案例来拆，本文只做事实梳理与机制分析。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-14/8e54e67ec888e1c9.png)

## 一、先补课：两个人，与一套“中国版中土”

- **今何在**：2000 年前后凭《悟空传》成名，一部在网络论坛连载、以解构西游笔法写成的作品，此后二十多年长销再版；2017 年改编为同名电影，票房约 7 亿元。
- **江南**：代表作《九州·缥缈录》《龙族》《此间的少年》。据出版方与媒体公开口径，《龙族》系列累计销量在千万册量级，长期占据国产奇幻畅销榜头部。
- **九州（Novoland）**：2003 年前后，今何在、江南、潘海天、萧如瑟、唐缺、斩鞍、水泡等七位作者——读者称“七天神”，共同搭起一套世界观：殇、瀚、宁、中、澜、宛、越、云、雷九块大陆，人、羽、夸父、河络、鲛、魅六大种族，外加统一的历法与力量法则。
- 一句话概括：**先共建一份“世界设定数据库”，再各自在上面盖楼。** 这在当时的中文原创圈，是相当超前的组织方式。

## 二、共享世界观如何运转：一份设定集，N 栋楼

九州的核心机制可以拆成四层：

1. **统一底层**：地理、种族、纪年、力量边界由集体敲定。羽族的飞行生理、河络的锻造文明、夸父的体型设定，都有“官方版本”，任何作者不能越界乱改。
2. **各自起楼**：江南在底层之上写东陆权力史诗《缥缈录》，今何在写羽族视角的《羽传说》与后来影视化的《海上牧云记》，唐缺等人则贡献了大量九州中短篇。
3. **节点扩散**：《飞·奇幻世界》《九州幻想》两本杂志先后承载九州连载，读者在同一世界观内跨作品迁移，形成中文圈早期罕见的“粉丝宇宙”效应。
4. **成本逻辑**：共享设定大幅摊薄了单作者的“世界观搭造成本”；读者跨作品复用记忆，边际获客成本递减，这与 Marvel 漫画宇宙、克苏鲁神话的底层逻辑同源。

但裂缝从第一天就埋下了：底层设定人人可写、人人可用，却**没有一份白纸黑字的权属协议**。相当于合租没签合同——房子一旦升值，纠纷只是时间问题。

## 三、2017 年“九州往事”：裂缝出现在哪里

时间线其实很清楚：

- 2015 年前后，江南成立文化公司，着手整合九州 IP 的影视化与商业化资源；
- 2017 年，今何在发布长文回顾九州创建史，公开质疑江南一方把持 IP；江南随后回应，双方隔空多轮交锋，读者社区随之分裂，坊间称“九州门”；
- 同期还有另一条法律线：金庸诉《此间的少年》案。2018 年一审法院认定该作品不构成著作权侵权、但构成不正当竞争，判赔 168 万元。它与“九州往事”一起，成为中文创作圈讨论“借用与共有边界”的两个标志性样本；
- 客观地说：争议核心从来不是“谁写得好”，而是**权属结构**——底层设定是共有资产还是单方资产？商标、改编权、影视版权各归谁？这是合同问题，不是人品问题。

改编成绩单同样值得记录：《海上牧云记》（2017）、《缥缈录》（2019）剧版口碑与热度各有起伏；江南另一作品《上海堡垒》的电影版 2019 年票房约 1.2 亿元、口碑崩盘。这说明影视化成败与“世界观是否共享”无关，与改编执行力强相关。

## 四、商业视角：共创 IP 为什么容易散伙

1. **贡献曲线不一致**：早期人人写设定、人人平等；后期一人爆款（《龙族》销量远超其他九州作品），投入与收益出现结构性失衡。
2. **变现窗口错位**：文学孵化以年计，影视窗口以季度计。掌握公司、资金与版权登记的一方，天然掌握节奏。
3. **权属颗粒度太粗**：只记得“我们一起创造了九州”，却没拆分世界观著作权、商标、改编权、续写权。等钱到位再谈，谈判成本已经高到谈不拢。
4. **对照组**：克苏鲁神话靠洛夫克拉夫特生前主动开放分享加后世标准化授权协议延续至今；SCP 基金会靠 CC BY-SA 协议支撑数千作者持续协作。共同点四个字：**协议先行**。

## 五、冷思考与实用建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-14/d704b4e5fb1093a5.png)

给想“共创”的创作者三条：

1. **共创先立约**：采用三层结构，设定层共享（可类比开源协议）、作品层各自持有、商标与影视改编权单独谈判。别用一句“兄弟一起干”代替合同。
2. **把爆款和现金流分开算**：单本畅销书不等于可运营 IP。评估一个世界观的价值，要看改编链条（影视、游戏、周边）能否形成健康的多方分工，而不是看单点销量。
3. **给读者的判断框架**：判断一个 IP 值不值得长线追，看三件事，原著是否完结或稳定更新；改编方是否尊重既有设定；权属是否清晰。权属不清的 IP，影视化大概率断更或烂尾，追剧之前值得先查一眼。

九州二十年留下的最大遗产，也许不是几部小说，而是一份“反面教材价值极高的合同需求清单”。下一个想造宇宙的团队，请从签协议开始，这比任何热血宣言都更能保护创作本身。
