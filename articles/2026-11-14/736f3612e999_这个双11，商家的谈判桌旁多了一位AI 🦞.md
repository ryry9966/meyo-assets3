双11走到第17个年头，玩法换了一层皮。2009年首届只有27家商家参与、成交5200万元；如今头部平台全周期成交以万亿计，"卷价格、卷流量"的边际收益越来越薄。36kr 报道里有个细节值得注意：今年不少商家在选品、定价、做素材、投广告之前，会先打开一个对话框跟 AI"商量"——问它该备多少货、优惠怎么设计、素材往哪个方向改。另一头，消费者也把"满300减50、跨店凑单、券上叠券"的算术题直接丢给大模型算最优解。谈判桌两边还是人，但桌边多了一位新角色。这篇就把这件事拆开看：链路怎么变、钱省在哪、坑在哪。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-14/625071c3b3003008.png)

## 从"人找货"到"Agent 找货"：链路本身变了

- **旧链路**：搜索框 + 推荐流。用户迁就系统——想关键词、翻货架、开 N 个标签页自己比价，转化漏斗每一步都在折损。
- **新链路**：AI 购物助手（淘宝"问问"、京东"京言"，海外如 ChatGPT 的购物入口）把流程改成：一句话说需求 → Agent 拆解成查询 → 调工具检索、比价、读评价 → 给出方案，甚至直接代下单。
- **技术拼图四件套**：
  1. LLM 负责理解意图；
  2. Function Calling / 工具调用接商品库和订单系统（Anthropic 2024 年开源的 MCP，就是"模型连工具"标准化的尝试）；
  3. RAG 接实时商品与价格信息，免得模型拿训练语料里的去年价格开涮；
  4. Computer Use / 浏览器操作类 Agent 替人走完点击流程。
- **协议层也在跟上**：2025 年 OpenAI 上线 Instant Checkout，Google 联合多家支付机构推出 Agent Payments Protocol（AP2），Stripe、PayPal 都发布了面向 Agent 的开发工具包。商业基础设施开始默认"对话那一端是个程序"，这是个强信号。
- **一句话含义**：需求入口正从货架迁往对话。谁接住对话，谁就站到了流量上游。

## 商家侧的 AI 账本：钱到底省在哪儿

按"高频、标准化、容错率高"的落地顺序，商家真金白银省下来的主要是五块：

1. **内容生产**。主图、详情页、短视频脚本交给 AIGC。过去外包一条商品短视频几百元、周期好几天；现在平台侧工具（如阿里妈妈"绘蛙"这类免费 AIGC 素材工具）把单条成本打到个位数、出图以秒计。
2. **客服**。大模型版客服机器人接管"什么时候发货""能不能退"这类高频问题，官方口径里独立解决率提升明显；夜间时段尤其香——真人客服排班贵，AI 不要睡觉。
3. **投放**。素材批量生成 + 智能出价，AI 自动组合"图 × 文案 × 出价 × 人群"，把投手手动试错的过程压缩成小时级循环。
4. **经营决策**。对话式生意参谋：问"这款要不要补货""大促预算怎么分配"，AI 基于历史数据给建议，商家拍板执行。"和 AI 商量着做生意"，字面意思就在这一层。
5. **数字人直播**。京东"言犀"等工具宣称成本不到真人主播的十分之一，适合长尾时段开播补量——但转化率与头部真人主播仍有差距，现阶段是"补时段"而非"替代"。

## 深层变化：商品信息要变成"机器可读"

这是最容易被低估的一条。

- 过去做电商优化，卷的是关键词、主图点击率，本质是**给人看**。
- 现在你的第一读者可能是 AI。它读参数表、评价文本、问答区——参数写不全、评价稀薄的商品，在 Agent 眼里近乎不存在。
- 海外圈为此造了个新词：从 SEO 走向 AEO/GEO（Answer / Generative Engine Optimization），让答案引擎愿意引用你。落到国内电商语境，动作其实很朴素：规格参数写全、真实评价留足、常见问题答清。
- 另一面是价格透明化。AI 比价是毫秒级的，"信息差生意"的利润被进一步压薄。对做品牌的商家是利好——差异化终于比价格战值钱；对纯搬运型商家，则是实打实的坏消息。

## 冷思考：三个别急着 All in 的理由

以前商家养投手、养客服、养主播；今年多了个"不要五险一金的实习生"。但它也会犯实习生不犯的错——比如一本正经地编出个不存在的赠品。所以：

1. **幻觉背锅问题**。AI 客服若承诺了不存在的优惠，纠纷算谁的？解法不是不上，而是给它套权限围栏：可说范围白名单、敏感话术转人工、全量对话留痕可回溯。
2. **同质化陷阱**。所有人都用同一批模型生成主图和文案，货架会越长越像。效率上去了，辨识度下来了，品牌调性和独特卖点反而更值钱——那恰好是模型批量生成不出来的部分。
3. **新的攻击面**。Agent 时代的安全题变了：藏在评价里的恶意 prompt 注入，可能指挥对手的 AI 客服乱承诺；经营数据外泄、价格策略被对方的爬取 Agent 整包搬走，都是新风险。生意越自动化，围栏越要提前修。

## 写在最后：3 条实用建议

1. **把商品页当 API 来做**。参数结构化、评价真实、问答完整。你的下一个大客户，可能先是一个 AI——它读懂你，才会把你推荐给人。
2. **从客服和素材两个环节先跑 MVP**。这两处标准化程度高、ROI 好量化（解决率、单条素材成本），跑通了再往投放和定价推；定价权这种事，最后还是留在人手里。
3. **给"人"留位置**。AI 接管标准动作，人守三样：品牌调性、异常场景的判断、对数据的最终拍板。分工清楚，"商量"才是商量；分工不清，AI 只是替你更快犯错的工具。

双11 二十年，从拼手速到拼供应链，如今轮到拼"人机协作的颗粒度"。AI 不是这一届大促的主角，但它大概率是下一届的入场券。
