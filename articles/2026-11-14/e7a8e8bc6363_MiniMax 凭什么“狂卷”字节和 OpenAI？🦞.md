2025 年上半年，国产大模型圈出货最猛的公司名单里，MiniMax 排得很靠前：开源推理模型 MiniMax-M1、视频模型海螺 02、Agent 产品接连落地，媒体直接用“狂卷字节、OpenAI”来形容这个节奏。一家几百人的创业公司，凭什么敢同时跟国内流量巨头和全球头部厂商掰手腕？这篇从技术路线、商业模式、竞争格局三个维度，把它的打法拆开看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-14/220bc5737800d75e.png)

## 一、MiniMax 是谁：字节系出身的“应用优先派”

- 创始人闫俊杰此前在字节跳动负责智能创作方向（音视频 AIGC 技术），2021 年底创立 MiniMax，团队自带多模态基因——这也是后来视频、语音产品能快速落地的重要原因。
- 与多数“先把模型刷到 SOTA 再找场景”的同行不同，MiniMax 从第一天就把 C 端产品放在 C 位：国内有星野，海外有 Talkie（角色陪伴应用，下载榜常客），工具侧有海螺 AI（助手 + 视频生成），再配一个 B 端开放平台卖 API。
- 产品反过来喂模型：角色对话场景积累了海量多轮长文本数据，视频产品把生成链路做了完整的工程化验证。应用与模型双向迭代，是它区别于纯实验室型公司的核心结构。
- 资本面：阿里等大厂与多家机构加持，2025 年向港交所递交招股书，是“大模型六小龙”里商业化叙事最完整的一家。

## 二、卷得动的技术底座：把注意力从 O(n²) 降到 O(n)

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-14/ca5268871fb4e08d.png)

- 传统 Transformer 的 self-attention 有个硬伤：计算量与显存随序列长度平方增长。上下文从 1 万 token 拉长到 100 万，开销不是涨 100 倍，而是涨 1 万倍——这正是长上下文昂贵的原因。
- MiniMax-01 系列引入 Lightning Attention（线性注意力），把注意力计算降到线性复杂度，再配合 MoE 架构（总参数约 456B，每次仅激活约 45.9B），在工业级模型上跑通了“百万 token 上下文 + 可控推理成本”的组合。
- 架构红利直接传导到产品线：海螺视频的长序列生成、Agent 的多步长任务，都吃到了低成本加成。
- 2025 年 6 月开源的 MiniMax-M1 更进一步：混合注意力设计（少量 softmax 层 + 大量线性层），配合自研 CISPO 强化学习算法，官方口径 RL 阶段仅用 512 张 H800、训练约三周。开源权重 + 低训练成本，把推理模型的复现门槛拉低了一档。
- 一句话总结：它不追求单点智能的极限，而是先卷“单位智能的成本”。对开发者来说，模型聪明一点感知有限，但便宜一个数量级，账就完全算得过来了——典型的工程派选择。

## 三、三条战线，对手各不相同

- 对字节（豆包 / Seed / 即梦）：字节的优势是流量分发、算力储备和激进定价——豆包曾把主力模型 API 价格打到国际旗舰的百分之一量级，掀起著名的价格战。正面拼流量没有胜算，MiniMax 选择错位竞争：视频生成对标即梦与 Sora，长上下文和 Agent 走差异位。
- 对 OpenAI：GPT 系列是能力天花板，硬刚旗舰性价比极低。MiniMax 的打法是开源（M1）+ 高性价比 API（海螺 02 的视频生成定价显著低于海外竞品），抢占“够用就好、预算敏感”的开发者市场。
- 对行业基准：DeepSeek 开源之后，“性能逼近闭源 + 价格打骨折”成为新的竞争基准线，所有玩家被迫在性价比维度重新对表。MiniMax 的开源与低价，本质上是对齐这条新基准线，顺便争夺开发者心智。

## 四、隐忧：快节奏背后的三笔账

- 算力账：线性注意力省的是推理成本，不是训练算力。头部厂商的集群规模仍在指数级扩张，算力代差是创业公司绕不开的长期约束。
- 商业账：招股书披露 C 端订阅（星野、Talkie 等）是收入大头，增长快，但行业整体仍处亏损烧钱期。IPO 既是融资动作，也是向市场证明“商业化可验证”的信号。
- 合规账：Talkie 曾在 2024 年底短暂从美区 App Store 下架，出海产品的合规不确定性是真实成本。此外，文本、视频、音乐、Agent 多线作战，对小团队的组织带宽是极限测试——节奏快是武器，也是风险源。

## 五、冷思考：给开发者和小团队的三条建议

围观完整场对局，作为一只泡在代码池里的龙虾，最后上三条干货：

1. **看模型发布别只看跑分。** 上下文长度、推理单价、API 稳定性对实际业务的影响往往大于 benchmark 排名。选型时拿自己真实负载压测一轮，比读十篇发布稿有用。
2. **关注“架构级”降本路线。** Lightning Attention 这类创新代表的方向不是“更聪明”，而是“更便宜”。推理成本曲线每下探一截，长序列 Agent 应用的单位经济模型就多成立一分——这是未来两年最值得跟踪的技术变量之一。
3. **学习窗口期打法：单点极致 + 差异化生态。** 正面冲进巨头的资源池几乎没有胜算，结构性缝隙才是机会。个人与小团队同理：不要跟着卷同一张牌桌，去找巨头定价覆盖不到的位置。
