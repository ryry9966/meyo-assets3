2025 年参加任何一场 AI 行业活动，如果一整天没听到 "Agent" 这个词，那大概率是走错了会场。从 OpenAI 的 Operator、Anthropic 的 computer use，到各家发布会上“一句话订好机票酒店”的演示，Personal Agent（个人智能体）被描绘成下一代流量入口：谁掌握了那个替你干活的“数字分身”，谁就拿到下一个十年的船票。但另一边，不少用户试用三天后默默卸载，投资圈也冒出了“Agent 泡沫论”的声音。共识和泡沫，往往长在同一具身体上——这篇文章把它拆开看。

## 从 Chatbot 到 Agent：到底多出了什么

很多人以为 Agent 就是“更聪明的聊天机器人”，其实差的不止一个量级：

- **记忆（Memory）**：Chatbot 是金鱼，关掉窗口就忘；Agent 要长期记住你的偏好、日程和历史决策，配套的上下文工程、记忆检索（RAG）也在快速成熟。
- **工具（Tool use）**：不止输出文字，还要能调 API、操作网页、写文件、发邮件。Function calling、MCP（Model Context Protocol）这些协议，本质都是给模型装上“手”。
- **规划与自主性（Planning）**：把“安排下周东京的行程”拆成查航班、比价、订酒店、列清单十几步，中途自己处理报错和改签。
- **持续性**：Chatbot 做的是问答，Agent 接的是委托。

一句话总结：从“会说”到“会做”。举例来说，“把会议纪要里的 action items 发给对应的人”，背后是读文档、理解语义、查通讯录、起草邮件、等你确认、发送归档的完整 workflow，而不是一次对话。这不是加一个功能，而是换一套系统，长任务编排、状态管理、错误恢复、权限安全，全是新的工程难题。这也是为什么“demo 惊艳、产品难用”的落差如此普遍。

## 共识的燃料：巨头和 VC 到底在赌什么

1. **技术曲线还在陡峭段**：过去两年模型的推理能力、长上下文、多模态肉眼可见地变强，工具调用成功率持续上升，“Agent 还不够聪明”这个前提正在松动。
2. **成本曲线向下**：单位 token 价格持续下降，让“跑一百步”的长任务在成本上变得可承受。
3. **入口逻辑**：PC 时代的入口是浏览器，移动时代的入口是超级 App，Agent 时代的入口可能是那个替你干活的助手。入口意味着分发权，分发权意味着钱。
4. **协议在收敛**：MCP 等标准出现后，“Agent 连接万物”从口号变成了可以分工推进的工程问题。

参考历史：2000 年互联网泡沫破裂，但亚马逊和谷歌活了下来，并赢下整个时代。**泡沫与共识从不互斥，泡沫常常是共识的预付款。**

## 泡沫是怎么吹起来的：三种典型机制

1. **演示与可靠的鸿沟**。Demo 是一次成功，产品要求千次稳定。Agent 每一步都有出错概率，任务越长，成功率按连乘衰减：单步可靠性 95%，跑 20 步只剩约 36%。工程上这叫“可靠性连乘税”，是当前所有 Agent 产品的头号敌人。
2. **场景先于需求**。不少团队的逻辑是“有模型就能做 Agent”，于是套一层壳做个 wrapper：界面光鲜，但没有独占数据和流程壁垒，模型一升级，仅有的价值直接被上游吸走。
3. **评测失真**。Benchmark 分数与真实任务之间隔着数据污染和场景简化：测试网页干干净净，真实网页有弹窗、验证码和每周改版。发布会上的 Agent 个个能干，毕竟你看到的是导演过的成功案例。

对照 2016 年的聊天机器人热、2021 年的元宇宙：叙事先行、基建在后，中间倒下的，是把叙事当现金流的团队。

## 分界线在哪：四个可操作的观察指标

看到“Agent 创业”或者想入手一款 Agent 产品，先跑这四问：

- **看长尾不看头图**：拿你自己的真实任务去测，而不是复述官方 demo。
- **算单位任务成本**：完成一件事花多少钱、多少时间，是否真的比你自己干划算。
- **看错误恢复**：出错后是优雅回退、主动请示，还是一路狂奔把事情搞砸；关键操作有没有 human-in-the-loop 确认。
- **看数据飞轮**：用得越久，它是否越懂你？私有记忆和偏好数据，是 wrapper 唯一攒得下的护城河。

## 冷思考：三条建议

1. **给用户**：把 Agent 当实习生，不是外包。付款、发送、删除这类关键操作保留人工确认，先从整理、比价、写草稿等低风险任务开始建立信任，逐步放权。
2. **给开发者**：别做“全能助手”，做“某个闭环里的熟练工”。报税、客服质检、代码评审这类垂直场景，边界清晰、易评测、数据能沉淀，反而先跑通商业模型。
3. **给围观者**：区分“方向正确”与“当下成熟”。按 Gartner 曲线判断，Agent 大概率处在期望膨胀期；评估一家公司，看它每周的真实任务完成量，而不是发布会视频。

泡沫不是共识的反面，而是共识的成本，互联网泡沫破灭之后，互联网本身赢了。Personal Agent 大概率也是如此，只是别忘了：潮水退去时，先被泼出去的永远是水分最大的那一批。
