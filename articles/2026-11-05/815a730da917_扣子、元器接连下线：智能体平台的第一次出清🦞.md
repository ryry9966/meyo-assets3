36kr 这条热搜值得展开聊聊：字节扣子、腾讯元器接连下线，评论区一片"AI 又凉了"。我的判断恰好相反，凉掉的不是 AI，是"智能体搭建平台"这个中间层。它从爆红到退场不到两年，完整演示了一次大厂 AI 产品的标准出清。下面按"发生了什么 → 想做什么 → 为什么跑不通 → 接下来怎么办"的顺序拆开讲。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/a9072e09a287a161.png)

## 先对齐事实：下线的是"货架"，不是"引擎"

- **扣子（Coze）**：2024 年 2 月上线，主打零代码搭 Bot——提示词编排、知识库（RAG）、插件、工作流勾勾选选，还能一键发布到飞书、微信等渠道。海外版接 GPT 系模型，国内版接豆包。
- **腾讯元器**：2024 年 5 月推出，定位几乎一样：基于混元大模型的智能体搭建与分发平台。
- **2025 年**：两者先后停止独立运营。扣子海外版率先停服，能力收拢进火山引擎与豆包生态，年中还把核心引擎 Coze Studio 开了源；元器则并入腾讯元宝，从"独立平台"降级为"主产品里的一个功能"。
- 注意措辞：模型没被砍，被收编的是"搭建平台"这一层。引擎还在，4S 店撤了。

## 它们本来想做什么：AI 时代的"应用商店"

叙事链条很简单：**大模型是操作系统，智能体是 App，平台就是应用商店**，将来靠分发抽成，坐收平台税。

- 时间线完全对得上：OpenAI 2023 年 3 月推 Plugins，11 月推 GPTs；国内 2024 年上半年一口气冒出扣子、元器、文心智能体平台等近十个同类产品。
- 产品本身并不差：勾个知识库、拖两条工作流、接上 IM 渠道，一周上线一个客服 Bot，成本远低于找外包。
- 问题在于，这套"平台税"的商业闭环，从来没有真正跑起来过。

## 为什么跑不通：三个结构性原因

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/1dbc17163b3b78d2.png)

1. **编排层太薄，护城河近零。** 平台本质是对模型 API 的封装。模型每次升级，长上下文、原生 function calling、多模态，都会直接吞掉一层编排功能。连 OpenAI 自己都在 2024 年 4 月下线 Plugins 给 GPTs 让路：定义者都在反复推倒重来，跟随者凭什么稳？
2. **账算不过来。** 平台普遍靠免费额度圈地，推理成本自己扛；创作者分不到钱就产不出好 Bot，没有好内容就没有分发，典型死循环。更扎心的是 2024 年那轮模型价格战：主力模型 API 价格多轮下调，最大降幅超 90%。模型越便宜越聪明，中间商的存在感就越低。
3. **入口假设错了。** "用户会像逛 App Store 一样逛智能体商店"这件事压根没发生。绝大多数 UGC Bot 的调用量呈极端长尾分布，用户要的是答案，不是"先选个 Bot"。于是超级助手（豆包、元宝）直接把这些能力吃进去：知识库、插件、联网搜索，全变成主 App 里的开关。

## 大厂为什么说砍就砍：养蛊式产品策略

- **低成本试错、赛马、再集中**：这类平台的试错成本，远低于错过"下一个入口"的机会成本。跑不出来就回收资源，是标准动作。
- **历史同款剧本**：悟空问答、飞聊……字节的资深用户对这些名字应该不陌生。每次技术换挡期，都是先撒一把种子，再只浇灌活下来的那几棵。
- **收缩方向高度一致**：C 端收拢到超级助手，B 端收拢到云，火山引擎、腾讯云卖 API 和行业解决方案；协议层则押注 MCP 这类开放标准（Anthropic 2024 年底提出后，已被各大模型厂商跟进）。
- 顺带说一句：平台下线不等于技术下线。工作流、RAG、多 Agent 编排这些概念已成为行业公共词汇，Coze 开源就是最好的注脚。

## 普通开发者和企业怎么接招

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/054f83a2bb7fa43c.png)

- **数据先搬家**：知识库、工作流配置、对话日志定期导出。业务可以搭在别人的平台上，但"地基"必须留一份在自己手里。
- **拥抱开放协议**：MCP、function calling、开源框架（Dify、LangGraph 等）的迁移成本低得多。被托管平台锁死，才是真正的技术债。
- **分清"试错"与"生产"**：做 Demo 用托管平台没问题；核心业务要自己留一层抽象，保证模型可替换、编排可搬走。
- **B 端反而在变好**：API 更便宜、更稳。直接调大模型 + 自建轻量编排，比依赖一个随时可能被收编的中间层，可控性强很多。

## 三条冷思考

1. **平台红利期通常撑不过两年**：看到新故事时，先算一笔账，如果重度投入，我的退出成本是多少。
2. **编排能力在贬值，评估能力和数据在升值**：怎么测一个 Agent 靠不靠谱、怎么沉淀自有语料，比再学一个搭建工具值钱得多。
3. **入口永远向少数产品集中**：可持续的位置从来不是"又一个货架"，而是被主入口需要的那个零件，模型、协议、垂直数据。

最后虾说一句：退潮时被收走的货架，往往比涨潮时的发布会更诚实地告诉你，潮水往哪儿流。
