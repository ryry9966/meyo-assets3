2025 年，大模型圈发生了一场安静的“换地基”运动：硅谷公司开始成规模地使用中国团队的开源模型。Perplexity 把 DeepSeek-R1 改造成自家模型 R1-1776；微软把 R1 搬上 Azure 和 GitHub；斯坦福团队用不到 50 美元、以 Qwen2.5-32B 为底座蒸出了接近 o1-preview 水平的 s1 模型；Kimi K2 开源后，Groq、Fireworks 等推理服务商第一时间上线，多家 agent 创业公司把它设为默认后端。据路透社报道，Meta 内部甚至为此成立了多个“战情室”。一个来自中国的开源权重，正在变成别人系统里的地基。凭什么？

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/bc71008b706869f6.png)

## 先搞懂：“拿它当底座”到底是啥操作

“底座”（base model）指训练好、可以直接往下盖楼的模型本体。硅谷公司拿它当底座，主要有三种玩法：

1. **直接托管**：把开源权重跑在自己的推理集群或云服务上对外提供服务，微软、英伟达、AWS 都上架了 DeepSeek-R1；
2. **蒸馏（distillation）**：用教师模型生成高质量思维链数据，训练自己的学生模型。斯坦福 s1、伯克利 Sky-T1（训练成本约 450 美元）都是典型，底座大多是 Qwen 或 R1；
3. **继续训练**：在开源权重上做继续预训练、领域微调或强化学习，改造成垂直模型。

算一笔经济账就明白了：从头训练一个前沿底座，成本按亿美元起跳；而一个 MIT 协议的现成底座，等于别人把精装楼盖好了，你拎包入驻，省下的预算全部砸向数据、Agent 和产品层。对预算敏感的创业公司和高校实验室，这笔账不用犹豫。

## 凭什么一：把每一块算力榨到极限

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/26aadbbb6f1f190b.png)

很多人第一反应是“便宜”，但便宜不是天上掉下来的，是架构和工程硬抠出来的：

- **MoE 稀疏激活**：Kimi K2 总参数 1 万亿，每个 token 只激活约 320 亿；DeepSeek-V3 总参数 671B，激活 37B。容量是巨无霸，推理成本接近中杯模型；
- **MLA 注意力机制**：把推理时的 KV cache 压缩 90% 以上，长上下文的显存压力大幅下降；
- **FP8 混合精度 + DualPipe 流水线**：训练时计算与通信重叠。V3 全量预训练约 278.8 万 H800 GPU 小时，按租金折算约 557 万美元——虽只是预训练部分，仍远低于行业想象；
- **MuonClip 优化器**：K2 首次在万亿参数规模大规模使用 Muon，配合 QK-Clip 稳定注意力数值，15.5T token 预训练全程零 loss spike。

一句话总结：在高端算力获取受限的背景下，工程优化被逼到极致，“卡不够，算法来凑”，反而练出了成本护城河。

## 凭什么二：不止开源权重，连“菜谱”都摊开了

闭源厂商只给你 API，等于只卖菜不教做菜。而 DeepSeek、Kimi 的技术报告详细到配方级别：

- **GRPO 强化学习算法**：砍掉 PPO 里昂贵的 critic 网络，用组内相对比较估计优势，显存和算力省一大截；
- **R1-Zero 纯强化学习实验**：不靠人工标注推理数据，纯 RL 让模型涌现长链推理能力，训练日志里甚至出现模型自己写 "wait, wait, wait" 反思的"aha moment"；
- **社区快速复现**：伯克利学生用不到 30 美元在 CountDown 游戏上复现了类似“顿悟时刻”（TinyZero 项目）；R1 发布数月内，1.5B 到 70B 的蒸馏版本遍地开花。

开源的不只是权重，还有“它怎么被造出来”的方法论。对研究者来说，可复现性比榜单分数值钱得多——作业摊开了，抄不抄得明白是另一回事，但至少大家坐在同一张卷子前。

## 凭什么三：协议宽松 + 价格狠

- **许可证友好**：DeepSeek-R1 和 Kimi K2 用 MIT，Qwen3 系列用 Apache 2.0，均可商用、蒸馏、二次分发。对比之下，Llama 带有月活 7 亿需单独授权等附加条款，Gemma 也有使用政策限制；
- **API 价格屠刀**：R1 每百万 token 输出约 2.19 美元，o1 是 60 美元，差二十多倍。闭源对手要么降价，要么像 OpenAI 那样公开讨论开源部分旧模型；
- **自部署的隐性价值**：权重在本地，数据不出内网、不怕 API 断供涨价、可深度定制——对企业客户，这三条经常比价格更打动人；
- **生态飞轮**：Hugging Face 上 Qwen 系衍生模型已超 10 万个，超过 Llama 家族成为最大的开源模型生态。衍生模型越多，后来者越愿意选它当起点。

市场也在用脚投票：R1 发布当月，英伟达单日市值蒸发约 5890 亿美元，创下美股纪录；Sam Altman 罕见公开称赞 R1“性价比惊人”。震动是真实的。

## 上车之前，三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/b4e24c99a12df618.png)

热闹归热闹，真要把开源底座用进生产环境，先想清楚三件事：

1. **开源权重 ≠ 免费午餐**。自部署的真实成本包括 GPU、运维、安全和升级，先算 TCO 再决定“自己跑”还是“调 API”；许可证也要逐条读，MIT 同样有保留版权声明的义务。
2. **蒸馏有天花板**。学生模型学的是教师的输出分布，上限被教师锁死，幻觉和偏见还可能被一并继承。蒸馏适合快速起步，长期护城河要靠领域数据、评测体系和后训练。
3. **排行榜会过期，复现性不会**。选底座别只看榜单，更要看技术报告完整度、权重与代码配套质量、社区活跃度。个人开发者的稳妥路径：先用量化小模型在本地（Ollama、vLLM）跑通全链路，再决定要不要换更大的底座。

回到标题的问题：中国开源模型凭什么被硅谷当底座？答案不神秘——性能够硬、成本够低、协议够宽、配方够透明。开源世界向来只认这四样，和团队在哪个城市无关。
