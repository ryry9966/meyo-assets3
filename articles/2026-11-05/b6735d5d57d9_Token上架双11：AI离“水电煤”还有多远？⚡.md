双十一零点，天猫货架上有口红、有显卡，今年还多了一个奇怪的商品：Token。据公开报道，阿里云把大模型的 token 用量打包上架，几块钱就能买到百万级的推理用量，叠加大促补贴后一度卖爆。开发者圈的反应是“活久见”，但比“活久见”更值得聊的是背后的信号：AI 第一次以“计量商品”的姿态进入大众消费场景。这件事既是价格战打到底的结果，也是观察“AI 基础设施化”进度条的一个切面。这篇拆三个问题：Token 到底是什么；上架开卖标志着什么；离真正的“水电煤”还差几块拼图。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/976f3c54ef724f78.png)

## Token 是什么：AI 时代的“千瓦时”

先补个课。大模型并不直接“读”汉字或单词，而是先用 tokenizer（主流是 BPE 这类分词算法）把文本切成最小处理单元——token：

- 1 个 token ≈ 4 个英文字符、约 0.75 个英文单词；中文取决于分词器，一个汉字大约对应 0.6~1.5 个 token。
- 模型的计算开销和上下文长度成正比，token 就是“长度”的统一度量，地位相当于电表上的千瓦时。
- 举例：让模型写一篇 2000 字短文，输入输出合计大约消耗几千 token；一个 Agent 自动化流程跑一整天，账单轻松上百万 token。

所以“卖 token”的本质，是把 GPU 集群的推理算力按量零售。你在天猫下单的不是什么虚拟币，而是一段“模型替你思考的时长”。

## 上架开卖，标志性在哪

- **渠道下沉**。过去调 API 要注册云账号、过企业认证、读懂价目表；现在淘宝账号 + 支付宝就能下单，决策门槛从“采购流程”降到“顺手加购”。开发者第一次有了“给 AI 交话费”的实感。历史参照：2006 年 AWS 推出 EC2 时，口号就是“像用电一样用服务器”，但云计算真正走进大众视野，靠的恰恰是消费级触达。
- **价格锚点公开化**。国产模型 API 价格战已打了两年：2024 年 5 月，字节豆包把主力模型打到 0.0008 元/千 token，阿里随即将通义系列最高降价 97%；目前主流模型的输入价格普遍卷到几毛到几元/百万 token 量级。把价格直接挂上货架，等于把 B 端价格战做成了全民可见的“AI 物价指数”。
- **供给端的底气**。阿里云财报显示，AI 相关产品收入连续多个季度保持三位数同比增长，token 消耗量已成为云厂商的核心经营指标。货架销售，是“供给过剩 + 需求爆发”交汇处的必然动作。

## “水电煤化”的四道硬门槛，AI 卡在哪

一种东西要成为水电煤，至少要过四关，逐项对照：

1. **统一计量** ✅ 基本达标。“百万 token”已是行业通用计价单位，价目公开透明。
2. **稳定可靠** ⚠️ 部分达标。云厂商 SLA 能承诺 99.9%，但高峰期限流、模型“降智”、版本悄悄切换的情况并不少见。电的要求是“永远在”，AI 目前还是“尽力而为”。
3. **可互换** ❌ 最大短板。电力插座全球标准统一，插上就能用；模型之间只是 API 接口兼容，输出质量和行为风格完全不同，切换有真实的迁移成本。有迁移成本就有锁定，有锁定就不算大宗商品，只能算品牌。
4. **无感生态** ⚠️ 刚起步。电成为基础设施的标志是家电普及（负载端繁荣）；AI 的“家电”是 Agent 和应用，MCP 这类协议正在铺“插座标准”，但生态还在早期。

还有一个关键差异：电价以“十年”为单位平稳，token 价格以“年”为单位跳水——有海外机构（a16z 的 LLMflation 分析）测算，同等能力的推理价格大约每年下降 10 倍。水电煤的核心属性是稳定，而 token 目前更像快速贬值的电子元件。严格说，AI 现在处于“发电站已建成、电网刚架线”的阶段。

## 参照系：电和云计算各用了多少年

- **电力**：1882 年爱迪生珍珠街电站开始商业供电，此后经过电表计量、并网、监管标准化，到 20 世纪中叶才真正变成“墙上的插座”，全程约半个世纪。
- **云计算**：2006 年 EC2 上线，到“上云”成为企业默认选项，大约 15 年。
- **AI**：2022 年底 ChatGPT 引爆，2023–2025 年就完成了价格战、开源冲击、token 上货架三连。周期明显在加速，但协议、可靠性、生态这三件事没有捷径。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/3ead709bdb799801.png)

1. **个人开发者：可以薅，但先看三个细节**——是否限定模型、是否限有效期、续费恢复原价是多少。真实账单的大头通常在长上下文和多轮对话上，用好 prompt cache、batch 接口（普遍五折）和小模型路由，比囤任何大促包都省钱。
2. **企业：别把某家模型的 API 焊死在业务里**。在业务和模型之间加一层兼容网关，评估供应商看“单位任务成本”——完成一次工单、生成一份报告到底花多少钱，而不是单看单价。切换自由度，就是议价能力。
3. **观察者：里程碑不是“上热搜开卖”，而是“没人再讨论价格”**。当模型像插座一样被无感调用、宕机比降价更常上新闻时，基础设施化才算完成。在那之前，token 是商品，还不是公用事业——好消息是，进度条确实在动。
