刷到那条新闻时，我第一反应是把钳子里的计算器按了两遍：硅基流动的 token 礼包进了李佳琦直播间，一百来块钱一包，像话费充值一样被秒空。评论区在欢呼“AI 时代真的来了”，而翻开行业报道，画风突变——这家 2023 年成立、靠大模型推理 API 起家的公司，和它的不少同行，至今仍在亏损。一边是把 token 卖成快消品的火热，一边是账面上的持续失血。这门生意的账本，值得摊开来算一算。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/ec5fb14eed59bd08.png)

## 第一笔账：你买的 token，一半是折旧费

推理服务的成本结构，拆开看长这样：

1. **GPU 采购与折旧**：成本大头。一台 8 卡旗舰级服务器，整机百万元级，按 5 年折旧，每天光折旧就摊掉五六百元，电费、机房托管、带宽、存储另算；
2. **运维与研发**：推理框架工程师、调度系统开发、模型适配，都是旱涝保收的人力成本；
3. **关键性质**：以上几乎全是**固定成本**。服务器买回来那一刻，烧钱速度就锁死了，跟你今天卖出多少 token 关系不大。

所以推理这门生意不是“卖话费”，更像**开电影院**：场租固定、场次照排，上座率不满就是纯亏。token 卖得越多，摊到每一枚上的成本越低；卖不动，账面上只剩失血。

## 第二笔账：单价一年跌九成，成本降不了那么快

- 2024 年 5 月，DeepSeek-V2 把 API 定价打到“每百万 tokens 一块钱”的量级，随后字节豆包、阿里、智谱接连跟进，主力模型价格动辄下调 90% 以上；
- 大厂敢降，是因为它们把推理当**生态入口**：云业务引流、模型开源抢开发者，token 本身允许不赚钱；
- 创业公司不得不跟，是因为开源模型（DeepSeek、Qwen 系列）让推理高度**同质化**——换个 base_url 和 API key 就能搬家，用户比价成本趋近于零；
- 悖论在于：量化、continuous batching、投机解码这些优化每年确实在压低单位成本，但**价格跳水永远快于成本优化**。单价塌方叠加固定成本，毛利率被压成负数，就是这么来的。

## 第三笔账：利用率，才是生死线

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/80193c61b89b122c.png)

- GPU 集群必须按**峰值流量**配置，但流量天然有峰谷：白天业务高峰，凌晨大面积闲置。业内流传的推理集群平均利用率，普遍只有两三成；
- 于是出现峰谷悖论：按峰值扩容，平时机器晒太阳；不扩容，爆点一来（比如 2025 年春节 DeepSeek-R1 火爆时，第三方平台的排队与限流）就只能眼睁睁送走客户；
- 这也解释了“夜间错峰半价”为什么流行——本质就是电影院的周二半价场，把闲置产能打折卖出去；
- 推理平台的真功夫因此不在“有没有 GPU”，而在**调度**：KV cache 复用率、批处理效率、峰谷迁移能力。利用率从 30% 提到 60%，一份亏损报表就能被拉回盈亏线附近。

## 直播间卖 token：那是一笔投放，不是一门生意

- 先说结论：进直播间抢 token 的消费者，和 API 平台的大客户（开发者、企业），基本是两拨人；
- 消费者一百多块买的 token，按现在的定价可能用上好几个月，LTV（生命周期价值）有限，再叠上渠道折扣与佣金，单笔交易大概率不赚钱；
- 那图什么？三件事：**破圈拉新**、**教育市场**（让普通人第一次搞懂“token 是个什么东西”）、**品牌声量**。把它记成市场费用，逻辑立刻通顺；
- 对照组更扎心：云大厂做推理本来就“亏得起”——那是自家生态的引流品；创业公司把推理当主业，同样的价格战，一家叫补贴，一家叫失血。

## 还在坚持的理由：下注 token 消耗量的指数曲线

- Reasoning 模型改写了游戏规则：R1、o1 这类模型回答问题前要先“思考”，单次查询的 token 消耗比普通对话高一到两个数量级；Agent 更是连环调用，跑完一个任务烧掉百万 token 不稀奇；
- 经济学上这叫 **Jevons 悖论**：单价越降，用量涨得越凶，总盘子反而扩大。推理平台赌的正是这条曲线；
- 剧本并不新鲜：云计算早期、打车补贴、视频带宽大战，基础设施生意都是先亏后立，活下来的靠三样——规模摊薄固定成本、技术优化抬升单位毛利、融资撑过窗口期；
- 风险同样直白：若 token 消耗量增速不及预期，或上游模型厂商亲自下场包办推理，中间层就会被两头挤压。

## 冷思考：三条实用建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/7e66af0f64a61021.png)

1. **给开发者**：token 单价大概率还会降，直播间礼包按需买、别囤货；真实成本要看“有效 token”——缓存命中率、思考 token 占比，标价不等于账单；
2. **给从业者**：纯转售推理没有护城河，要么往上游走（模型、推理芯片、自研推理框架），要么往下游走（应用与工作流），卡在中间最危险；
3. **给观察者**：评估一家推理平台，别只盯收入增速，看两个硬指标——单位 token 经济模型（单位毛利 × 利用率）与峰谷调度能力。前者决定能不能活，后者决定能活多好。

token 进直播间，可以看作这个行业最生动的注脚：商品化的价格、工业化的成本、尚未跑通的单位经济模型。亏损不是终局，更像基础设施期的入场费——至于这笔入场费最后能不能换到座位，就看谁的“上座率”先爬上来了。
