2025 年年中以来，两条产品动态在技术圈刷了屏：字节的 Agent 搭建平台「扣子」被曝海外业务调整、团队转向，腾讯的智能体平台「元器」也宣布停止独立运营。36kr 把这轮变化概括为「大厂 AI 产品洗牌清退潮」。很多人的第一反应是「AI 是不是要凉了」，但拆开看会发现，这更像一个行业从狂热期走向收敛期的正常代谢。这篇把下线的产品、背后的机制、以及对开发者的启示，一次讲清楚。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/e428d26f4a3d63e1.png)

## 先搞清楚：下线的到底是什么产品

- **扣子（Coze）**：字节 2024 年推出的低代码 Agent 搭建平台。用户不写代码，拖拽 workflow、挂插件、接知识库（RAG），就能搭出一个 Bot，并发布到豆包、飞书、微信客服等渠道。海外版 coze.com 上线更早，一度是全球增长最快的 Agent 平台之一。
- **元器**：腾讯 2024 年 5 月基于混元大模型推出的智能体平台，主打 QQ、微信生态的分发能力，思路同样是「平台搭 Bot、生态给流量」。
- 它们属于同一个夹层品类：**Agent 搭建平台**。上游接大模型 API，下游服务想「低成本做 AI 应用」的开发者和普通用户，做的是「中间层生意」。

中间层生意的困境在于：模型能力太底层，终端应用太重，中间这层看着什么都沾，实际最容易两头受气——像极了同时被上游和下游 @ 的中台同学。

## 为什么撑不住：中间层的三重挤压

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/845fef619ccafa65.png)

1. **成本端：算力是无底洞。** Agent 不是一问一答。一次「帮我订机票」的任务 = 意图识别 + 调插件查航班 + 比价 + 生成确认，四五次模型调用起步，token 消耗是普通聊天的数倍。平台为了拉新普遍送免费额度，等于平台替用户付 GPU 账单，没有收入对冲就是持续失血。
2. **收入端：付费转化起不来。** 平台主力用户是个人开发者和小团队，付费能力和意愿都有限；真正有钱的企业客户，更倾向采购定制化方案而非 SaaS 月费。获客成本高、ARPU 低，这个商业模型很难画圆。
3. **技术端：能力被两头吸走。** 往上看，基础模型迭代太快——长上下文、function calling、MCP（Model Context Protocol）直接内置进模型和旗舰应用，豆包、元宝自己就能挂 Agent 能力，独立平台的存在感被稀释。OpenAI 的 GPTs 是前车之鉴：GPT Store 上线后，绝大多数使用仍发生在 ChatGPT 主应用里，独立分发从未真正跑起来。往下看，LangChain、Dify 这类开源框架让有技术能力的团队选择自建，工具价值被开源拉平。

再叠加一条**战略逻辑**：大厂 AI 投入动辄上百亿，资源必须向能打的主力集中。扣子之于豆包、元器之于元宝，定位重叠、算力竞争，砍掉边缘、能力并入主线，是教科书式的资源回收。注意，「下线」多数不是推倒重来，而是团队与功能被收编进旗舰应用。

## 不止这两家：AI 应用的清退潮才刚开始

把这轮下线放进更长的周期看，几乎是必经阶段：

- 2023 年「百模大战」，国内一度冒出 200 多个大模型和上千个 AI 应用；
- 2024 年起进入收敛期：据公开报道，阿里将通义 App 能力并入夸克，百度把文心一言 App 收进移动生态整合，一批 AI 社交、AI 陪伴类小产品陆续关停；
- 对照互联网历史，千团大战从 5000 多家团购网站打到只剩头部几家，共享单车、在线教育都走过同一条曲线：**资本涌入 → 同质化 → 补贴战 → 清退 → 头部集中**。

AI 应用的洗牌只会更快：算力成本比当年服务器贵一个数量级，技术栈每三个月刷新一轮，同质化产品根本来不及靠补贴耗死对手，往往先被自己的账单耗死。

## 对开发者：在别人的地基上盖房子，先想好退路

对普通用户，这些平台下线影响有限；对在上面认真搭过 Bot 的开发者，影响是实打实的——workflow、知识库、插件配置都可能要迁移。平台一般会留缓冲期和数据导出通道，但「从头搬一遍」的成本逃不掉。

核心教训是平台依赖（platform lock-in）：你搭的 Bot 逻辑、prompt、知识库，本质上都存在别人的服务器上。地基不是你的，房子再漂亮也只是租来的。

## 冷思考：三条可落地的建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/0f5d4e892932a279.png)

1. **核心资产自己留底。** 知识库原始文档、prompt、workflow 设计放进自己的版本管理（Git），关键逻辑做到模型无关、协议开放（优先用 function calling / MCP 这类标准接口）。换平台时是「搬家」，而不是「重建」。
2. **评估平台先看商业模式，再看免费额度。** 免费额度不是护城河，反而可能是补贴退坡的前兆。接入前问三个问题：这家公司把它放在主线还是边缘？有没有清晰的收入路径？数据能不能完整导出？
3. **场景价值大于平台红利。** Agent 的价值不在「在某平台搭了个 Bot」，而在解决具体业务问题——客服降本、内部工具自动化、数据处理流水线。绑死一个场景、握住一份私有数据，比追任何平台流量都抗周期。

行业的收敛不是终点，而是把资源从「demo 竞赛」挪回「真问题」的过程。潮水退去时没被晒干的，从来不是运气好，是提前备好了自己的泳池。
