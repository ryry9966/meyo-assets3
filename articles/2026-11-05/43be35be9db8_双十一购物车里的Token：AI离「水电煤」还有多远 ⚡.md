今年双十一，天猫购物车里除了口红、显卡和空气炸锅，多了一个奇怪的新品类：Token。百万个 tokens 打包只要几块钱，叠加平台补贴还能更便宜；有开发者的双十一第一单不是给家人买的礼物，而是替公司囤的“算力粮草”。把大模型的计量单位当商品卖，为什么能火出圈？AI 离真正的“水电煤”，究竟还差几步？

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/186d89e14deb076a.png)

## 一、先搞懂：Token 凭什么论个卖

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/3208971a2db87ce7.png)

- **Token 是大模型处理文本的最小计量单位**。英文大约每 0.75 个单词切出一个 token，中文大约 1~1.5 个汉字对应一个 token，具体切法由各家的 tokenizer 决定，略有差异。
- 举例：一句“帮我写份周报”大约消耗十几个 token；一段千字回答，再算上模型要“读”的上下文，几千个 token 很快就没了。
- 为什么按 token 收费？因为推理成本和 token 数量高度相关——每个 token 都要消耗显卡算力、显存带宽和电力，这些开销可以被精确折算到单价上。
- 所以 token 本质上是 AI 时代的“通话分钟”：电表计千瓦时，AI 计 token。

## 二、天猫卖 Token，卖的其实是什么

表面是促销，底下是三件事：

1. **API 销售的电商化**。过去买算力要注册企业账号、走采购流程、预充值签协议，如今像买话费一样下单付款，个人开发者、学生和小微团队的上手门槛骤降。
2. **入口争夺战**。各家模型能力逐渐趋同后，厂商真正抢的是“开发者的默认选项”。用大促补贴让用户完成第一次充值，逻辑与当年的外卖、打车大战如出一辙。
3. **心智定价**。token 第一次被摆上大众货架，价格锚点进入了普通人的认知——“一百万个 token 只要一杯奶茶钱”，这句话本身就是最好的市场教育。

据 36氪 等媒体报道，多家模型厂商的 token 套餐大促期间销量可观，部分爆款多次补货；买家不少是替公司采购的程序员，也有人专门买来送给写代码的朋友——token 成了某种“程序员硬通货”。

## 三、“水电煤”的四个硬标准，AI 补齐了几个

水电煤之所以算基础设施，靠的是四个特征，逐一对照：

1. **计量标准化 ✅**：电表按千瓦时走，AI 按 token 走，即用即付、按量计费已经完全实现。
2. **即开即用 ✅**：一个 API key、几行代码就能接入，不必自建机房，体验接近“插上插座就有电”。
3. **供给无差别 ❌**：任何电厂发的电都一样，但不同模型的输出并不同质，换一个模型效果就变——token 之间目前不可互换。
4. **价格与供给稳定 ⚠️**：电网很少突然断供，模型服务却有高峰限流、版本波动；价格也还在补贴与价格战里起伏。

一句话总结：**管道已经铺好，管子里的“水”还不标准。**

## 四、价格雪崩与杰文斯悖论

- 过去两年，同等能力 tokens 的单价大约以每年一个数量级的速度下降。缓存命中、模型量化、MoE 架构、小模型蒸馏，每一项都在压成本；主流国产模型每百万 tokens 的输入价格，已从早年的上百元降到几元甚至更低。
- 但单价下降不等于总支出下降。19 世纪蒸汽机效率提升后，英国的煤耗不降反升，史称**杰文斯悖论**。token 同理：过去一次人机对话消耗几千 tokens，如今一个 Agent 自动执行任务，动辄调用上百次模型、消耗几十万 tokens。
- 所以“水电煤化”的真正标志，不是价格降到底，而是**全社会的 token 消耗量大到像用电量一样**。英伟达把数据中心称为“token 工厂”——AI 公司本质上是在用电生产 token，这条产业链的上游，确实和电网接在了一起。

## 五、还差三块拼图

1. **互操作**：换电厂不用换电器，换模型却常常要改代码、调 prompt。聚合路由层（类似海外的 OpenRouter 模式）正在补这一块，国内各家也在跟进。
2. **质量 SLA**：电网承诺 99.99% 可用，大模型却存在幻觉、降速和排队。自动 fallback、双模型热备这类“保险丝”设计，还没有成为行业标配。
3. **无感化**：真正的水电煤，用户感觉不到计量单位的存在。未来的 token 大概率会像流量包一样被“包月化”，隐入订阅费或硬件售价里——到那一天，token 才算真正完成基础设施化。

也别忽略物理层：数据中心电力需求正在快速攀升。AI 的“水电煤化”，一半是软件问题，另一半是字面意义上的水电煤问题。

## 六、三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/5a3582b7b37f46e8.png)

1. **囤 token 前先看有效期和适用范围**。大促套餐常限定可用模型或有效期，而模型半年一迭代，囤太多可能贬值。先小量验证效果，再决定要不要放量。
2. **优化“每任务成本”，而不是“每 token 成本”**。开启缓存、精简冗余上下文、简单任务走小模型档位，很多场景能省一半以上——这比等双十一打折更可持续。
3. **别把低价当常态，把可迁移性写进架构**。当前的价格战带有明显的获客补贴色彩；选型时留好模型抽象层和标准化接口，做到“换电不换电器”，才不怕任何一家涨价或停服。

双十一把 token 塞进了购物车，等于把 AI 从发布会拉进了菜市场。至于它什么时候真正变成拧开就有的自来水——大概率不是某个确定的日期，而是某天你突然发现，自己已经很久没留意过它了。
