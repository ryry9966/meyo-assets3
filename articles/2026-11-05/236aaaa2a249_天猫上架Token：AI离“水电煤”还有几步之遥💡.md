今年双十一，天猫的货架上出现了一个新物种：Token。通义千问的 token 套餐像话费充值卡一样被摆上电商页面，用户下单付款，几百万 token 到账，然后在 App 里一点一点“烧”掉。这条来自 36kr 的热议话题之所以出圈，不在于销量有多惊人，而在于它的象征意义——AI 算力第一次以“标品”姿态进入大众消费货架。从“能买”到“像水电煤一样用”，中间还有多远？这篇文章拆开来看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/68e4b2f2567f94a0.png)

## 一、Token 是什么：大模型时代的“度”

- **定义**：token 是大模型处理文本的最小单位。一个汉字大致对应零点几到一点几个 token（各家分词器不同），一个英文单词约 1.3 个 token；多模态时代，图片、音频、视频同样会被切成 token 计费。
- **量级感受**：100 万 token 的文本量级，大致相当于一部《三体》全书的体量。
- **为什么按 token 计费**：你每问一句，GPU 都要做一遍前向计算，算力、显存带宽、电力都是真实成本。token 本质上是把 GPU 时间折算成的“度数”，和电表是同一个设计哲学：用了多少，付多少钱。区别是，电不会因为升级换代突然变聪明，token 会。
- **价格曲线**：2023 年国内主流模型 API 还在“每千 token 几分钱”量级；2024 年价格战开打，有厂商把长文本模型的输入价格降到 0.0005 元/千 token（即 0.5 元/百万 token），一年降幅超过 90%。

## 二、把 Token 搬上货架：一次标志性的渠道实验

- **发生了什么**：token 套餐被做成标准 SKU，加入大促，走完“下单—支付—到账—核销”的完整电商链路。
- **平台在算的三笔账**：
  1. **流量变现的新出口**：双十一的海量流量第一次可以直接为云和 AI 业务导流，电商与算力消费被打通；
  2. **用户教育**：中国用户对“充值”毫不陌生——话费、游戏点卡、网盘会员都是前作，这一步是把“按量付费”心智从开发者扩散到普通人；
  3. **生态卡位**：Agent 时代个人也会大量消耗 token，先占住“购买入口”，就占住了未来的分发权。
- **对行业的意义**：算力从“企业采购合同”变成“购物车里的商品”。公用事业的第一特征恰恰是人人可买、随处可买——这一步算是走完了。

## 三、离“水电煤”还差什么：四个硬指标

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/c37e8e26789d48f8.png)

- **计量标准化**：一度电在哪家电网都一样。但一个 token 在不同模型里“含金量”差异巨大——同样一百万 token，强模型的有效产出可能是弱模型的好几倍，context 长度、分词器口径也各不相同。目前统一的是“计量单位”，不是“产品本身”。
- **价格与供给的稳定性**：电价受监管、多年平稳；token 价格每隔几个月就被新一代模型重写一次，老模型还会下线。你买的不是电，更像一份会贬值、会停供的期货。
- **可靠性 SLA**：电网按 99.99% 的可用性设计；API 则可能限流、排队，高峰期响应质量波动。真要当水电用，先看 Service Level 承诺够不够硬。
- **可替换性**：插座是通用标准，换供电方零成本；模型之间虽有 OpenAI-compatible API 这样的“事实标准”，但 prompt 行为、输出风格、工具调用能力都有迁移成本。
- **一句话小结**：今天的 AI 算力更像“桶装水时代”——品牌化、有溢价、送货上门，而不是拧开龙头就有的“自来水时代”。

## 四、为什么大家又觉得“快了”：三个真实推力

- **推理模型把消耗量拉高一个数量级**：o1、R1 这类推理模型会先“打草稿”再作答，一道题动辄消耗数千 token；Agent 循环执行“感知—思考—行动”，一个任务跑掉几万 token 很正常。单价在降，总消耗在暴涨——教科书级的杰文斯悖论（Jevons Paradox）：效率提升反而推高总需求。
- **成本曲线仍在下探**：MoE 稀疏架构、KV Cache 复用、量化、推理专用芯片，每一项都在压低单个 token 的边际成本。
- **基础设施三件套已就绪**：计量（token）、计费（云账单）、支付（电商+充值）全都齐了。回头看，2006 年 AWS 推出 EC2 时讲的也是“计算像水电一样”的故事——云用了二十年长成基础设施，而 token 的起点比云当年高得多。

## 五、三条冷思考：别急着囤，先学会用

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/ed079a0003723416.png)

1. **按“单位产出成本”选模型，而不是单价**：便宜模型答错一次，重试加返工的 token 和时间，可能比贵模型更贵。把“含重试的综合成本”算进去再做选择。
2. **Token 更像鲜奶，不像黄金**：模型以月为单位迭代，囤大额度的意义有限。购买前看清有效期、适用模型范围和规则细则，把它当消耗品管理，而不是当资产持有。
3. **把自己的 token 用量当水电账单管**：打开用量日志、按项目设预算；prompt 写瘦一点、能命中缓存就命中缓存、简单子任务路由给小模型——省 token 和省电一样，是门手艺。

## 写在最后

电从实验室的灯泡走到墙上的插座，用了几十年；token 从 API 文档走进购物车，只用了一年多。方向已经很清楚，节奏仍然未知。对普通人来说，最好的姿势不是预测哪天“来电”，而是先学会用电——理解计量、管理用量、按需选择。等基础设施真正铺到你家门口时，你已经是熟练用户了。
