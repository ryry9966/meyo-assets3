据 36 氪报道，百度智能云上线了模型交易平台“词元所”，汇集 42 款大模型——既有自家文心系列，也有 DeepSeek 等第三方模型。名字起得很妙：“词元”是 token 的中译，“所”字明显在对标证券交易所。企业用户像逛批发市场一样，按套餐买入不同模型的调用额度。那么问题来了：模型既不是股票也不是电力，“交易”到底在交易什么？这篇就把它拆开讲清楚。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/a4b46ae4aa6bc073.png)

## 一、先弄懂“词元”：AI 时代的“度电”

- **Token 是什么**：大模型不直接处理汉字或单词，而是先把文本切成 token。主流分词器基于 BPE（字节对编码）等算法，一个英文单词常折成 1~2 个 token，一个汉字大约折成 0.5~2 个 token，具体看各家切法。
- **为什么按它计费**：Transformer 对每个 token 都要做一遍矩阵运算，推理算力消耗近似与 token 数线性相关，GPU 时间几乎可以精确计量。于是 token 成了 AI 算力的“千瓦时”。
- **输入和输出不同价**：生成比阅读贵，主流平台的输出 token 单价通常是输入的 2~4 倍。
- **算笔示意账**：一个客服机器人每天处理 5 万轮对话，每轮连上下文平均消耗 4000 token，一天就是 2 亿 token；按“每百万 token 几块钱”的市价折算，月账单就是十万级。词元，就是云厂商财报里的新收入单位。

## 二、“词元所”交易的不是模型，是调用权

机制上，它更像“电力交易所 + 电商货架”的组合：

1. **货架层**：42 款模型像商品一样上架，参数规模、上下文长度、百万 token 单价摆在一起公开比价；
2. **管道层**：企业通过统一的 API 网关调用，换模型基本不用改代码——相当于同一个插座，背后随便切电厂；
3. **结算层**：词元套餐统一购买、统一开票、统一对账，用批发价替代零散充值。

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/740dd587d7949b7f.png)

对企业，好处很直接：接三家模型不再需要三个账号、三份合同、三套对账，还能随行就市换模型。对百度，好处更直接：所有调用流水都从平台过一遍，顺带拉动自家 GPU、存储、网络资源的消费——这就是 MaaS（Model as a Service）的飞轮：模型带流量，流量带云资源，云资源再反哺模型迭代。

## 三、为什么开“交易所”：价格战打不动之后

把时间线拉出来看：

- 2023 年“百模大战”，国内一口气冒出 200 多个模型，同质化严重；
- 2024 年 5 月价格战引爆：字节豆包宣称定价“比行业低 99%”，阿里通义千问最高降价 97%，百度干脆把几款轻量版文心模型转为免费；
- 2025 年初 DeepSeek 以低成本、低价格出圈，把 API 价格进一步打到地板。

结果：卖自家模型这件事，毛利已经薄如纸。当“产品模式”卷不动，“平台模式”就成了下一步——就像电商自营卷到头就做 marketplace，云厂商从卖自家整机转向开商店。开交易所的生意逻辑有三层：

1. 聚合带来规模，规模带来对上下游的议价权；
2. 撮合交易的模式比自营毛利更稳，参照应用商店与云计算市场；
3. “中立”姿态能接住多头下注的企业客户——企业本来就想同时用好几家模型。

据百度披露，其文心大模型日均处理的 token 量在 2025 年初已达 16.5 万亿。换句话说，词元所是把“卖矿泉水”升级成“开自来水公司的收费处”。

## 四、接上“交易所”，怎么用才不踩坑

1. **模型分流**：把 70%~80% 的简单请求（寒暄、FAQ、格式转换）路由给小模型，难题才给旗舰模型，整体成本常见可砍一半以上；
2. **上下文缓存**：system prompt、知识库前缀这类重复内容用 context caching，命中部分通常按五分之一到一半的价格计费；
3. **批处理**：对时效不敏感的任务走 batch 接口，主流平台普遍有五折左右的折扣；
4. **管住输出**：输出 token 更贵，用 max_tokens 和结构化输出（JSON Schema）把废话截住——模型不收快递费，但按 token 收“话痨费”；
5. **RAG 精准投喂**：检索命中的片段精挑几段再塞进上下文，别把整个知识库灌给模型。



## 五、三条冷思考

1. **交易所并不完全中立**：平台既开交易所，又派自家选手上场（文心也在货架上）。推荐位、默认模型、套餐折扣向谁倾斜，值得留意——采购前用自建评测集横向跑一遍，别只看货架上的宣传数字。
2. **别囤词元**：过去 18 个月，主流模型 API 单价普遍跌了一个数量级，今天的折扣套餐半年后可能就是原价。按季度滚动采购，给调整留出余地。
3. **词元不是 AI 成本的大头**：真正的开销在数据治理、评测体系、工程集成和流程改造。把“省 token”当作工程优化的起点，而不是 AI 战略本身；代码里留好模型抽象层，随时可迁移。

一句话总结：模型是电厂，token 是电，词元所想当的是电网。电价大概率还会降，先把自家的布线和电表装明白，才是真省钱。
