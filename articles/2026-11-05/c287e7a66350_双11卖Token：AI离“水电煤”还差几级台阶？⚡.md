今年双11，天猫的搜索框里多了一个奇怪关键词：Token。点进去，百万级 tokens 打包上架，标价个位数人民币，和辣条、洗衣液挤在同一张购物车里，销量一路走高。把“智能”拆成按量计费的商品挂上货架，国内大厂里这是头一回。热闹之余，值得认真回答一个问题：Token 都卖成快消品了，AI 是不是已经是“水电煤”了？先给结论：入门了，但离“拧开就有”还差几级台阶。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/f4834eced162a8a8.png)

## Token 是什么：AI 界的“千瓦时”

- **它是最小计量单位。** 大模型并不直接认识汉字或单词，而是通过 tokenizer（分词器，主流是 BPE 类算法）把文本切成 token。中文里 1 个 token 约对应 1~2 个汉字，英文约 0.75 个单词。比如“人工智能”通常被切成 2~3 个 token。
- **成本天然跟着它走。** 输入要算 attention，输出要一个 token 接一个 token 地生成，历史对话还会持续占用显存里的 KV cache。算力和显存开销基本随 token 数量增减，所以它是天然的计量单位——就像电按千瓦时、水按立方米。
- **“卖 Token”卖的是什么？** 本质是把模型推理服务预包装成充值包：你买到的不是一段代码，而是“调用某模型的 N 份计量额度”。用完即止，按需续费。

## 从 API 到货架：AI“水电煤化”的四步走

- 电力走了一百多年：1882 年爱迪生的珍珠街电站开始供电时，电还是炫技的新鲜玩意儿；直到统一电压频率标准、发明电表、铺成电网，它才真正变成公共事业。
- 云计算是同款剧本：2006 年 AWS 推出 EC2/S3，贝索斯反复讲“算力要像用电一样按需取用”，这个愿景花了近二十年才成为企业的默认选项。
- 拆开看，一种资源“水电煤化”大致四步：**① 技术可用 → ② 成本可计量 → ③ 价格可竞争 → ④ 渠道可触达**。
- Token 卖上电商货架，标志第④步走通：开发者不用注册企业账号、不用约商务谈折扣，加购物车就能充值。**渠道民主化，才是这次“出圈”的真正含义。**

## 价格雪崩：Token 为什么越卖越便宜

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/a58815537a767cd2.png)

- a16z 统计过一个数：同等能力下，大模型推理单价大约**每年下降 10 倍**，业内戏称 LLMflation。对照一下：GPT-4 发布时，百万 tokens 输出要 60 美元；如今同级能力的国产旗舰模型，输出价格已压到每百万 tokens 个位数人民币。
- 降价不是烧钱让利，而是一条工程流水线在持续降本：
  - **架构**：MoE 稀疏激活，每次推理只动一小部分参数；
  - **压缩**：FP8/INT4 量化、蒸馏，把大模型塞进小盒子；
  - **推理优化**：KV cache 复用、投机解码、continuous batching，把 GPU 榨出汁；
  - **竞争**：2024 年以来几轮价格战，部分模型单价降幅超过 90%。
- 一句话总结：电价二十年基本没动，token 价格一年打一折。这不太像“水电煤”，倒像一种**年化通缩 90% 的智能**。

## 离“水电煤”还差四道硬指标

- **互换性。** 插座全球通用的前提是电压频率标准化。而 A 家的 token ≠ B 家的 token：分词器不同、模型能力不同，同样 100 万 tokens 的实际“含金量”能差出几条街。目前 OpenAI 兼容接口、MCP 协议正在充当“事实插座标准”，但“同价不同质”仍是常态。
- **公正计量。** 电表有计量机构背书，token 数目前是厂商自报，用户很难复核——长 system prompt、多轮历史上下文都会悄悄进账单。
- **价格稳定。** 水电煤是相对管制定价，token 是每年 10 倍通缩的资产，“囤货”逻辑不成立：今天囤的额度，明年可能只值零头。
- **可靠性与 SLA。** 电网可用性承诺 99.9% 以上；AI API 还会遇到限流、宕机，以及比宕机更麻烦的幻觉。“来电”和“来对电”，目前还是两回事。

## 冷思考：三件事值得现在就做

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/9f32d29a9659a6e1.png)

1. **开发者：为可移植性设计。** 用统一的 API 网关或抽象层（如 OpenAI 兼容格式）把模型层隔离在业务代码之外，任何一家降价、限流或改版，都能在半小时内切换。Token 本身会越来越便宜，真正贵的从来是迁移成本和被锁定的数据。
2. **团队：把 Token 当电费管理。** 给每个业务设预算和用量监控。Agent 场景下上下文会指数级膨胀，一个失控的循环一晚上能烧掉一个月预算；省 token 的本质是省上下文——少塞废料，多用缓存。
3. **观察者：盯真正的里程碑。** 上货架只是渠道事件；等 token 计量有了第三方审计、跨模型有了互换标准、价格曲线进入平台期，“水电煤”才算验收完成。另外记住一点：未来最大的买家不是人，是 Agent——机器买单的规模，才决定这场基建化的终局。

电用了一百多年才从奢侈品变成墙上的插座。AI 的进度条，大概走到了“路灯已亮、插座尚未标准化”的阶段——这一代开发者要做的事，就是在插座标准落定之前，把自己的电器做成插哪都能亮。
