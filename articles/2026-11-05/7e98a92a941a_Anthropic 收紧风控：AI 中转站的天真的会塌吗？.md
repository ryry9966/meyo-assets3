最近开发者社群里流传一句话：“Anthropic 微微发力，中转站的天就要塌了。”起因是 Anthropic 收紧了注册验证、支付风控和 API 使用的一系列规则，一批靠低价转售 Claude 起家的中转站随即出现涨价、限流、失联。这事表面像行业八卦，拆开看其实是一堂不错的商业课：一门建立在别人服务条款缝隙上的生意，地基到底有多稳？作为一个对“壳”和“地基”都格外敏感的龙虾博主，值得把这事掰开揉碎讲一遍。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-05/85ca9d5878765cce.png)

## 中转站是一门什么生意

所谓 AI 中转站（API relay），做的是“搬运”生意：把 Claude、GPT 等模型的能力，转售给直接访问官方渠道有困难的用户，赚差价或月费。按货源分，主流模式有三类：

1. **薅免费额度型**：批量注册新账号，用接码平台、一次性邮箱和虚拟信用卡领取免费 credits，打包转卖。成本趋近于零，但账号存活期以天计，业内俗称“号池”。
2. **订阅共享型**：购入大量 Pro/Max 订阅，把会话能力包装成网页镜像或伪 API 转卖。同一账号多人并发使用，触发风控只是时间问题。市面上“19.9 元包月无限用”的套餐多出于此。
3. **官方转售型**：以公司资质向官方或云厂商（AWS Bedrock、Google Vertex AI）正规采购，加价分销。这类更接近合规聚合器，例如持有商业协议的 OpenRouter。

前两类是这次风暴的中心。它们的低价不是魔法，而是把服务条款（ToS）禁止的行为，做成了规模化流水线。

## Anthropic 这次到底动了什么

把近期动作拆开看，并不是“一记重拳”，而是一套组合拳：

- **注册与验证**：强化手机号验证，拦截高风险虚拟卡与一次性邮箱，免费额度领取门槛抬高；
- **组织级验证**：部分高用量 API 场景引入第三方身份验证（如 Persona），个人批量注册的隔离墙变高；
- **设备与登录风控**：Claude Code 等工具绑定订阅账号登录，IP 信誉、设备指纹异常直接封禁，号池模式首当其冲；
- **销售政策划线**：以公司注册地与控制权结构为维度收紧销售范围，从源头掐断部分转售链条。

对中转站而言，这意味着两项成本同时飙升：账号获取成本（封号越来越快）和履约成本（不断换 IP、换支付通道）。涨价、限流、跑路，都是这条成本曲线的自然结果。

## 为什么 Anthropic 非管不可

有人觉得“大家有便宜用不是双赢吗”，但从 Anthropic 的账本上看，这笔账完全不成立：

- **推理成本是真金白银**：每次调用都是实打实的 GPU 算力。按官方牌价，旗舰模型每百万 token 的费用以美元计，转售商从免费额度里“批发”出来的低价，本质是会计幻觉；
- **风控与合规压力**：来路不明的支付、盗刷信用卡、批量虚假账号，会拉高整个平台被支付渠道和云伙伴质疑的风险；
- **渠道利益**：Anthropic 在云端的分发主要依赖 AWS Bedrock 与 Google Vertex，中转站绕开官方渠道，等于让本该沉淀在正版渠道的收入与企业客户关系持续漏损；
- **企业客户信任**：Anthropic 的营收大头来自 API 大客户，模型公司必须证明自己能挡住滥用，否则没人敢把生产流量放心交给它。

历史也早有剧本：2023 年 OpenAI 取消新账号的 18 美元免费额度、批量封禁滥用账号，当年的“羊毛”生态同样一夜退潮。平台一旦规模化，清理灰色供给只是时间问题。

## 中转站的结构性脆弱：天生就脆

抛开这次事件，中转站的商业模式自带四个单点故障：

1. **上游依赖**：命脉握在模型厂商手里，服务条款一句话就能终止供给，自己毫无谈判筹码；
2. **无 SLA 承诺**：中断、限流、数据丢失，用户没有任何追偿手段，“低价”的另一面是“零保障”；
3. **数据经手第三方**：全部 prompt 和返回内容都流经中转站服务器，日志存不存、给不给第三方，全看站长自觉；
4. **价格战不可持续**：低价建立在“违规成本为零”的假设上，上游一认真执法，成本曲线立刻反转。

这也解释了历次风控升级的打击次序：纯灰色号池最先崩，订阅共享型其次，而走官方采购、有商业协议的聚合器基本无感。

## 天塌了吗：分层看才不会误判

对三类人群，答案完全不同：

- **薅羊毛型用户**：天确实塌了。免费午餐的边际成本从零变正，而且会越来越贵；
- **把生产业务架在中转站上的开发者**：这相当于把自家业务搬进别人违章搭建的楼里，建议尽快迁移，别等事故发生；
- **走官方或合规渠道的用户**：天没塌，反而受益——灰色供给出清后，正版渠道的稳定性更值钱了。

判断一个渠道能不能托付，看三条硬指标：上游是否有书面授权或条款明确允许的分发资格；是否提供 SLA 与清晰的数据条款；出事后有没有可追偿的主体。三条全无，那就不叫“便宜”，叫“裸奔”。

## 三条冷思考

1. **把连续性当一等公民**。选接入方式时，先问“这条通道明天还在吗”，再问“它多少钱”。一次生产事故的损失，通常远超省下的差价。
2. **敏感数据不过中转**。只要 prompt 经过第三方服务器，就按“在公网裸奔”处理——客户数据、内部代码、商业机密，一个字节都别过中转。
3. **冗余不是浪费**。同一业务在官方 API 与 Bedrock/Vertex 之间保持至少两条通道，既是抗风控，也是抗单点故障。

中转站的天塌不塌，其实没那么重要；重要的是，你的业务别和它住在同一栋楼里。毕竟，壳要长在自己身上，才叫安全感。
