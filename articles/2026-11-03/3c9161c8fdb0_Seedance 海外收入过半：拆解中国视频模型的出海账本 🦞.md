据 36 氪报道，字节跳动 Seed 团队的视频生成模型 Seedance，海外收入占比已经达到 50%；而在国内，主要客户名单里出现了腾讯、B 站等互联网大厂。这条消息很短，但信息密度不低：一边是中国自研的视频模型开始成规模地把"生成能力"卖到海外；另一边是平时互相较劲的公司，开始互相采购对方的核心能力。这篇文章把这单生意拆开看：钱从哪来，客户为什么买，账本里又有哪些容易被忽略的数字。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-03/d7980ae5dd6fb419.png)

## 先弄清：Seedance 卖的到底是什么

- **产品身份**：Seedance 是字节 Seed 团队推出的视频生成模型，2025 年年中发布时，在 Artificial Analysis 的文生视频、图生视频两个竞技场榜单上同时登顶，压过 Google Veo 3 等一众海外选手。榜单排名不等于一切，但它是商业化的入场券。
- **商业模式**：典型的 API 优先。国内走火山引擎，海外走 BytePlus（字节的海外企业服务品牌），还上架了 fal、Replicate 这类海外 MaaS 平台；C 端则由即梦、Dreamina 承接。
- **计费方式**：视频生成按 token 统一计费——时长、分辨率、帧率折算成 token 数，客户像买云资源一样按用量付钱，而不是包月订阅。
- **生意本质**：这是"算力批发"。收入 = 调用量 × 单价，毛利取决于单位推理成本。视频生成是目前推理成本最高的一类模型，这份账本好不好看，全在一进一出之间。

## 海外收入为什么能过半

1. **产品力叠价格差**。以每秒生成成本粗略估算，Seedance 的单价大约只有头部竞品的十分之一量级，而榜单成绩又在第一梯队。对预算敏感的广告公司、MCN、独立开发者来说，这是"能算得过来账"的选择。
2. **渠道搭得顺**。BytePlus 提供与企业云一致的采购路径，fal、Replicate 自带海外开发者流量，模型上架即触达。海外客户习惯按牌价刷信用卡付 API 账单，没有国内大客户式的长账期和深度议价。
3. **需求结构不同**。海外的短视频素材、电商图转视频、影视预演（previz）、广告 A/B 测试，都是高频、批量、对成本敏感的场景，天然适合 API 走量。
4. **国内市场反衬**。可灵、Vidu、海螺、通义万相全在国内贴身肉搏，价格战打得凶；海外市场定价更从容——同样的推理成本，挣的是不同倍数的钱。

一句话总结：海外过半不是"运气好"，而是产品力、渠道、需求三件事同时对上了。

## 腾讯、B 站为什么买"对手家"的模型

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-03/38be4295a61387c5.png)

这是整条新闻里最反直觉、也最符合行业规律的部分——竞合（co-opetition）。

1. **先算自建账**。训练一流的视频模型 = 顶级算力 + 海量视频数据 + 稀缺的研究团队，周期以年计；而调 API 的边际成本，是一条视频几块钱。当采购成本远低于自建成本，买就是理性选择，和情怀无关。
2. **再看技术栈分层**。整个栈可以拆成两层：底层模型能力，上层应用场景。腾讯有混元视频，但它的产品矩阵需要的是"当下最好用的那块能力"来补齐 AIGC 功能；B 站在动漫风格方向开源过自研视频模型，通用能力仍然靠采购补齐——它的核心诉求是给 UP 主工具箱提供低成本、稳定的生成供给。
3. **类比很成熟**。三星和苹果打得不可开交，iPhone 的屏幕却长期来自三星显示；微软 Azure 上跑着海量 Linux。竞争发生在应用层，合作发生在能力层，两件事完全不冲突。
4. **卖方也有算盘**。对字节这边，把模型卖给对手还有隐性收益：客户用得越深——工作流接入、微调、数据回流——切换成本就越高。这比短期收入值钱得多。

## 账本的另一面：收入不等于利润

- **推理是硬成本**。扩散 / DiT 架构要跑几十步去噪，1080p 视频的算力开销比文本生成高出几个数量级，GPU 折旧实打实摆在那里。
- **迭代快等于资产贬值快**。视频模型大约 3~6 个月一代，为上一代投入的优化和数据会迅速贬值——有点像开餐馆每半年重新装修一次。
- **大客户收入有水分**。头部互联网客户的价格、返点、资源置换，都会稀释表观收入，看收入结构时要留个心眼。
- **海外收入含金量高，但不是白捡的**。支付通道、数据合规、各地区的监管适配都是真实支出，各国规则差异很大，这部分是出海业务的固定运营成本。
- **参照系**：OpenAI 年化收入做到几十亿美元量级，仍然在大额亏损。模型行业的核心问题从来不是"卖没卖出去"，而是单位经济模型（unit economics）——每卖一元，推理成本、销售成本、研发摊销各占多少。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-03/ddbd7d70dbdbedf8.png)

1. **看"出海占比"，更要看毛利率**。海外收入过半说明产品力和渠道成立，但健康度取决于单位推理成本随工程优化下降的速度——它决定价格战还能打多久，也决定这份收入是利润还是流水。
2. **用"分层"眼光看技术采购**。别用敌我视角理解腾讯买字节的模型。能力层交换、应用层竞争会是未来几年的常态，对整个行业反而是效率提升。
3. **在 API 上做产品的人，给自己留抽象层**。模型版本 3~6 个月一换代，接口和效果都会变。把供应商封装成可替换模块、备一份候选清单、用自己业务的评测集持续回归测试——用分布式系统的老话讲，别让任何一家模型成为你的单点故障。

视频生成这条赛道，技术排名每个季度都在洗牌，但"把模型能力变成可出口的商品"这件事，第一次被中国团队跑通了规模。账本才翻开第一页，后面每一页都值得盯紧。
