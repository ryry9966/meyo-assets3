最近 36kr 的一篇独家报道给出两组耐人寻味的数字：字节跳动 Seed 团队的视频生成模型 Seedance，海外收入占比已经达到 50%；而在国内市场，主要客户不是散落各处的中小创作者，而是腾讯、B 站这类互联网公司。两句话放在一起，基本勾勒出当下 AI 视频生意的真实形态——一边在海外按美元收钱，一边在本土给“友商”供货。这篇文章拆三本账：收入从哪来、单位经济怎么算、竞争关系怎么处。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-03/ce7478c139bf0d9a.png)

## 第一本账：Seedance 卖的是“能力”，不是 App

- Seedance 是字节跳动 Seed 团队的视频生成模型，主打多镜头叙事（一段提示词直接生成连续多个镜头，角色和场景保持一致）、较强的动作幅度和 1080p 画质，发布后曾在 Artificial Analysis 等第三方评测中登顶视频生成榜。
- 它的商业形态以 API 为主：国内走火山引擎，海外走 BytePlus，同时接入了一批海外模型托管平台。客户买的是“给一段文字或图片，还一段视频”的接口，而不是某个短视频 App。
- 计费逻辑很直接：按时长、分辨率、调用量计价，本质是把 GPU 推理成本翻译成“每秒视频多少钱”。
- 由此推出本文最重要的一个推论：**收入占比 ≠ 用量占比**。海外单价高，同样一次调用换来的收入更多，所以“海外收入 50%”远不等于“海外用量 50%”。

## 第二本账：海外收入凭什么占到一半

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-03/e311ad94abbfd8b2.png)

- **价差是第一推动力。**同类能力，海外按美元计价，单价普遍是国内数倍；国内市场还在反复打价格战，5 秒 1080p 视频的单价已被卷到几块钱人民币的量级。同样一秒视频，在海外卖出更高的价钱是自然结果。
- **渠道差是第二推动力。**海外已经形成成熟的“模型分销层”：托管平台和聚合 API 能把一个新模型在发布当天就铺给全球开发者，上架即放量；国内更多依赖自家云的销售体系，触达周期更长。
- **需求结构不同。**海外广告代理、影视预演（previsualization）、电商素材等 B 端场景付费习惯成熟，愿意按项目、按次采购；国内个人创作者价格敏感，量大但单价低。
- 举个形象的算术题：一个海外广告团队为一次投放批量生成几十版分镜测试片，几百次调用按美元结算；同样的调用量放在国内，收入直接打折。这就是“收入占比领先于用量占比”的来源。
- 一点必要的冷静：这是单一信源的独家报道，"50%"应理解为量级表述。流水和确认收入、是否扣除代金券，口径不同数字能差出不少，看趋势就好。而且这条赛道不缺对手——可灵、海螺、Veo 都在抢同一批客户，渠道和价差的窗口不会一直开着。

## 第三本账：腾讯、B 站为什么买“友商”的模型

- 大厂采购模型和采购云服务是同一套逻辑：**多供应商**。很少有平台把全部模型需求押在一条自研线上，混合调度是常态。
- 能力互补优先于姿态。自家模型解决通用需求，外采模型补特定短板：多镜头一致性、大动作、特定风格，或者单纯这一档性价比更高。采购合同里通常还有量价协议和保底调用量，账算得比外人想象的精。
- 这类事在行业里毫不新鲜：Netflix 的大部分计算负载跑在 AWS 上，苹果的 iCloud 也部分部署在别家云上。竞争归竞争，生意归生意，两张表分开记——友商的钱也是钱，而且是目前最像“好钱”的那种。
- 对内容平台来说，AI 视频主要用在 UGC 创作工具、广告素材生成、动漫化处理、短剧辅助制作这类场景，核心诉求是“接得快、跑得稳、单价可控”，供应商是谁反而最不重要。

## 隐形成本：视频生成这门生意贵在哪

- 技术层面，视频生成要处理时空 token：一秒视频 24~30 帧，主流的 DiT（Diffusion Transformer）架构要做多步迭代去噪，每一步都要对全部时空 token 做矩阵计算，算力消耗比生成同样长度的文本高几个数量级。
- 分辨率、时长、并发数，每一项都直接乘在算力账单上。这也是各家拼命做蒸馏、量化、推理优化的原因——模型每少跑几步去噪，毛利就厚一分。
- 所以要分清两个概念：**收入占比 50% 和利润占比 50% 是两回事**。低价走量的那部分市场，很可能恰恰是不挣钱的部分。谁能把“每秒视频的推理成本”压得最低，谁才有资格谈规模。

## 冷思考：三条建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-03/694e2098c1dbeb44.png)

1. **给开发者与创业团队**：优先用 API 组合能力，把预算花在场景理解和工作流上，而不是从零训模型。动手前先算一笔按时长/按调用计费的成本账，别等账单到了再优化。
2. **给内容从业者**：把 AI 视频当成流水线上的一个工位——分镜预演、素材填充、风格试验，而不是替代整条制作线。沉淀可复用的提示词模板和镜头语言，生产效率的差距往往是数倍级的。
3. **给行业观察者**：判断 AI 商业化别只看 DAU 和榜单，多看两个硬指标——按次付费收入的规模，以及客户复购与续费。对单一信源的“独家数据”，保持交叉验证的习惯，这比转发有意思得多。

下一秒你刷到的视频里，也许就有一段像素来自某个你从没听说过名字的 API。这大概就是模型时代内容工业的日常。
