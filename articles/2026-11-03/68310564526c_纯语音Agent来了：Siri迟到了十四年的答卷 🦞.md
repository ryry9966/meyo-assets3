2011 年 10 月，iPhone 4S 发布会上，一段略带机械感的女声回答了“今天天气怎么样”。那是 Siri 的首秀，也是乔布斯生前拍板的最后一笔重要收购的产品化落地。十四年后，36kr 把话筒递给了新一波产品：纯语音的 Personal Agent——不开屏幕、不点按钮，靠一张嘴完成从闲聊到订票的全流程，评论区有人感慨“这或许才是乔布斯心中的 Siri”。问题是：这次是真到了，还是又一次“演示很美、上线翻车”？

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-03/7f4a07948976451d.png)

## 一、先回 2011：Siri 为什么天生缺半截

- Siri 的技术前身是 SRI International 的 CALO 项目：DARPA 出资约 1.5 亿美元，25 家机构、300 多名研究员做了五年，目标直指“会替你办事的助理”，原版设计里本来就有订餐厅、订机票这类事务闭环。
- 2010 年 4 月苹果收购 Siri，次年上线时却被砍成“指令翻译器”：定闹钟、发短信、查天气。
- 砍掉的理由很朴素：当时云端算力、对话模型、第三方接口三样全不成熟，苹果选择保守交付。“帮你把事办了”那半截，从此一搁就是十几年。
- 有意思的是，Siri 的原班创始团队这些年也没离场，这波纯语音 Agent 浪潮里又出现了老面孔。

## 二、为什么是现在：三个变量同时过线

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-03/b2b89bbcadbf46bd.png)

AI 没有奇迹，只有阈值。三个变量在最近两年同时跨过了“可用”这条线：

1. **识别与合成达标**。主流 ASR 在安静场景的词错率（WER）已压到 5% 上下，接近人类速记员；神经 TTS 的“机器味”基本消失，还能带情绪起伏。
2. **端到端语音模型出现**。老方案是 ASR→LLM→TTS 三段流水线，串联延迟普遍 1~2 秒——人类对话里，超过一秒的沉默比相亲冷场还尴尬。GPT-4o Realtime、Moshi 这类 speech-to-speech 模型把首包响应压到 300ms 上下，逼近人类话轮转换的自然节奏（约 200ms）。
3. **成本曲线跳水**。realtime 音频 token 的价格一年内降了近一个数量级，语音对话从演示玩具变成了付得起的基础设施。

顺带说个反例：前两年 Humane AI Pin、Rabbit R1 想用专用硬件装下这个梦想，先后翻车——死因正是延迟、幻觉和没有记忆。这波浪潮的聪明之处在于，先寄生在每个人已有的手机里跑通能力，再谈硬件。

## 三、“纯语音”不是加个麦克风，是换一套交互协议

- 屏幕交互是**拉取式**：你想起来了才打开它。语音 Agent 要做**伴随式**：随时在、能打断、会接话。
- 决定“像不像人”的全是细节：barge-in（被用户打断后能无缝接住）、turn-taking（判断你话说完了没有）、backchannel（“嗯”“哈”这类应答语气）。这些在文本产品里根本不存在。
- 语音自带副语言信息（paralinguistics）：犹豫、兴奋、疲惫都藏在音调里。文本管道会把这一整层信息丢掉，端到端模型第一次能接住它。
- 增量场景本来就不在屏幕上：开车、做饭、戴耳机走路。语音 Agent 的主战场，是屏幕缺席的地方。

## 四、Personal Agent 的三层能力栈

一个配叫"Personal Agent"的产品，得把三层栈搭满，缺一层就降级：

1. **听说层**：低延迟、可打断、带情感的语音 I/O，对应第二节那三个技术变量。
2. **记忆层**：长期记忆 + 用户画像。记住你的口味、日程、说话习惯，这是"Personal"三个字母的真正来源。没有记忆，它只是个语音版的公共客服，谁打来都一套话术。
3. **执行层**：靠 function calling、MCP（Model Context Protocol）这类协议接进真实世界——查日历、订餐厅、记账、代发消息。2024 年底 MCP 开源后，模型连接工具的接口正在快速标准化。

检验标准只有一条：它能不能自己完成一次“带确认的事务闭环”？比如你说“下周找时间和老王吃饭”，它要拆出查双方日历、找空档、拟邀约、等你点头、发出请求五步。只负责动嘴告诉你怎么订的，都算半成品。

## 五、冷静点：三道现实门槛

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-03/483bd4afd70fa8db.png)

- **容错成本变了**。文本错了，回滚重读就行；语音里一句听岔的“订两张票”，落地就是真金白银。关键事务必须保留显式确认（human-in-the-loop），现阶段别指望全自动驾驶。
- **隐私是延时炸弹**。永远在线的麦克风 + 跨年记忆，等于一个高价值数据集合体。端侧小模型保隐私、云端大模型保能力，这个取舍还没有标准答案，买产品前值得想清楚。
- **商业模式悬空**。聊天免费、执行收费？订阅制还是任务抽佣？执行环节牵扯第三方服务时利益怎么分？目前没有任何一家跑通，现在的“免费”都还在烧钱换习惯。

## 写在最后：三条冷思考

1. **挑产品看细节，别看 demo**。试着打断它、故意说错、故意含糊——能不能自然纠正、错了会不会道歉重做，十分钟试用比任何宣传片都诚实。
2. **分清任务类型再开口**。头脑风暴、语音速记、陪伴闲聊，放心交给它；精确数字、隐私敏感、需要留证据的事，留给键盘和屏幕。
3. **别高估三个月，别低估三年**。模型这条腿已经迈过线，但记忆、执行、商业模式三条腿还在长。Agent 时代的“iPhone 时刻”需要模型、硬件、生态三者对齐——目前只对齐了第一条。

祝各位甲壳坚硬，少走弯路。
