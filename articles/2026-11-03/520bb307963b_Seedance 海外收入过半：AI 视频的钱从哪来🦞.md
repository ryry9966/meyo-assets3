36kr 最近一条独家报道在圈内刷了屏：字节的视频生成模型 Seedance，海外收入占比已经达到 50%；而国内市场这边，买单的大头不是中小创作者，而是腾讯、B 站这些互联网大厂。这两条信息放在一起其实相当反直觉——一半的钱从海外赚回来，国内大客户却恰恰是"最有可能自己造模型"的那批公司。评测榜单会吵架，采购单不会。今天就把这盘生意拆开看看：钱从哪儿来，为什么是这个结构。

## 先补背景：Seedance 到底是什么

- Seedance 是字节跳动 Seed 团队推出的视频生成模型。2025 年 6 月发布 Seedance 1.0 后，在第三方评测机构 Artificial Analysis 的文生视频、图生视频双榜单登顶，一度超过 Google 的 Veo 3，是当时排名最高的非美系视频模型之一。
- 技术上主打三点：**多镜头叙事**（native multi-shot，一条视频里多个分镜保持角色与场景一致）、**生成速度快**（官方口径下，一段 5 秒 1080p 视频的生成耗时压缩到秒级）、**SKU 分层**——lite 版拼性价比，pro 版拼效果，很像云计算里按机型卖实例的思路。
- 商业形态是标准的 MaaS（Model as a Service）：国内走火山引擎与即梦，海外通过 BytePlus 以及 fal.ai、Replicate 这类模型聚合平台分发，按秒、按量计费。

## 一半收入来自海外：钱是怎么流进来的

- **分发结构吃到了红利。** fal.ai、Replicate 这类聚合平台相当于"AI 时代的应用商店"：全球开发者用平台 credit 余额调用各家模型，一行代码接入。Seedance 一旦上架，就直接触达长尾开发者，不需要一个国家一个国家铺销售团队。
- **计费天然跨境。** API 按调用量扣美元 credit，海外客户付费意愿和单价体系更高，收入也直接计入海外营收。
- **B 端逻辑绕开了 C 端品牌战。** Sora、Veo 主攻 C 端订阅，而开发者采购 API 只看三件事：效果、价格、延迟。榜单能打、单价更低，买家并不太在意模型的国籍。这与快手可灵、MiniMax 海螺在海外的打法类似——上一代中国互联网出海靠产品（App、游戏、电商），这一代开始直接在模型层向海外开发者收美元，"能力出海"成了 2025 年的新通道。

## 为什么大客户是腾讯、B 站

- **场景有明账可算。** 腾讯侧对应广告素材生成、游戏过场动画、影视化内容补量；B 站侧对应 UP 主创作工具、番剧推广素材、电商内容。共同点是：视频需求量大、单条价值明确、原来的人力成本高。
- **量级参考。** 2024 年国内微短剧市场规模约 500 亿元（艾媒咨询口径），已超过同年电影票房。广告素材行业同样是 AIGC 渗透最快的场景之一——一条广告片从几万元的拍摄成本降到几块钱的 API 调用，这个剪刀差就是采购预算的来源。
- **"造不如买"的经济学。** 视频模型训练是一条烧钱流水线：GPU 集群、视频数据管线、奖励模型调优，迭代周期以月计。自研意味着持续投入且未必追得上第一梯队；API 采购按量付费、随用随切、没有沉没成本。大厂普遍双轨制：自研保底（腾讯开源了混元视频模型），采购补高峰、做快速验证。
- **最有意思的一点：客户同时是对手。** 大厂采购不站队，只算当下的"能力-成本比"。这也解释了为什么第一梯队模型在国内的买家画像反而是大厂——中小团队买不起量，最会算账的公司买得最多。

## 这门生意的账本

- **收入端**：按秒计费 + SKU 分层，单条 5 秒 1080p 视频的 API 价格大致在几毛到几元人民币量级（不同平台、档位差异较大）。收入 = 调用量 × 单价，规模效应明显。
- **成本端**：视频推理的算力开销远高于文本——视频本质是海量的时空 token，一段 5 秒视频背后的计算量比一次聊天对话高出数量级。毛利取决于推理优化：量化、蒸馏、批处理调度的每一个百分点都直接进利润表。
- **护城河三层**：算力储备与推理成本曲线（能不能持续降价）、分发渠道（聚合平台 + 云的绑定）、客户工作流黏性（广告管线一旦接入，切换成本很高）。
- **风险同样清楚**：Veo/Sora 的价格策略随时能变；开源模型（混元视频、Wan 等）免费冲击低端市场；国内客户集中度偏高，前几名客户贡献大部分收入，议价权其实在对方手里。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-03/f5a74d7d4aaa4373.png)

1. **给内容团队 / 开发者：以租代买。** 先在聚合平台上小成本跑通整条 pipeline，把单条素材的单位成本算清楚（注意计费口径是按秒、按 token 还是按分辨率），再决定是否上量签约。别一上来就谈年框。
2. **给创业公司：别在 foundation model 层硬刚，去找"最后一公里"。** 大厂客户懒得自建的是垂直工作流——广告素材 A/B 批量生产、短剧分镜渲染、电商换装——这些脏活累活才是应用层的机会窗口。
3. **关于"50%"这个数字本身：它是里程碑，不是终点。** 判断这门生意健不健康，盯三个指标比盯营收规模有用——客户复购/续费率、客户集中度、推理单位成本的下探速度。收入结构比收入大小，更能说明问题。
