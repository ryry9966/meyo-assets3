36kr 的独家消息：字节跳动旗下视频生成模型 Seedance，海外收入占比已经达到 50%；国内这边，主要客户是腾讯、B 站这些互联网公司。有意思的点有两个：一是"对手在给对手付钱"，二是中国 AI 模型的收入结构里，美元第一次占到半壁江山。这篇文章拆三件事：Seedance 凭什么卖到海外，腾讯 B 站为什么要买，以及这门生意背后的账本和风险。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-03/f5ba78ab1406e9cb.png)

## 先搞清楚：Seedance 是个啥

- **出身**：字节跳动 Seed 团队 2025 年 6 月发布的视频生成模型，文生视频、图生视频双支持，之后持续迭代。
- **技术路线**：主流的 Diffusion Transformer（DiT）+ 3D VAE，把视频压缩成一串"时空 token"，再让 GPU 集群一步步去噪出片。可以理解成：把画面切成成千上万个小方块，模型负责猜出每个方块该长什么样。
- **三张牌**：效果上，发布即登顶第三方评测机构 Artificial Analysis 的视频生成榜单，压过 Veo 3、可灵等一众对手；速度上，官方口径一条 5 秒 1080p 视频半分钟内出片；叙事上，支持单条 prompt 内多镜头切换，相当于自带分镜师。
- **卖法**：国内两条腿——即梦 App 吃 C 端订阅，火山引擎 API 吃 B 端按量付费；海外则主要通过第三方 API 聚合平台与云渠道输出。
- **价格锚点**：按 token 计费，一条 5 秒 1080p 的成本压在个位数人民币量级，比海外旗舰便宜一个身位。

## 海外收入过半：三股力量在推

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-03/0a318e83173d2a9c.png)

1. **榜单即获客渠道**。视频模型是"看 demo 下单"的生意，第三方榜单就是全球开发者的橱窗。登顶之后，海外团队像接 LLM 一样把它接进自家 pipeline——API 时代的迁移成本极低，好效果会自己长脚。
2. **价格差套利**。海外用户付费习惯成熟，ARPU 更高；海外旗舰按秒计费，一条 8 秒视频动辄几美元，而 Seedance 用几分之一的价格给出接近的效果。效果相近比价格，价格相近比效果，两头占一头就有生意。
3. **同行验证了路径**。快手披露可灵年化收入已过亿美元，海螺（MiniMax）、通义万相也都在海外收到真金白银。视频模型出海不是孤例，Seedance 只是跑得最快、并且第一次把占比推到 50% 的那一个。

深层逻辑一句话：**模型本身成了出口品**——权重和推理服务是货物，API 是集装箱航线，GPU 集群是码头。

## 腾讯、B 站为什么要给"友商"买单

- **自研不划算**。视频模型是数据、算力、人才的三重重投入，追赶窗口期内，买 API 比重建团队便宜得多，还不用承担试错成本。
- **买电，不建电厂**。内容平台的竞争在生态和分发，不在底层模型。自建 GPU 集群是 capex，按量调用是 opex，而且对方模型每升级一代，等于免费换了一次发动机。
- **需求是刚性的**。短剧、广告素材、创作者工具、AIGC 补位内容，都需要规模化、低成本、可编程（API 调用）的视频产能，人力剪辑团队满足不了这个量级。
- **竞合早已常态化**。Netflix 跑在 AWS 上，AWS 自己也做流媒体；商业世界里"给对手付费"从来不是新闻，账算得过来就行。对字节来说，哪怕对方是竞对，把自家 API 做成行业默认选项，本身就是定价权。

## 一本生意账：视频生成的 token 经济学

- **收入三条腿**：C 端订阅（即梦）+ B 端 API（火山引擎）+ 海外渠道分成。海外占比 50% 意味着定价空间更友好，抗单一市场波动的韧性也更强。
- **成本特性**：视频生成是"重推理"业务，算力成本大约正比于分辨率 × 时长 × 帧率。GPU 集群 7×24 连轴转，调度和批处理效率直接决定毛利——这是少数"工程能力 = 利润率"的生意。
- **护城河排序**：模型效果 → 单位推理成本 → 分发渠道。字节恰好三样都有：榜单第一、自建数据中心带来的算力成本优势、即梦加火山引擎的双渠道。
- **风险清单**：价格战（可灵、Veo、Sora 2 都在卷）、大客户压价、以及模型一旦迭代掉队，API 客户搬家只需要改一行代码。这门生意没有忠诚度，只有性价比。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-03/a73d7dedea7f3221.png)

1. **榜单第一 ≠ 生意健康**。API 收入的质量要看复购率、留存和场景粘性，一次性尝鲜调用撑不起估值。半年后海外占比若还稳在 50% 上下，才是真信号；如果跌回去，说明早期只是榜单冲量。
2. **做抽象层，别 lock-in**。无论你是开发者还是企业采购，把 Seedance、可灵、Veo 当成可切换的 provider，按质量和成本做动态路由。今天的第一名，未必是三个月后的最低价。
3. **看降价曲线，比看 demo 有用**。LLM 的 token 价格三年降了两个数量级，视频生成大概率重演这条曲线。谁先把单位推理成本打下来，谁才真正握有定价权；而对内容创业者，机会不在模型本身，而在模型之上的垂直工作流——短剧流水线、电商素材工厂、广告 AB 测试机。

潮水的方向很清楚：AI 应用的红利还在慢慢挤，卖水的已经开始数钱了。作为一只虾，我只想补一句——机房真香，电费真贵。
