最近科技圈一条热搜看着像"半导体八卦"，实则干货十足：英伟达被曝将在下一代平台推出自研服务器 CPU（代号 Vera），而且据多家外媒披露，它没有跟随行业主流的 Chiplet（芯粒）路线，而是回归单 die（整片裸片）设计。一边是 AMD、Intel、苹果们把芯片越切越碎再拼回去，一边是英伟达反手把芯片"焊"成一整块。刚成为行业共识没几年的 Chiplet，真要被推翻了？先给结论：不是推翻，而是一次教科书级的"按账本选路线"。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-06/9642e54a0b774a3a.png)

## Chiplet 是怎么成为行业共识的

先把概念钉牢：Chiplet 就是把一颗大芯片拆成若干小"芯粒"，分别流片，再用先进封装拼回一颗芯片。它走红靠的是三本账：

- **良率账**：晶圆缺陷密度一定时，die 面积越大良率越低。用简化泊松模型估算，缺陷密度 0.1/cm² 时，100mm² 的 die 良率约 90%，600mm² 就会跌到 55% 左右。切成小芯粒，等于把废片损失摊薄。
- **成本账**：逻辑核心用最先进制程，I/O、接口这类"跑得慢"的模块用成熟制程，混搭省钱。
- **灵活账**：同一组芯粒按数量增减，就能拼出从 8 核到 192 核的产品矩阵，SKU 极速扩展。

案例随后排队入场：AMD 从 Zen 2（2019 年）起用 Chiplet 重写服务器市场；Intel 自 Meteor Lake 起全面转向 tile；苹果用 UltraFusion 把两颗 M1 Max"缝合"成 M1 Ultra；连英伟达自己的初代 Grace CPU Superchip，也是两颗 die 用 NVLink-C2C 拼的。2022 年 Intel 牵头成立 UCIe 互连标准，AMD、Arm、台积电、三星悉数加入——Chiplet 至此从"厂商私有技巧"升格为"行业标准动作"。

## Vera 的"反常"：一颗整 die 背后的四本账

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-06/9fc2b4364a4d3cbc.png)

据报道，Vera 约 88 核、ARM 架构、采用 3nm 级制程，是一颗单 die，而非像初代 Grace 那样双 die 拼合。看着反常，摊开账本其实不反常：

1. **摊薄账**：在一套 NVL72 机柜（媒体报道售价约 300 万美元）里，GPU 和 HBM 才是成本绝对大头，CPU 只占零头。Chiplet 省的是 CPU 自身的制造成本，摊到整机层面边际收益很小，却要额外付出封装与互连开销。
2. **互连账**：die-to-die 互连不是免费的，每 bit 都有功耗和延迟成本。对一颗要和 GPU 深度协同、共享统一内存的 CPU 来说，内部总线越"直"越好——少过一次桥，就少一分延迟。
3. **产能账**：CoWoS 这类先进封装近两年一直是全球稀缺资源，优先留给 GPU 和 HBM。CPU 若也要封装拼合，等于跟自家 GPU 抢产能。
4. **家底账**：英伟达本来就是"大 die 玩家"，Blackwell 单颗 GPU 就是两块逼近光罩极限的大 die 拼合，die 间靠 10TB/s 级的 NV-HBI 互连。它并不排斥切分，而是只在"必须切"（超过单 die 面积上限）时才切。3nm 密度提升后，88 核重新装得进一块 die，单 die 自然成了更划算的选项。

## 单 die vs Chiplet：不是推翻，是分工

把镜头拉远会发现，行业本来就不是"全员 Chiplet"：

- AMD 最新 Zen 5 的 CCD 内部其实是单 die，Chiplet 体现在封装层；苹果标准款 M 系列长期是单 die，只有 Ultra 版才缝合。所谓共识，一直是"按需取用"。
- **Chiplet 占优的场景**：出货量大、SKU 多、需要混搭制程、要复用 IP、要绕开光罩尺寸上限——通用服务器 CPU 是典型。
- **单 die 占优的场景**：追求极致带宽与延迟、系统高度耦合、软硬件全在自己手里、出货集中在少数旗舰——AI 超级集群里的专用 CPU 是典型。

英伟达的选择更像"系统厂商的算法"：当 CPU 只是 AI 机柜里的一个零件时，为它单独做 Chiplet 化，就像给 F1 赛车的备胎做轻量化——方向没错，但优先级存疑。

## 这场"逆行"会改变什么

- **封装格局**：CoWoS、EMIB、Foveros 的需求结构会随产品分化，ABF 载板、KGD（已知良好裸片）测试环节的价值持续上升。
- **标准生态**：UCIe 阵营仍在扩张，die-to-die PHY IP 成为新的竞争点。而芯片之间的高速互连（NVLink、CXL、高速以太网）依旧是刚需，这块和单 die 路线并不冲突。
- **后发者的路**：对不在最先进制程第一梯队的厂商，Chiplet 提供了"成熟制程 + 先进封装"组合追赶的现实路径。多家第三方机构预测，Chiplet 相关市场到 2030 年后仍是数百亿美元量级的增长曲线——一颗 Vera 改变不了这条曲线的方向。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-06/80a6e3e302dd0a1a.png)

1. **看标签不如看账本**：评估一颗 CPU，别问"是不是 Chiplet"，去问四个数——互连带宽、延迟、功耗预算、封装成本占比。路线是手段，账是目的。
2. **技术路线是螺旋，不是直线**：上世纪 90 年代的多芯片模块（MCM）→ 2000 年代的单芯片 SoC → 今天的 Chiplet，"合久必分、分久必合"。在任一条路线上押下全部信仰的人，历史上都补过学费。
3. **真正的分水岭是生态位**：英伟达敢用单 die，因为它卖的是整柜系统；通用 CPU 厂商坚持 Chiplet，因为它们卖的是灵活性。判断哪条路线会"赢"之前，先看清自己站在哪个位置。

一颗 Vera 推翻不了 Chiplet，正如当年 Chiplet 也没能一口吞下单 die。半导体行业没有信仰，只有算得过的账和算不过的账。
