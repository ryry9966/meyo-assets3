最近 36kr 把一件事推上了热议：OpenAI 研究员姚顺雨公开“摇人”——在社交平台发帖喊话、转发岗位、明示团队在招人，评论区被求职者和围观群众挤爆。一个研究员的招聘动作能引发这么大动静，乍看反常。但把它放回 AI 行业这盘棋里看，逻辑相当清楚：这不是吃瓜素材，而是一次关于“顶级人才如何被定价、如何被挖动”的公开示范。这篇就把它背后的机制拆开讲清楚。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-06/0405b946cce03a5c.png)

## 先搞清楚：他凭什么“摇”得动人

- **履历一句话版**：清华本科（据公开资料），普林斯顿博士，2025 年加入 OpenAI，主攻方向是 agent。
- **ReAct**（2022，ICLR 2023）：让 LLM 在“思考（Reason）”与“行动（Act）”之间交替循环，把模型接上工具与环境。今天几乎所有主流 agent 框架里都能找到它的影子——一个伪代码级别的简单思想，被整个行业复用。
- **Tree of Thoughts**（NeurIPS 2023）：把线性思维链升级成可分支、可回溯、可搜索的树状推理。
- **SWE-bench**：用真实 GitHub issue 考“改 bug”的评测集，如今是软件工程 agent 的行业标准考场。
- **长文《The Second Half》**（2025）：提出 AI 研究进入“下半场”——新方法不再稀缺，稀缺的是定义问题、设计评测的能力。

结论很简单：他的号召力不是热搜给的，是论文、benchmark 和长文垒出来的。在 AI 圈，摇人不靠嗓门，靠 citation。

## “摇人”机制：为什么熟人内推在 AI 行业效率最高

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-06/eb8e1bc76a48ff51.png)

- “摇人”直译就是喊人、拉人，落地动作是“熟人内推 + 公开喊话”的组合拳。
- **链条长这样**：A 曾和 B 共事 → A 判断 B 属于 top 5% → A 直接把 B 的论文甩给实验室合伙人 → 越过 HR 直达决策层。信息保真、速度快、试错成本低。
- **原因一：研究能力极难量化。** 简历会撒谎，benchmark 会说话；一封来自可信研究者的背书，能砍掉绝大部分筛选噪音。顶级实验室的招聘里，内推权重长期高于海投。
- **原因二：人才密度优先于人数。** 头部 lab 普遍信奉小而精——招错一个高级别人选，成本远不止薪水，还有算力预算、项目方向和团队氛围。“宁缺毋滥”不是姿态，是算过账的。
- **原因三：公开喊话本身就是定向广播。** 真正的大牛不刷招聘网站，属于被动候选人；一条有信息量的帖子，等于对目标人群做零成本广告，顺带完成雇主品牌建设。
- **行情佐证**：据 36kr 及多家外媒报道，2025 年头部实验室之间的挖角报价屡创新高，资深研究员总包可达七位数美元，个别案例被曝更高。听着夸张，本质是为“关键少数撬动巨额算力资本”的边际产出付溢价。

## 为什么是他：稀缺研究员的四个定价因子

1. **定义过范式**：能提出被全行业复用的方法论（ReAct）的人，在劳动力市场上接近孤品。
2. **掌握评测权**：做出 SWE-bench 这样的标准考场，等于握有“模型到底行不行”的裁判权——下半场这正是稀缺资源。
3. **能写能讲**：《The Second Half》没有一个实验，却影响了整个行业的议程设置。写作是研究员的放大器，这点长期被低估。
4. **方向踩中主战场**：agent 与 RL 是当下各家 lab 的投入重心，个人稀缺性被行业周期再放大一层。

换个角度：研究员的平均产出和顶尖产出之间差着数量级，公司给后者的是“期权式”报酬——赌的是他参与的方向能跑通，跑通后的回报远超薪资本身。

## 行业信号：摇的其实不是人，是方向

- **主线迁移**：从 2023 年的 chatbot，到 2025 年的推理模型、coding agent、computer use，行业重心明显从“会聊天”转向“会干活”。
- **下半场逻辑**：预训练、RL、工程化这些方法层在趋同，差异化越来越来自问题定义和评测设计，所以 lab 愿意重金买入“会定义问题”的人。OpenAI 的 Codex、Anthropic 的 Claude Code 都把 coding agent 当战略产品线，评测与环境建设成了竞争壁垒的一部分。
- **全球同步**：不只是海外，国内大厂与创业公司同样在 agent 和基座模型上加码，人才回流与出海并存。抢人不是孤立事件，是能力竞赛的伴生现象。

## 冷思考与三条实用建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-06/409998a73cfcf78a.png)

冷思考放最前面：**摇人是结果，不是原因。** 先有代表作，才轮得到你摇别人；顺序反了，喊破喉咙也只是单向广播。

1. **作品 > 简历。** 把一个想法做到“被同行复用”，比堆十段经历值钱。开源一个工具、维护一个 benchmark、写一篇讲透问题的长文，都是最硬的信用凭证。
2. **选平台看杠杆，不只看薪资。** 算力额度、数据质量、同事水平、反馈速度，这些决定你五年后的上限；能量密度高的地方，成长是非线性的。
3. **把写作当杠杆练。** 能用一页纸把复杂问题讲清楚的人，在任何团队都是稀缺品。表达不是包装，是研究工作流的一部分。

抢人大战还会继续，价格大概率还会涨。但对个体来说，真正的问题从来不是“要不要被摇”，而是“你手里有没有值得被摇的东西”。
