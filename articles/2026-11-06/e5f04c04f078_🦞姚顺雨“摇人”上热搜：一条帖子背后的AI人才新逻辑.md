“摇人”，原本是开黑打游戏时喊队友的黑话，最近却成了 AI 圈的正式动词——从喊人打排位，到给前沿实验室喊人，这个词完成了职业生涯的跃迁。据 36kr 等媒体报道，OpenAI 研究员姚顺雨多次在社交媒体上公开为团队“摇人”，相关帖子在中文科技圈刷屏。一条招聘内容能上热搜，本身就值得琢磨：它不只是热闹，而是观察前沿 AI 实验室如何找人、如何组织的一个绝佳切片。这篇文章就把“摇人”背后的人才逻辑、组织逻辑，以及对普通从业者的启示，逐一拆开。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-06/c4b12c23460e9e6a.png)

## 一、先看“摇人”的人：一份 agent 时代的标准履历

为什么是他摇得动人？先看履历：

- **教育背景**：清华本科，普林斯顿大学博士，主攻语言模型与 agent 方向。
- **2022 年，一作 ReAct**：让模型把“推理（Reasoning）”和“行动（Acting）”交替进行——先想一步，再调用工具做一步，看结果再想。这篇论文成为大模型 agent 领域被引用最多的基础工作之一，今天各家 API 里的 function calling / 工具调用范式，都能看到它的影子。
- **2023 年，参与 Tree of Thoughts**：把搜索树引入语言模型的推理过程，让模型学会“分支探索、回头纠错”。
- **2024 年前后，推动推理时扩展（inference-time scaling）**：不加大模型参数，靠多采样加验证器也能显著提升表现，这条路线后来成了行业主战场之一。
- **2025 年，加入 OpenAI**（据其本人与公开报道），聚焦 agent 方向。

一句话概括：他的研究主线，正好是“让模型从会说话变成会做事”。这条线三年前还算冷门，如今是全场焦点。**人随问题走，影响力也随问题涨**——这是理解“摇人”为什么成立的第一块拼图。

## 二、“摇人”摇的是什么：一条帖子背后的招聘机制

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-06/d407cf6f1f5d50a6.png)

传统招聘和“公开摇人”的差别，可以拆成四层来看：

1. **分发层**：猎头是点对点，帖子是广播。社交媒体的推荐算法会把内容主动推给“可能感兴趣的人”，一条帖子的理论触达是几十万量级，而且自带筛选——不相关的人根本刷不到它。
2. **信任层**：帖子的背书不是 HR 写的 JD，而是发帖人本人的论文、开源代码和公开言论。作品即信用，省掉了候选人心里“这团队到底靠不靠谱”的怀疑成本。
3. **信号层**：把“我们要解决什么问题”写清楚，等于把筛选条件前置。对问题本身兴奋的人会主动举手，这比按关键词匹配简历精准得多。据报道，这类帖子下评论区往往很快变成“简历池 + 技术讨论区”，一场帖子形式的招聘会。
4. **成本层**：发帖的边际成本约等于零；而传统猎头佣金通常在年薪的 20%–30% 量级（行业惯例）。代价则在于——你得先拥有十年积累的影响力资产，才有这次“广播权”。

所以“摇人”不是玄学，而是一次**影响力变现 + 自筛选漏斗**的组合操作：整个招聘漏斗里最贵的前端环节（触达 + 初筛），被一条帖子大幅压缩了。

## 三、为什么是“小团队 + 高密度”：人才密度经济学

接下来的问题是：前沿实验室为什么不直接招一百个人，而要费劲摇十几个对的人？

- **可购买 vs 不可购买**：算力可以下单，数据可以攒，代码可以写，但“判断该做什么”的 research taste 稀缺且难复制。agent 方向的特殊性在于，连问题定义本身都还没定型，方向感的价值远高于执行人手。
- **沟通成本的平方定律**：《人月神话》的老结论至今成立——沟通路径随人数平方增长。n 个人有 n(n-1)/2 条沟通线：10 人团队 45 条，50 人团队 1225 条。在评测困难、迭代以天计算的 agent 领域，小团队的高频对齐是更优解。
- **历史镜像**：Transformer 论文的核心作者是位数量级；DeepMind、OpenAI 早期的多数突破，也都来自十人上下的核心小组。行业反复验证同一件事：**先有密度，再谈规模**。

换句话说，“摇人”摇的不是人头，是密度。一个对的人带来的方向感，超过十个执行者——这也是为什么顶级实验室愿意为“对的人”支付极高的溢价和耐心。

## 四、这事儿跟大多数从业者有什么关系

热搜看完了，跟不在 OpenAI 的我们有什么关系？至少有三点值得展开：

1. **招聘漏斗前移了。** 作品——论文、开源 repo、技术博客、上线的产品——成了可被检索的信号。“被摇”的前提，是你在公开世界里“可被发现”。沉默地做好工作当然重要，但可检索性决定了机会能不能找到你。
2. **公开输出有复利。** 姚顺雨这次的影响力不是一条帖子的运气，而是读博期间持续做研究、持续公开表达的多年复利。那条帖子只是收割动作，资产是早些年一茬一茬种下的。
3. **也要泼点冷水。** 热搜天然展示幸存者。对绝大多数公司和团队，“摇人”只是招聘渠道之一，薪酬、成长空间、问题本身的吸引力仍是硬通货。把发帖神化，和把中奖故事当理财攻略，属于同一种认知错误。

## 五、收尾：三条建议与冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets3@main/images/2026-11-06/cfa867ae8196ed26.png)

1. **把作品当简历的前置项。** 一个能跑起来的 repo、一篇把问题讲清楚的博客、一次认真的复现与评测，都比简历上的“精通 XX”更有信息量。先让世界能搜到你，再谈机会找到你。
2. **用问题筛选人，而不是用岗位筛选人。** 如果你在组队或招人，试着把“我们在解决什么问题、卡在哪一步”写出来——吸引来的是同路人；只写岗位描述，吸引来的只是投递者。
3. **冷思考：影响力是放大器，不是起点。** 它会精确放大你已有的水平。先有东西可摇，再谈摇人；对围观者同理，热闹看完，真正值得研究的是那条帖子背后十年的公开积累——这才是热搜里最不该被划走的部分。
